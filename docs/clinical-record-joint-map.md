## 二、记录中反复出现的总流程

### 0. 主诉优先，不把查体异常平均分配优先级

系统必须先固定一个本次主目标，例如“下楼时膝内侧疼痛”，而不是把膝伸直受限、踝背屈受限、单腿蹲不稳和其他不舒服动作分别生成同等优先级的处理任务。

- **主诉**决定处理顺序和最终复测动作。
- **疼痛位置与诱发动作**生成第一批候选来源。
- **活动度、力量、触诊和其他功能异常**用于支持、排除、补充或调整候选排序。
- **处理查体异常的价值**，最终仍用主诉动作是否改善来判断。
- 肿胀、力量、刺痛和按压痛等不适合当场反复测试的项目，留作后续随访，不抢占主诉动作的即时复测位置。

例如“下楼时膝内侧疼痛”，记录支持的候选不只在疼痛点局部：

1. 大腿外侧链：股外侧肌、阔筋膜张肌与髂胫束周围。
2. 鹅足肌群：缝匠肌、股薄肌、半腱肌及止点周围。
3. 内收肌与内侧腘绳肌。
4. 胫骨前肌、胫骨后肌、足外翻与足弓支撑。
5. 髌骨、膝关节、腓骨近远端以及踝足关节活动。
6. 股四头肌离心控制、臀肌和下肢力线控制。

以上都是“候选”，不是一次全部处理。一次只改变一个变量，随后用相同台阶、速度、深度和扶持重复下楼动作；明显改善的方向保留，部分改善可保留后继续下一项，没有变化则换方向，加重则停止该方向。

### 1. 先确定本次要解决什么

1. 问清部位、性质、程度、发生时间、诱发动作和缓解方式。
2. 急性损伤补问受伤机制、当时能否负重、肿胀和淤血变化、是否做过影像学检查。
3. 记录患者真正想恢复的动作：走路、上下楼、久坐、弯腰、举手、跑步、球类等。
4. 只把会改变后续处理的异常列为本次重点。

### 2. 从局部检查到相关链条

记录中最稳定的顺序不是一次查遍全身，而是：

1. **症状位置与触诊**：找到更具体的疼痛、肿胀、紧张和压痛区域。
2. **局部各方向活动**：和健侧比较，确认哪个方向受限、哪个方向会出现原症状。
3. **局部力量与控制**：判断是疼痛抑制、萎缩、无力还是动作代偿。
4. **高相关特殊测试**：用于判断是否需要影像或医学评估，不用单个阳性测试直接下诊断。
5. **患者的疼痛动作**：现场重现走路、下蹲、抬手等问题。
6. **相关区域**：局部发现解释不足时，再查上下游关节、神经张力和整体动作。
7. **手动调整后复测**：屏蔽某块肌肉、改变关节位置或做一次低风险处理，再做原动作，判断该方向是否值得继续。

### 3. 处理按异常结果分配

- **肿胀明显**：先处理肿胀和负荷，过度肿胀时不强行做没有意义的末端活动测试。
- **活动受限**：先处理相关紧张软组织；改善不足时，再加入相应关节松动；随后复测原受限方向。
- **疼痛动作**：根据触诊和动作调整结果选择肌肉、关节或动作模式候选；随后复测同一动作。
- **力量不足**：安排对应训练，不要求当场力量明显改变。
- **步态或功能异常**：先处理限制功能的疼痛和活动度，再训练负重、协调和动作模式。
- **特殊测试阳性或结构问题不能排除**：结合受伤机制、负重能力、时间变化和影像问答决定是否先医学确认，而不是让用户凭一个名词自我诊断。

### 4. 训练不是附加项，而是另一条主线

记录中可提炼出的通用训练进阶是：

1. **恢复能动**：无明显加重的关节活动、等长或低负荷激活。
2. **恢复基础力量**：卧位或支撑稳定的双侧动作。
3. **恢复日常功能**：站立、步态、下蹲、上下台阶、举手和日常使用。
4. **恢复单侧控制**：单腿站、单腿髋控制、分腿蹲、单臂支撑等。
5. **恢复负荷和速度**：负重、耐力、离心、快速发力。
6. **回归运动**：跑步、变向、跳跃落地、球类或专项动作。

进阶依据应是“当前级别能完成、动作可控、症状未明显加重、第二天可以恢复”，而不是机械地按第几次康复升级。

## 三、关节活动受限的统一判断方法

《关节受限判断》中的方法非常适合没有量角器的教练使用，但需要先区分三个概念：

| 类型 | 回答的问题 | 例子 | 系统中的名称 |
| --- | --- | --- | --- |
| 关节活动度测试 | 某个方向实际能活动多少 | 膝伸直、踝背屈、肩外旋 | 活动度结果 |
| 功能动作筛查 | 完成生活或训练动作是否受限 | 弯腰、举手、下蹲、走路 | 功能结果 |
| 位置或排列观察 | 两侧外观或标志点是否不同 | 脚跟高度、髂前上棘高度 | 位置候选 |

功能动作异常不能直接等同于某个关节受限；位置不对称也不能直接等同于“关节错位”。它们的作用是告诉系统下一步应该检查什么。

### 1. 无工具用户的基础流程

每个关节方向统一采用以下顺序：

1. **先问是否允许活动**：明显变形、急性期过度肿胀、无法承受的疼痛或医生明确限制活动时，不强行测试。
2. **主动活动**：双侧采用相同姿势、相同速度，同时做到可接受末端。
3. **记录四件事**：哪侧较小、在哪里疼、疼痛性质、出现了什么代偿。
4. **重复一次**：只有差异能够重复出现，才标记为“主动活动受限”。
5. **安全时检查被动活动**：由协助者缓慢把关节带到自然末端，对比角度、疼痛和末端阻力；急性损伤、术后限制和强烈疼痛不使用。
6. **根据主动—被动组合分支**：判断主要进入肌肉控制路径，还是关节与肌肉共同处理路径。
7. **增加功能动作**：下肢看负重、走路、下蹲或台阶；上肢看举手、摸背、穿衣、拧毛巾或撑地。
8. **处理后按固定顺序复测**：先被动、再主动、最后复测原功能动作，姿势、速度和测试方法保持一致。

### 2. 不用角度时如何判定

系统不要求非专业用户填精确角度，而采用四级结果：

- **基本相同**：两侧没有稳定、明显差别。
- **轻微不同**：看起来略有差别，但重复时不稳定，不直接列为主要问题。
- **明显受限**：同一方向连续两次都明显小于健侧，或提前因原症状停止。
- **无法完成**：因为疼痛、肿胀、恐惧、无力或医嘱限制不能测试。

“无法完成”需要继续标注原因，不能自动归类为关节僵硬。

精确量角仍应由经过训练的人完成。CDC 的关节活动度研究采用统一体位、标准量角器和明确的运动终点，说明精确角度依赖标准化操作；其参考值也显示正常人之间存在较大差异，因此本产品优先使用同侧随访和健侧对比，而不是用一个正常角度把所有人一刀切。[CDC 关节活动度研究](https://archive.cdc.gov/www_cdc_gov/ncbddd/jointrom/index.html)

### 3. 所有关节统一采用的主动—被动规律

这条规律适用于肩、肘、腕、髋、膝、踝等四肢关节；颈椎、胸椎和腰椎也采用相同逻辑，但脊柱被动活动和分节检查只由专业人员完成。

| 主动活动 | 被动活动 | 系统判断 | 主要方向 |
| --- | --- | --- | --- |
| 受限 | 基本正常 | **肌肉控制路径** | 疼痛抑制、肌力、肌肉激活、动作控制和必要的神经检查 |
| 受限 | 同样受限 | **关节＋肌肉路径** | 肿胀、相关肌肉、关节囊和关节活动处理，同时安排主动控制训练 |
| 基本正常 | 基本正常 | 暂无活动度异常 | 根据疼痛、力量和功能继续评估 |
| 基本正常 | 被动反而受限 | 结果不一致 | 重新确认姿势、代偿、疼痛和测试方法 |
| 无法完成 | 未测试 | 尚不能分类 | 先记录疼痛、肿胀、恐惧、术后限制或安全原因 |

#### 主动受限、被动正常：肌肉控制路径

1. 当前已确认的是“主动控制不足”，不需要默认做关节松动。
2. 检查主动肌发力、疼痛抑制、协同肌代偿和必要的神经因素。
3. 先用口令、触觉提示、等长或低负荷动作恢复主动参与。
4. 训练主动达到完整被动范围，再进入负重、耐力和功能动作。
5. 力量变化以跨次随访为主；当场主要观察主动角度和动作质量是否改善。

#### 主动受限、被动也受限：关节＋肌肉路径

1. 当前已确认存在被动活动限制，同时把肌肉控制不足列为需要处理和训练的伴随问题。
2. 有明显肿胀时先处理肿胀；没有明显肿胀则检查限制该方向的相关肌肉和软组织。
3. 先做相关肌肉松解，再复测被动范围。
4. 改善不足且适合关节手法时，加入相应关节松动，再复测被动范围。
5. 被动范围改善后立即复测主动范围。
6. 在新获得的活动范围内安排主动控制和力量训练，避免只获得被动角度却不会主动使用。
7. 最后复测原疼痛或功能动作，记录当场反应和第二天反应。

这套规则不用于直接判断具体受损结构，而是决定本次康复的处理顺序。大部分长期被动受限的关节也会伴随末端肌肉控制不足，因此系统不能在松解和关节松动后结束，必须接上对应方向的主动训练。

### 4. 疼痛动作必须与主动—被动活动合并判断

疼痛动作是患者真正想改善的动作，也是处理方向最重要的现场复测项目。它不能只记录“疼或不疼”，而应拆成：

> **什么动作 + 动作哪个阶段 + 哪里疼 + 什么性质 + 是否限制幅度 + 哪种手动调整能改变**

#### 疼痛动作排查顺序

1. **建立基线**：让用户完成一次原疼痛动作，如举手、拧毛巾、下蹲、上下台阶、走路或跑跳。
2. **记录疼痛阶段**：动作开始、中段、末端，还是负重、发力、离心或回程时出现。
3. **记录疼痛表现**：具体位置、酸胀/刺痛/拉扯等性质、程度，以及动作能否继续完成。
4. **检查相关关节主动活动**：看疼痛动作是否同时伴随某个方向主动受限。
5. **安全时检查相关被动活动**：使用主动—被动规律判断肌肉控制路径或关节＋肌肉路径。
6. **做一次肌肉方向调整**：对高相关肌肉进行轻柔屏蔽、放松、触觉提示或改变发力方式，再重复原动作。
7. **做一次关节方向调整**：由具备能力的人手动稳定或调整关节位置，再重复原动作。
8. **只保留能重复改变原动作的方向**：一次偶然变化不够，应重复确认。
9. **完成处理后再做原动作**：比较疼痛位置、性质、程度、出现阶段和动作幅度。

#### 疼痛动作与活动度的组合

| 疼痛动作表现 | 主动—被动结果 | 处理重点 |
| --- | --- | --- |
| 疼痛动作伴主动受限 | 被动正常 | 疼痛抑制和肌肉控制优先，训练主动达到被动范围 |
| 疼痛动作伴主动受限 | 被动也受限 | 肌肉＋关节共同处理，恢复被动后训练主动控制 |
| 疼痛但活动度基本正常 | 主动、被动都正常 | 不标记活动受限；排查局部负荷耐受、肌肉发力、关节稳定和动作策略 |
| 非负重不疼，负重动作疼 | 基础活动可能正常 | 增加步态、下蹲、台阶、支撑、推拉等负重功能评估 |
| 调整某块肌肉后疼痛动作改善 | 活动度可能改变或不变 | 该肌肉进入优先候选，处理后复测并安排控制训练 |
| 调整关节位置后疼痛动作改善 | 活动度可能改变或不变 | 关节位置/活动或动态控制进入优先候选 |
| 肌肉和关节调整都无变化 | — | 重新定位疼痛、检查其他相关区域、特殊测试或影像需要 |

疼痛动作排查得到的是“本次可能相关且可以继续验证的方向”，不是通过一次手动调整确定结构诊断。

#### 哪些结果适合当场复测

- 适合：原疼痛动作、主动活动度、被动活动度、动作质量。
- 不要求当场明显改变：肿胀、淤血、压痛、刺痛残留、肌肉力量和组织恢复。
- 后一类结果进入下次康复和 24 小时反应随访，不能为了追求即时变化反复刺激。

### 5. 通用复测决策

| 处理后表现 | 对思路的调整 |
| --- | --- |
| 被动改善，主动同步改善 | 被动限制是主要影响因素，继续巩固活动并训练控制 |
| 被动改善，主动没有跟上 | 肌肉控制问题更突出，增加激活和主动末端训练 |
| 肌肉松解后被动改善不明显 | 再考虑相应关节松动或重新检查限制来源 |
| 关节处理后被动仍无变化 | 重新检查肿胀、疼痛保护、软组织、测试方法和结构问题 |
| 主动被动都改善，但功能动作仍疼 | 转向负荷耐受、动作策略和其他相关区域评估 |
| 当场变化不大但属于力量不足 | 保留训练，下一次复查，不反复追求即时力量变化 |

### 6. 《关节受限判断》的逐项标准化

#### 膝关节伸直

- **姿势**：仰卧，双腿自然伸直，脚尖朝上；主动绷紧大腿前侧，把膝后侧向床面靠近。
- **观察**：两侧膝后间隙、脚跟是否离床、末端疼痛和股四头肌发力差异。
- **主动控制**：协助者可把手放在腘窝下方，对比两侧主动下压的压力；该结果反映主动发力和控制，不单独代表伸直角度。
- **被动活动**：一手稳定大腿末端，另一手托住小腿下段或脚跟，缓慢把膝关节带到伸直末端，对比两侧角度、疼痛和末端弹性，不强行压向过伸。
- **判断**：主动受限但被动接近健侧，进入股四头肌控制路径；主动和被动都受限，进入膝关节＋相关肌肉共同处理路径。
- **复测**：处理后先复测被动伸直，再复测主动下压和伸直，最后观察站立负重或走路。

#### 膝关节屈曲

- **姿势**：仰卧，双侧脚跟同时向臀部滑动，避免骨盆明显抬起或身体旋转。
- **观察**：两侧小腿角度、脚跟到臀部的距离、末端疼痛和骨盆代偿。
- **被动比较**：主动屈曲受限时，在安全范围内由协助者缓慢增加屈曲，比较主动和被动末端。
- **判断**：主动受限、被动正常进入屈肌控制路径；主动和被动都受限进入肌肉、髌骨/关节囊和膝关节共同处理路径。

#### 骨盆位置观察

- 原记录中的仰卧—抬臀复位—长坐比较，以及髂前上棘/髂后上棘触诊，可以保留为**骨盆相关候选测试**。
- 输出只能写“脚跟高度随坐起发生变化”或“标志点左右不对称”，不能自动写成“骨盆卡旋前/旋后”。
- PSIS 触诊的检查者间一致性研究结果较低，因此位置观察必须结合腰髋活动、疼痛动作和调整后复测，不能单独决定处理。[PSIS 触诊可靠性系统综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC4807681/)

#### 踝关节四方向

- **姿势**：坐位或仰卧，双侧同时完成背屈、跖屈、内翻、外翻，膝和髋保持相近位置。
- **观察**：各方向分别记录，不合并成“踝活动不好”；同时记录疼痛位置、肌肉抽动和代偿。
- **主动—被动比较**：四个方向逐项比较。主动受限、被动正常时训练该方向肌肉控制；主动和被动都受限时处理相关肌肉及踝足关节，再在新范围内训练。
- **增加负重背屈**：能安全负重时增加膝碰墙测试——脚跟不抬，膝盖向前碰墙，逐渐把脚向后移动，对比脚尖到墙的最大距离。
- 膝碰墙测试对负重背屈有较好的重复性，研究中的最小可检测变化约为 1.6–1.9 cm；产品可把约 2 cm 的稳定变化作为明显进步的参考，但非专业用户仍以重复测试和同侧随访为主。[负重弓步测试系统综述](https://pubmed.ncbi.nlm.nih.gov/25704110/)

#### 腰椎屈曲

- **原方法保留为功能筛查**：站立弯腰，观察手能到哪里、是否出现原症状、下腰是否参与、髋膝如何代偿。
- “手能否过膝”不能单独判断腰椎屈曲角度，因为动作同时包含胸椎、腰椎、骨盆和髋关节。
- 系统输出写“弯腰功能受限/疼痛”，随后补查髋屈曲、后侧链、神经张力和腰椎运动表现。
- 即使专业环境使用 Schober 类方法，也存在测量范围和效度限制，因此产品不把单一皮尺结果作为确定结论。[Schober 测试效度研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10915146/)

#### 腰椎伸展

- **原方法保留为功能筛查**：站立后仰，观察活动幅度、疼痛位置、左右偏移和髋部代偿。
- “肩是否越过中线”不是标准角度判断，只能作为同一个人前后复测的固定参照。
- 系统输出写“后仰功能受限/疼痛”，不能直接写“腰椎小关节卡住”。

#### 胸椎旋转

- **姿势**：坐位，双脚着地，膝髋保持稳定，双臂在胸前交叉或水平折叠，左右旋转。
- **观察**：肩线旋转幅度、左右差异、疼痛以及骨盆是否跟着转。
- **判断**：稳定、可重复的侧间差异记为“胸椎旋转疑似受限”。
- **主动—被动比较**：普通用户只完成主动比较；专业人员可在固定骨盆后做轻柔被动或分节判断，并按统一规律决定控制训练或关节＋肌肉处理。
- 坐位旋转在标准化固定下具有较好的重复性，但仍不能完全隔离相邻节段，因此需要同时记录骨盆代偿。[胸椎旋转测量研究](https://pubmed.ncbi.nlm.nih.gov/22488230/)

#### 肩关节前屈与外展

- **姿势**：站位或仰卧，肘伸直；前屈从身体前方向上举，外展从侧方向上举。
- **观察**：两侧末端高度、疼痛出现位置、耸肩、躯干后仰和肩胛运动。
- **判断**：主动受限、被动正常进入肩胛和肩部肌肉控制路径；主动和被动都受限进入肩周肌肉、关节囊和肩关节共同处理路径，之后训练新范围内的抬臂控制。
- 功能上同时记录能否举手摸头、拿高处物品或完成穿衣。

#### 肩关节内外旋

- **姿势**：仰卧，肩外展 90°、肘屈曲 90°，稳定肩胛后比较前臂向两侧旋转的幅度。
- **调整**：如果疼痛或活动不足不能达到肩外展 90°，改为手臂贴近身体测试，不能强行摆位。
- **观察**：肩胛是否提前翘起、肱骨头是否明显前移、疼痛位置和末端感觉。
- **判断**：主动旋转受限但被动正常时训练肩袖控制；主动和被动都受限时先处理相关肌肉、后侧/前侧关节囊和肩关节，再训练内外旋主动控制。
- 功能上增加摸后脑、摸对侧肩和手背向后摸背。

#### 颈椎活动

- 原记录中的左右旋转应保留，并补齐屈曲、后伸、左右侧屈。
- **姿势**：坐位，躯干和肩膀固定，动作缓慢，不用甩头追求角度。
- **观察**：左右差异、疼痛、头晕、麻木和肩膀/躯干代偿。
- **主动—被动比较**：普通用户只做主动活动；被动末端和节段活动由专业人员检查，并同样区分肌肉控制路径和关节＋肌肉路径。
- 出现明显头晕、视物异常、进行性麻木无力或急性外伤时，不继续自行做末端测试。

### 7. 新增的关节方向

《关节受限判断》暂未覆盖髋、肘、腕手和部分脊柱方向。结合线下记录，系统还应补充：

| 区域 | 至少检查的方向 | 简化方法 |
| --- | --- | --- |
| 髋 | 屈曲、后伸、内旋、外旋、内收、外展 | 稳定骨盆，先主动再在安全条件下被动比较 |
| 肘与前臂 | 屈曲、伸直、旋前、旋后 | 上臂贴近身体，先主动再被动比较 |
| 腕 | 屈曲、背伸、桡偏、尺偏 | 前臂固定在桌面，先主动再被动比较 |
| 胸椎 | 旋转、伸展 | 坐位旋转；靠椅背或泡沫轴做伸展观察 |
| 腰椎 | 弯腰、后仰、左右侧屈 | 作为功能和症状筛查，不声称隔离单一节段 |
| 颈椎 | 屈曲、后伸、左右旋转、左右侧屈 | 坐位固定躯干后逐项比较 |
| 足部 | 第一跖趾背伸及足部承重表现 | 大脚趾活动、提踵、走路推进阶段 |

### 8. “当前异常”的生成规则

症状输入只能生成待检查项目。完成上述测试后，系统按以下格式生成当前异常：

> **部位 + 方向/疼痛动作 + 主动结果 + 被动结果 + 疼痛阶段与性质 + 手动调整反应 + 分支类型 + 证据来源**

例如：

- 右膝主动伸直和被动伸直均小于左侧，膝后侧拉扯；进入关节＋肌肉路径；来源：双侧仰卧对比。
- 右踝主动和被动背屈均受限，负重背屈较左侧少约 3 cm；进入关节＋肌肉路径；来源：非负重比较和膝碰墙测试。
- 左肩主动前屈明显受限，被动前屈接近右侧；进入肌肉控制路径；来源：主动—被动比较。
- 下楼梯承重阶段右膝下方刺痛，按压/屏蔽股外侧肌后重复下楼疼痛减轻；股外侧肌相关方向进入优先候选，仍需处理后再次复测。
- 肩前屈中段前方夹痛，手动辅助肩胛上回旋后疼痛减轻、幅度增加；肩胛控制方向进入优先候选。
- 弯腰到膝下时出现右腰疼；来源：功能动作筛查，尚不能确定为腰椎屈曲受限。
- 脚跟高度在仰卧和长坐时发生变化；来源：位置观察，骨盆相关候选，未确认结构位置异常。

这样系统既能把“已经观察到的事实”和“可能的原因”分开，也能直接决定后续是以训练为主，还是先处理关节和肌肉再训练。

## 四、颈部

### 常见问题

- 旋转、侧屈、屈曲或后伸受限，后伸受限在部分记录中更明显。
- 上斜方肌、肩胛提肌、斜角肌、胸锁乳突肌和枕下肌紧张。
- 头痛、头晕、肩胛内侧不适，以及手臂或手指麻木。
- 第一肋上浮、上颈椎活动受限、胸椎活动不足和肩胛位置异常共同出现。

### 评估思路

1. 问清头痛、头晕、麻木、电击感、夜间症状及颈部受伤史。
2. 按“屈曲、后伸、左右旋转、左右侧屈”逐项比较主动活动，并记录出现原症状的方向和躯干代偿；需要被动和分节判断时交由专业人员完成。
3. 选择转头、抬头、低头或抬臂等原疼痛动作作为基线，分别观察肌肉支持、肩胛/胸椎调整和专业关节调整后是否改变。
4. 触诊上斜方肌、肩胛提肌、斜角肌、胸锁乳突肌、枕下肌。
5. 检查上颈椎与颈椎侧向滑动，再看胸椎旋转和伸展。
6. 看第一肋、锁骨和肩胛位置；有上肢症状时检查正中、尺、桡神经张力。
7. 补查肩关节前屈和内外旋，避免把肩部问题全部归到颈椎。

### 处理思路

- 主动受限、专业被动检查基本正常：以颈部肌肉控制、疼痛抑制和主动训练为主。
- 主动和被动都受限：处理相关颈肩肌肉，并由专业人员选择颈椎/上颈椎松动；随后先复测被动，再训练主动达到新范围。
- **反复出现**：松解上斜方肌、肩胛提肌、斜角肌、胸锁乳突肌、枕下肌；根据受限方向选择颈椎、上颈椎、胸椎和第一肋松动。
- **有神经症状时**：处理可能增加张力的肌肉与第一肋，并采用温和的神经滑动，复测麻木范围和原动作。
- **不要固定归因**：第一肋、胸椎或某块肌肉只是候选因素，要看调整后颈部动作或上肢症状是否改变。

### 训练思路

- 起始：无明显症状加重的颈部活动、颈深屈肌激活、呼吸配合。
- 基础：肩胛后缩下沉、菱形肌和中下斜方肌控制、胸椎伸展与旋转。
- 进阶：四点跪支撑、鸟狗、上肢活动中保持颈肩控制，再回到久坐、转头和训练动作。
- **资料不足**：记录缺少颈部抗阻、耐力和运动专项的统一组数与进阶标准。

## 五、肩关节与肩胛

### 常见问题

- 前屈或外展时疼痛、夹挤感和活动受限。
- 肩内旋受限、后侧关节囊紧、肱骨头前移。
- 肩胛上提、外展、翼状或上回旋不足。
- 肩袖、肱二头肌长头、胸大肌/胸小肌、上斜方肌和肩胛提肌紧张。
- 颈椎、胸椎、第一肋和神经张力共同影响上肢动作。

### 评估思路

1. 明确举手、穿衣、卧推、游泳、投篮等具体疼痛动作。
2. 先做主动前屈、后伸、外展、内旋、外旋；主动受限时再根据安全条件比较被动活动，明确进入肌肉控制路径还是关节＋肌肉路径。
3. 观察肩胛静态位置和抬臂时上回旋、后倾、贴胸情况。
4. 触诊肩袖、肱二头肌长头、胸肌、三角肌及肩胛周围肌肉。
5. 选择少量高相关测试，如夹挤、空罐等；阳性只表示需要进一步排查。
6. 做肩胛辅助、肱骨头位置调整或肌肉屏蔽，然后马上复测原动作。
7. 补查颈椎旋转、胸椎旋转/伸展、第一肋和上肢神经张力。

### 处理思路

- 主动受限、被动正常：优先训练肩袖、三角肌和肩胛控制，并处理导致主动抑制的疼痛，不默认做关节松动。
- 主动和被动都受限：先处理肩袖、胸肌、背阔肌、肩胛提肌等相关软组织；被动改善不足时加入肩关节或后侧关节囊松动；被动改善后训练主动抬臂或旋转达到新范围。
- 抬臂夹挤：根据肩胛辅助和肱骨调整结果，选择肩胛、后侧关节囊、胸椎或第一肋方向。
- 前方疼痛：把肱二头肌长头、胸肌、肱骨前移和肩袖列为候选，不能仅凭空罐测试固定为冈上肌问题。
- 麻木或放射：加入颈椎、第一肋和神经路径处理。
- 最终处理优先级由原疼痛动作决定：哪种肌肉或关节调整能稳定改善举手、穿衣、推拉或专项动作，就优先处理并接上相应控制训练。

### 训练思路

- 起始：疼痛允许范围内的前屈、内外旋活动；肩胛后缩下沉和贴胸控制。
- 基础：菱形肌、中下斜方肌、肩胛下肌和肩袖激活；低负荷三角肌外展。
- 进阶：四点跪或墙面支撑、肩胛稳定下抬臂、内外旋抗阻、划水或推拉模式。
- 回归：逐渐恢复卧推、游泳、投掷等目标动作，并用原诱发动作复测。
- **资料不足**：肩袖力量进阶、过头负荷、速度和回归运动标准记录较少，系统应先标为待补充模块。

## 六、肘关节

### 常见问题

- 术后或受伤后的伸直、旋前受限。
- 肘外侧或前侧疼痛，肱二头肌、肱桡肌及前臂肌群紧张。
- 尺神经或正中神经相关的手指麻木。
- 肘部问题与肩关节、肩胛、第一肋和神经张力同时存在。

### 评估思路

1. 区分术后、急性损伤、重复负荷和训练动作诱发。
2. 对比主动屈曲、伸直、旋前、旋后；存在受限时在安全条件下补充被动比较，记录末端感觉、疼痛位置和两侧差异。
3. 触诊肱二头肌、肱三头肌、肱桡肌、屈伸肌群和手术瘢痕。
4. 检查肘、桡尺关节活动和稳定性。
5. 有麻木时检查尺/正中/桡神经，并补查肩、肩胛、第一肋。
6. 用推、拉、支撑、提物等实际动作复现并复测。

### 处理思路

- 主动受限、被动正常：训练肱二头肌、肱三头肌或前臂旋转肌群的主动控制。
- 主动和被动都受限：根据方向处理肱二头肌、肱三头肌、肱桡肌和前臂肌群，被动改善不足时选择肘或桡尺关节松动；随后训练新范围内的屈伸或旋转控制。
- 术后记录中还包括瘢痕、淤血和肿胀处理。
- 神经症状需要处理整个上肢路径，不能只松解肘部痛点。
- 分别尝试前臂肌肉屏蔽、发力提示和肘/桡尺关节稳定，只有能够重复改变提物、推拉或支撑疼痛的方向进入优先方案。

### 训练思路

- 起始：肱二头肌、肱三头肌等长或低负荷激活；主动屈伸和旋前旋后。
- 基础：前臂旋转力量、轻负荷提物、握力。
- 进阶：墙面到桌面再到地面的支撑，逐渐恢复推、拉和专项动作。
- **资料不足**：独立肘部训练病例偏少，尤其外侧肘痛的离心训练与负荷进阶需另行补充验证。

## 七、腕与手

### 常见问题

- 尺侧或桡侧腕痛，负重、尺偏/桡偏、背伸或旋前旋后诱发。
- 腕骨或远端尺桡关节位置/活动异常。
- 拇指发力不足、抓握或支撑困难。
- TFCC 相关体征在一份专项记录中较完整，但属于个案候选模板。

### 评估思路

1. 问清撑地、提物、旋拧、握拍等诱发场景。
2. 对比主动屈曲、背伸、桡偏、尺偏、旋前和旋后；受限方向再做安全的被动比较。
3. 触诊疼痛点，检查远端尺桡关节和腕骨活动。
4. 检查抓握、拇指/小指功能和旋前旋后力量。
5. 必要时做琴键征等高相关测试；阳性结合创伤史和影像判断。
6. 手动稳定某个关节位置后复测原负重动作。

### 处理思路

- 主动受限、被动正常：以相应腕手和前臂肌群的主动控制、力量和抓握训练为主。
- 主动和被动都受限：先处理相关前臂/腕手肌肉，被动改善不足时再选择远端尺桡关节、腕骨或拇指关节松动，随后训练主动使用新范围。
- 按疼痛位置选择尺侧腕屈肌、肱桡肌、鱼际和前臂肌群作为软组织候选。
- 用撑地、提物、旋拧或握拍作为原疼痛动作，比较肌肉调整和腕骨/尺桡关节稳定后的变化，再决定处理和训练方向。

### 训练思路

- 抓握、旋前旋后、桡偏/尺偏、小指外展和拇指控制。
- 从无负重活动到桌面支撑，再到俯卧撑或专项握持。
- **资料不足**：腕手资料数量与随访结果不足，系统中应清楚标注为低置信度候选，不形成自动化固定方案。

## 八、胸椎与肋骨

### 常见问题

- 胸椎旋转或伸展受限。
- 肩胛内侧、上背或肋骨周围不适。
- 第一肋上浮、胸肌紧张、肩胛动作不足。
- 常作为颈肩活动受限、抬臂夹挤或姿势问题的相关因素出现。

### 评估思路

1. 普通用户对比坐位或四点跪位主动旋转、主动伸展，并固定骨盆、观察腰椎和肩胛代偿；被动或分节检查由专业人员完成。
2. 观察呼吸时胸廓活动和左右差异。
3. 触诊胸椎分节、肋骨、胸肌、背阔肌和肩胛周围。
4. 同时复测颈部转动、抬臂或上肢训练动作，确认胸椎改变是否真正影响主诉。

### 处理思路

- 主动受限、专业被动检查基本正常：训练胸椎主动旋转/伸展和躯干控制。
- 主动和被动都受限：先处理胸背相关肌肉，再由专业人员选择胸椎或肋骨松动；被动改善后训练主动使用新范围。
- 胸椎和相关肋骨松动。
- 松解胸大/小肌、背阔肌、菱形肌、竖脊肌等候选软组织。
- 第一肋处理需结合颈肩动作或上肢症状的即时变化。
- 胸椎本身的角度改变不是唯一目标；只有胸椎/肋骨处理能改善原转体、抬臂或呼吸疼痛动作时，才把它列为本次重点。

### 训练思路

- 胸椎伸展、翻书/开放书、胸椎旋转、呼吸练习。
- 与肩胛稳定、鸟狗和四点跪支撑结合。
- 进阶到抬臂、划水、转体和目标运动动作。

## 九、腰椎与骨盆

### 常见问题

- 久坐、弯腰、后伸、侧屈或翻身诱发的腰骶部不适。
- 臀部或下肢拉扯、麻木和放射症状。
- 髋活动受限、后侧链紧张、臀肌/腘绳肌无力、单腿稳定性差。
- 记录中大量使用“骨盆卡旋前/旋后”描述；它适合作为手法与复测方向，不应直接包装成确定的结构诊断。

### 评估思路

1. 问清久坐、弯腰、搬重、睡觉、跑步等诱发场景及下肢症状分布。
2. 检查主动弯腰、后伸、左右侧屈和必要的旋转，记录原症状与动作策略；这些是功能筛查，不直接等同于某个腰椎节段受限，被动和分节活动由专业人员检查。
3. 触诊腰大肌、腰方肌、竖脊肌、臀肌、梨状肌和骶髂周围。
4. 专业人员可检查腰椎分节；骨盆标志点和仰卧—长坐变化仅记为位置候选，不能单独确定骨盆旋转方向。
5. 对比髋屈曲、伸展、内旋、外旋、内收，以及直腿抬高、PKB和下肢神经张力。
6. 测臀肌、腘绳肌、核心能力，再看单腿站、下蹲、屈髋和步态。
7. 用手动骨盆/骶骨调整或软组织屏蔽后复测原疼痛动作。

### 处理思路

- 主动动作受限、专业被动/分节检查基本正常：以核心、腰髋肌肉控制和动作训练为主。
- 主动和被动/分节活动都受限：先处理相关肌肉和软组织，再选择适合的腰椎、髋或骨盆关节手法；随后训练主动弯腰、后伸或侧屈控制。
- 根据运动受限和触诊结果选择腰大肌、腰方肌、竖脊肌、TFL/髂胫束、臀肌、梨状肌和前后侧链处理。
- 髋关节囊、腰椎、骨盆或骶骨松动作为候选，以原动作复测决定是否继续。
- 有下肢放射或拉扯时加入神经滑动，但应避免强刺激追求“拉开”。
- 急性期先降低刺激、恢复可接受活动，不能一开始堆叠高强度训练。
- 用弯腰、后仰、坐起、翻身、走路或目标训练动作作为基线；肌肉屏蔽、骨盆/髋调整后必须重复同一动作，变化稳定才保留该方向。

### 训练思路

- 起始：呼吸与深层腹部激活、骨盆控制、臀桥、温和活动。
- 基础：脚垫高臀桥、单腿臀桥、死虫、鸟狗、猫式伸展。
- 站立：屈髋、单髋支撑、深蹲、分腿蹲、螃蟹步。
- 进阶：单腿屈髋/硬拉、登阶、负重、耐力和目标运动。
- 记录中已有“肌肉能力不足时先在仰卧位训练，具备支撑能力后再进入站立位”的清楚进阶原则。

## 十、髋关节与大腿

### 常见问题

- 髋屈曲、内旋、外旋或内收受限，腹股沟、臀部或大腿外侧不适。
- 腰大肌、TFL/髂胫束、股直肌、股外侧肌、内收肌和后侧关节囊紧张。
- 臀大肌、臀中肌和腘绳肌无力或萎缩。
- 髋问题常同时影响腰、膝、踝、步态和单腿动作。

### 评估思路

1. 明确久坐、走路、跑步、下蹲、单腿支撑等诱发动作。
2. 稳定骨盆后逐项对比主动髋屈曲、后伸、内旋、外旋、内收和外展；受限方向再比较被动活动，区分肌肉控制问题和关节＋肌肉问题。
3. 触诊腹股沟、臀部、腰大肌、TFL、股四头肌、内收肌和后侧链。
4. 检查骨盆位置、PKB、直腿抬高和相关神经张力。
5. 测臀大/中肌、腘绳肌和内收肌能力。
6. 看屈髋模式、单腿站、单腿蹲、步态；必要时补查腰、膝和踝。
7. 在下蹲、台阶、单腿支撑或走跑等原疼痛动作中，分别比较髋周肌肉提示、骨盆稳定和髋关节调整后的反应。

### 处理思路

- 主动受限、被动正常：训练对应方向的臀肌、髋屈肌、内收/外展或旋转控制。
- 主动和被动都受限：按方向先处理髋周软组织和前/后侧关节囊；被动改善不足时加入髋关节松动；获得范围后训练主动髋控制。
- 骨盆动态调整作为相关候选，需用髋活动和目标动作复测决定是否保留。
- 疼痛跨越腰臀腿时加入神经路径检查，不把所有外侧紧张都归为髂胫束。
- 哪个方向能重复改善原疼痛动作，就优先进入本次处理；处理后仍需在相同动作中复测并训练主动控制。

### 训练思路

- 起始：臀桥、髋外展/臀中肌激活、腘绳肌低负荷训练。
- 基础：单腿臀桥、蚌式/螃蟹步、屈髋模式、单髋支撑。
- 进阶：深蹲、分腿蹲、登阶、单腿屈髋/硬拉。
- 回归：负重、跑步、跳跃和专项转体。
- 训练选择应服从当前问题；不能因为臀桥出现频率高，就让每个髋膝踝病例都采用同一组合。

## 十一、膝关节

膝是这批记录中路径最清楚的关节，适合最先做成完整的产品知识模块。

### 常见问题

- 膝末端伸直受限，膝后侧或膝下不适。
- 髌骨位置/滑动异常、髌腱或脂肪垫压痛。
- 肿胀、积液、皮温改变和术后瘢痕粘连。
- 屈曲末端受限。
- 股内斜肌、臀肌、腘绳肌、小腿肌群弱或萎缩。
- 踝背屈/外翻受限、腓骨活动不足、髋与骨盆问题、神经张力。
- 下蹲、单腿蹲、上下楼、跑步、跳跃落地或步态异常。

### 推荐评估顺序

1. **病史和目标**：受伤/手术/影像、肿胀变化、疼痛位置与性质，走路、楼梯、跑跳目标。
2. **观察与步态**：肿胀、皮温、肌肉围度、负重和走路模式。
3. **局部触诊**：髌骨周围、髌腱、脂肪垫、关节线、腘窝、腘肌和小腿。
4. **髌骨**：位置、上下内外活动和压磨相关表现。
5. **活动度**：先按标准化仰卧方法查主动伸直和屈曲；存在受限时，在安全条件下比较被动活动，决定进入肌肉控制路径还是关节＋肌肉路径。术后同时看瘢痕、医嘱和末端限制。
6. **力量**：股内斜肌/股四头肌、腘绳肌、臀肌和小腿。
7. **特殊测试**：按病史选择半月板、韧带或髌股相关测试，不做无差别测试套餐。
8. **相关链**：踝背屈/外翻、距骨与近端腓骨，髋各方向、骨盆、PKB、直腿抬高和神经张力。
9. **功能**：下蹲、单腿站、单腿蹲、上下台阶、步态；运动需求者再看跑跳落地。
10. **疼痛动作调整**：对原疼痛动作分别尝试相关肌肉屏蔽/发力提示、髌骨或胫骨位置调整，记录哪一种能稳定改变疼痛和动作幅度。

### 按问题分配处理

#### 伸直受限

- 主动受限、被动正常：以股四头肌特别是末端伸膝控制和疼痛抑制处理为主。
- 主动和被动都受限：同时处理下列肌肉、髌骨/膝/腓骨等关节候选；被动伸直改善后立即训练主动末端伸膝。
- **反复出现的肌肉候选**：股外侧肌、TFL/髂胫束、腘肌、小腿三头肌和其他后侧链。
- **反复出现的关节候选**：膝关节 AP/PA 松动、髌骨上推、近端腓骨松动；必要时处理踝和髋限制。
- **力量候选**：股内斜肌/股四头肌抑制或萎缩。
- 处理后先复测被动伸直，再复测主动伸直和原负重动作；不要求力量当场明显改变。

#### 屈曲受限

- 主动受限、被动正常：优先训练屈膝控制，并检查疼痛抑制。
- 主动和被动都受限：进入肌肉、髌骨/关节囊和膝关节共同处理路径。
- 检查股四头肌、股直肌、髌骨向下活动、瘢痕和关节囊。
- 对应软组织或关节处理后先复测被动屈膝，再复测主动屈膝、下蹲或上下楼，并训练新范围内的主动控制。

#### 肿胀或术后

- 记录肿胀范围、皮温、活动和负重变化。
- 候选处理包括淋巴回流、理疗、瘢痕和温和活动；训练级别由肿胀和承重反应决定。
- 术后方案必须受手术类型、组织愈合和医嘱约束，不能套用普通膝痛路径。

#### 前方、内侧或外侧疼痛

- 用具体触诊点、活动方向和疼痛动作区分髌腱/脂肪垫、髌股、关节线及软组织候选。
- 记录中多次出现“屏蔽股外侧肌或调整髌骨/胫骨后，原动作减轻”，这种结果可用来排序处理候选，但不能单独构成诊断。
- 处理后必须重复同一个下蹲、台阶、走跑或跳跃动作；只触诊压痛变化不能代替功能复测。

### 训练思路

- **恢复伸直与激活**：膝伸直下压、股内斜肌激活；记录中有 20 次 × 3 组的家庭训练示例。
- **后侧链与臀肌**：臀桥、单腿臀桥、俯卧屈膝慢放、腘绳肌向心/离心、髋外展。
- **踝与小腿**：踝背屈外翻活动、足外翻激活、提踵和小腿力量。
- **恢复负重**：步态练习、屈髋蹲、深蹲、分腿蹲、登阶。
- **单腿控制**：单腿站、单髋支撑点地、单腿屈髋、单腿蹲。
- **回归跑跳**：负重深蹲、快速小幅分腿蹲、单腿硬拉、跳上台阶、落地缓冲、跑步和专项动作。

### 膝关节训练进阶示例

| 阶段 | 重点 | 记录中的动作候选 |
| --- | --- | --- |
| 1 | 活动与肌肉重新参与 | 膝伸直下压、踝活动、臀桥 |
| 2 | 双侧承重与步态 | 步态、屈髋蹲、深蹲、提踵 |
| 3 | 单侧稳定 | 分腿蹲、登阶、单髋支撑、单腿臀桥 |
| 4 | 力量与耐力 | 负重深蹲、负重分腿蹲、腘绳肌离心 |
| 5 | 速度与运动 | 跳跃落地、单腿跳、跑步、变向/专项 |

## 十二、踝关节与足

### 常见问题

- 急性崴脚或外力损伤后的肿胀、积液、淤血和活动受限。
- 背屈、跖屈、内翻、外翻中的一个或多个方向受限。
- 外侧、前外侧、足背、足底、跟腱或足跟疼痛。
- 距骨、腓骨、骰骨、足舟骨或第一跖趾关节活动异常。
- 腓骨肌、胫骨前/后肌、小腿三头肌或足部肌肉无力/萎缩。
- 单腿提踵困难、平衡差、步态异常、无法顺畅负重或跑跳。

### 推荐评估顺序

1. **受伤信息**：机制、时间、能否立即和当前负重、肿胀/淤血变化、既往崴脚、影像问答。
2. **需要先确认的表现**：明显错位轮廓异常、高能量机制、骨点压痛合并明显负重困难、进行性神经血管异常等；淤血本身不等于危险颜色异常。
3. **观察与触诊**：肿胀区域，外踝/内踝/足背/足底/跟腱等具体压痛点。
4. **四个方向活动**：背屈、跖屈、内翻、外翻逐项做主动比较；存在受限时再安全地比较被动活动，能够负重时增加膝碰墙测试。
5. **局部关节**：距骨、近远端腓骨、骰骨、足舟骨、跖趾关节，按症状选择。
6. **力量**：背屈、跖屈、内翻、外翻；检查小腿围度、双脚/单脚提踵。
7. **特殊测试**：按受伤位置选择韧带、肌腱和骨性筛查；结果用于决定是否影像确认。
8. **功能**：负重、走路、单腿站、下蹲、上下台阶；后期再看跑跳。
9. **相关链**：膝伸直和控制、髋/臀肌、骨盆、神经张力，但不喧宾夺主。
10. **疼痛动作调整**：在走路、蹲、台阶、提踵或后期跑跳中，分别尝试相关肌肉提示、足踝支撑和关节位置调整，记录原症状是否改变。

### 按问题分配处理

#### 肿胀和急性疼痛

- 观察肿胀是否消退、范围是否缩小、负重是否逐渐恢复。
- 候选包括负荷调整、淋巴回流、理疗和温和活动；过度肿胀时不强求完整末端测试。
- 淤血可为损伤后的常见残留，应结合温度、感觉、血运和时间变化判断。

#### 活动受限

- 主动受限、被动正常：以该方向肌肉控制训练为主，例如外翻控制、胫骨前肌控制或提踵。
- 主动和被动都受限：进入踝足关节＋相关肌肉共同处理路径。
- 按方向检查胫骨前/后肌、腓骨肌、小腿三头肌、趾伸肌和足底组织。
- 松解后改善不足，可加入踝关节分离、距骨、腓骨、骰骨、足舟骨或跖趾关节松动。
- 处理后先复测被动方向，再复测主动方向和原疼痛动作，并训练主动使用新获得的范围。

#### 不同疼痛位置

- 外侧/前外侧：腓骨肌、胫骨前肌、趾伸肌、外侧关节与韧带作为候选。
- 内侧/足弓：胫骨后肌、足底组织、足舟骨和第一跖趾功能作为候选。
- 后侧/跟腱：小腿三头肌、跟腱负荷和踝背屈作为候选。
- 足底/足跟：足底组织、足部关节、步态和小腿能力共同检查。
- 以上都是起始候选，必须由触诊、动作和复测结果排序。
- 疼痛位置只用于选择第一批候选；最终优先级由原走路、提踵、台阶或跑跳动作在调整后的变化决定。

### 训练思路

- **活动恢复**：四方向主动活动，尤其记录中高频的背屈和外翻。
- **局部力量优先**：足外翻、胫骨前/后肌、小腿三头肌、提踵和足部控制。
- **负重与步态**：双脚负重、重心转移、步态练习、上下台阶。
- **平衡与单腿**：单腿站、不稳定面、单腿提踵、单腿髋控制。
- **整体力量**：深蹲、分腿蹲、臀桥作为下肢协同训练，而不是替代脚踝训练。
- **回归运动**：快节律提踵、跑步、跳跃落地和变向。

### 一条重要纠偏规则

一份随访记录明确指出：脚踝病例前期过度强调髋部模式，而活动度和小腿肌肉没有得到足够训练。后续应调整为：

1. 先恢复踝足活动度；
2. 增加小腿外侧和后侧肌群训练；
3. 恢复步态、提踵和平衡；
4. 再把髋膝训练作为完整下肢链的一部分；
5. 最后进入跑跳。

这条规则应直接进入产品，防止“所有下肢问题都生成臀桥和臀肌训练”。

## 十三、从记录到产品知识库的分类方式

每条知识不应写成“症状 = 某结构 = 固定动作”，而应拆成以下字段：

| 字段 | 示例 |
| --- | --- |
| 适用区域 | 膝关节 |
| 当前异常 | 伸直末端受限 |
| 结果类型 | 关节活动度 / 功能动作 / 位置候选 |
| 主动—被动组合 | 主动受限＋被动受限 |
| 原疼痛动作 | 下楼梯承重阶段膝下刺痛 |
| 动作调整反应 | 屏蔽股外侧肌后减轻；髌骨调整后是否改变 |
| 伴随信息 | 膝后紧、股外侧紧、踝背屈受限、股内斜肌弱 |
| 要做的评估 | 伸直对比、触诊、髌骨、腓骨、踝活动、肌力 |
| 候选原因 | 外侧链紧、腘肌/小腿紧、关节活动不足、股四头抑制 |
| 分支类型 | 关节＋肌肉路径 |
| 可尝试处理 | 相关肌肉松解；被动改善不足时相应关节松动；随后主动控制训练 |
| 当场复测 | 被动伸直 → 主动伸直 → 原下楼动作 |
| 训练方向 | 股四头、腘绳肌、臀肌、小腿、步态和单腿控制 |
| 进阶条件 | 动作可控、症状未明显加重、次日可恢复 |
| 置信度 | 反复出现 / 个案候选 / 资料不足 |
| 来源 | 匿名记录编号，不在前台展示姓名 |

## 十四、当前最值得进入系统的高频规则

1. **所有关节先比较主动与被动**：主动受限、被动正常进入肌肉控制路径；主动和被动都受限进入关节＋肌肉路径。
2. **被动范围恢复后必须训练主动控制**：关节松动和肌肉松解不能作为活动度处理的终点。
3. **疼痛动作贯穿全流程**：建立原动作基线，肌肉调整和关节调整后重复原动作，只保留能够稳定改变症状的方向。
4. **膝伸直受限**不能只看膝：依次检查股外侧/TFL、腘肌和小腿、髌骨/腓骨/膝关节、股内斜肌，再看踝与髋。
5. **踝痛或崴脚**必须测四方向、局部力量、提踵、负重和步态；髋臀训练不能替代小腿和踝足恢复。
6. **肩抬举痛**应包含肩胛辅助和肱骨位置调整后的复测，并补查胸椎、第一肋和颈部。
7. **颈肩伴手麻**需要把第一肋、胸椎和上肢神经张力放进路径，而不是只松斜方肌。
8. **腰臀腿症状**从腰部动作出发，再检查髋、骨盆、肌力和神经；“骨盆旋前/旋后”只作为候选方向。
9. **力量不足**直接进入训练与随访，不设计无意义的即时反复测试。
10. **当场复测**集中在疼痛动作和主动/被动活动度；肿胀、压痛、刺痛和力量变化主要看时间趋势。
11. **后续康复**不是只训练：肿胀、疼痛和活动受限仍存在时，下一次仍需复查并继续相应处理，同时逐级推进训练。
12. **活动受限**必须写清关节、方向、主动/被动、症状和比较来源；“弯腰不舒服”不能直接转换成“腰椎屈曲受限”。
13. **骨盆位置测试**只生成候选，不自动生成旋前/旋后结论；是否保留该方向取决于疼痛动作和处理后复测。

## 十五、资料目前的主要空白

1. 肩、肘、腕手的分阶段力量训练、组数和回归运动标准不足。
2. 大多数记录写了动作名称，但缺少阻力、节奏、休息、每周频率和升级/降级条件。
3. 训练后的 24 小时反应和跨次随访记录不统一，难以自动判断进阶。
4. 特殊测试记录有阳性/阴性，但缺少统一测试方法、适用条件和组合解释。
5. 术后病例需要按手术类型、时间和医嘱单独建路径，不能混入普通损伤。
6. 记录中的理疗、关节松动和部分手法缺少操作者等级与禁忌说明，面向非专业用户时需要分成“可自助、需教练辅助、仅专业人员”三个权限等级。
7. 一些因果描述来自单次即时反应，应改写成“本次可能相关并值得继续观察”，不应表述为确定病因。

## 十六、建议的建设优先级

1. **第一批完整模块**：膝、踝足、腰髋。资料最丰富，能形成从评估到处理再到训练进阶的闭环。
2. **第二批模块**：颈、肩、胸椎。先完成评估与基础训练，再补齐抗阻和回归运动。
3. **第三批模块**：肘、腕手。资料不足，先以少数病种候选卡呈现，不生成强结论。
4. 每个模块先做“症状—关键评估—发现的问题—处理—复测—训练—下次复查”，不要一次展示整套知识。
5. 后续线下记录统一增加四项：**本次训练、组数/个数、完成质量、第二天反应**。这会比继续堆更多动作名称更能提高系统质量。
