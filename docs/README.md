## 维护规则

1. 一条规则只在一份现行文档完整定义，其他文件只链接引用。
2. 审核结论直接替换原规则；需追溯的旧内容移入 `archive/`。
3. 代码、现行文档、验收用例必须同步修改；文档内事实须带 `文件:行号` 证据。
4. 病例经验只生成候选和排序，不能直接变成固定处方或诊断。
5. 桌面与 320~430px 手机网页均为维护范围；Android APK 网页确认后构建。
