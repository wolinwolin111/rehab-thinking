# 疼痛评分动态辅助文案需求

## 背景

康复应用里有一个 0～10 分的疼痛/不适评分滑块，由用户自己选择。数字仍然用于同一动作、同一条件下的前后比较，动态文案只帮助普通用户理解当前分数所属的大致感受档位。

```
0 · 没有疼痛或不适
1～2 · 刚有一点感觉
3～4 · 轻微痛感
5～6 · 明显难受
7～8 · 很痛
9 · 接近最严重
10 · 能想象到的最严重
```

## 已确认方案

- 保留 0～10 的原始数字和滑块操作；不改动评分存储、前后比较或决策阈值。
- 已选择分数时，在滑块下方动态显示“当前分数 · 感受档位”。
- 没有选择分数时只显示“拖动后显示当前程度”，不把默认 0 当作已记录。
- 端点固定为“0 · 没有疼痛或不适”和“10 · 能想象到的最严重”。
- 动态文案只描述疼痛或不适的主观强度，不描述能否走路、能否继续动作、是否影响睡眠或其他功能结果。
- 分档文案是普通用户的选择辅助，不作为临床分级或核心决策规则。

## 约束

1. **通用**：不能绑定走路、跑步、上下楼等特定动作或部位。
2. **简洁**：动态文案保持一行，移动端允许自然换行。
3. **不混维度**：不把疼痛强度和功能受限、睡眠、情绪或行为反应混在一起。
4. **不伪造精度**：不为 0～10 的每个整数硬定义一套医学含义；相邻分数的精确差异由数字位置和用户自身感受表达。
