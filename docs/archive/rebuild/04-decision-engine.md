# 04 决策引擎流程

## 1. 引擎目标

决策引擎不是生成一整套固定康复方案，而是不断回答一个问题：

> 根据当前已经知道的信息，下一项最值得做、且用户能够完成的事情是什么？

## 2. 完整决策循环

```text
原始描述
→ 建立多个症状问题
→ 补充少量会改变下一步的信息
→ 完成必要安全确认
→ 选择当前优先问题
→ 做最有区分度的一项检查
→ 更新问题和候选因素
→ 达到可处理条件后尝试一组相关处理
→ 第一项高相关处理后复测主诉与本组涉及的异常
→ 主诉改善后只复测会改变下一步的相关活动范围
→ 保留有效方向、降低无效方向
→ 处理剩余问题
→ 本轮处理结束后统一复测一次主诉
→ 根据能力差距生成训练
→ 保存并进入后续康复
```

## 3. 症状解析

### 双管齐下但暂不接 AI

首屏提示用户尽量包含：

- 怎么出现的；
- 现在什么位置不舒服；
- 现在什么情况最容易出现。

示例仅帮助表达，不限制格式。

本地解析提取：位置、侧别、时间、发生方式、症状性质、当前动作、功能限制和影像信息。原文没有的信息保持未知。

位置解析采用“文字预选 + 人体图确认”：主诉、肿胀或淤青、按压痛、感觉变化分别建立位置记录，不能用一个位置字段互相替代。

### 解析确认

系统不能静默采用低置信结果。只确认真正影响路径的内容，例如：

> “你提到的下楼，是受伤发生时的动作，还是现在下楼仍然不舒服？”

若无法识别当前主诉动作，允许“没有固定动作/说不清”，后续按症状位置和检查发现继续。

同一句同时出现按压痛和走路、上下楼、下蹲等功能动作时，优先把功能动作作为主诉复测动作；按压痛保留为独立症状和位置记录，不抢占功能主诉。

评分同样不是必填字段。只有当前症状明确、存在可重复情境且用户能判断程度时才询问；说不清、没有固定症状或当前无法安全复现时，评分字段保持空值，前台不显示分数选择，决策流程继续。

## 4. 控制题量

决策库中的字段不等于用户问卷。每条规则都要标记：

- 是否必须询问；
- 是否可以从原文获得；
- 是否会改变下一步；
- 是否已经获得；
- 不知道时是否仍能继续；
- 什么时候停止追问。

首轮一般只补充 3～5 项关键信息；触发急性损伤或安全信号时再增加必要确认。一次只显示一个问题。

首批膝、踝流程按相关性继续缩短：原文已经有清楚的诱发动作时，不再重复询问诱发场景；非近期外伤且原文没有外伤线索时，不强制追问发生方式；刺痛只有在缺少固定诱因或同时存在按压痛时，才追加出现范围或轻按反应。已解析的信息继续显示在右侧，待补充项只显示当前一项，避免形成长清单。

## 5. 多部位与优先级

多个问题同时保留，处理顺序参考：

1. 需要优先医学确认的信号；
2. 急性程度、承重和生活影响；
3. 用户这次最想改善的问题；
4. 与多个问题共同相关的因素；
5. 其他独立异常。

用户说不清优先项时，系统可以推荐顺序并允许修改，不要求先选择唯一关节。

## 6. “不知道”的处理

所有关键结果都支持：存在、不存在、不知道、当前不能检查。

选择“不知道”后按顺序处理：

1. 若能通过一个简单动作看出来，提供通俗指令；
2. 若不影响当前下一步，保留待确认并继续；
3. 若只能由他人或工具判断，切换到适合当前身份的替代检查；
4. 若关系到安全，说明需要确认的具体信息并保存记录；
5. 不能因为未知而把所有其他可处理问题锁死。

## 7. 安全与影像

只询问会明显改变后续路径的信号，包括明显错位或异常轮廓、开放伤口、持续远端颜色温度感觉异常、进行性麻木无力、全身性异常，以及符合条件的急性骨性风险组合。

肿胀和外伤后淤青本身不等于错位或循环异常。

影像采用问答分类，不要求系统直接解析不同医院报告：

- 是否提示骨折；
- 是否提示韧带或肌腱问题；
- 是否有骨挫伤或骨髓水肿；
- 是否有积液；
- 医生是否允许开始康复，有何限制；
- 不知道或报告没有说明。

需要影像但尚未完成时，保存本次记录为等待状态；获得结果后从原记录继续，不重新丢失前面信息。

## 8. 评估队列

### 检查中的不适必须重新定位

检查动作出现不适时，不能默认沿用最开始的主诉位置。用户需要在当前关节附近的局部图上重新标记位置，再选择感觉和分数。系统保存的是一条可复测观察，例如“把脚背向上勾 · 右侧外踝前方 · 刺痛 · 5/10”，而不是让用户判断疾病或结构。

当最开始没有固定主诉动作时，再询问一句“这是平时困扰你的那种感觉吗？”：

- 是：当前检查动作可转成临时复测目标；
- 不是：只保留为辅助发现；
- 说不清：不建立疼痛复测，继续比较活动范围或功能表现。

同一轮最多保留 1～2 个由检查生成的复测目标。

### 生成原则

评估不是“该关节所有检查来一遍”，而是动态选择：

- 主诉位置与性质；
- 当前主诉动作；
- 急性或慢性阶段；
- 恢复目标所需能力；
- 已经发现的问题；
- 用户身份；
- 哪项结果最能区分下一步。

### 题量与检查预算

- 普通用户首轮最多显示 4 项高相关检查；
- 教练最多 5 项，康复或医疗相关从业者最多 6 项；
- 首轮症状补充通常最多 5 问，只有会改变安全、评估顺序或处理方向的问题才进入；
- “不知道”和“当前不能完成”保留为有效状态，不通过重复换问法增加题量；
- 明确足趾局部问题时先看局部，不常规加入完整踝足或近端检查；
- 多位置问题共享题量预算，先处理主问题，其他位置保留在问题清单中。

普通用户首轮通常显示 3～6 个核心检查，但不是先生成六项再硬截断；每完成一项，重新决定下一项是否仍有必要。

### 活动度与不适分开

每个活动方向分别记录：

- 主动范围表现；
- 做这个动作是否出现不适；
- 不适位置、性质和分数；
- 无法完成是否因为疼痛。

普通用户以主动活动为主。专业人士给他人检查时，才补充被动活动和末端表现。脊柱后续模块除旋转等必要情况外不默认要求被动活动。

单侧问题优先与健侧比较；双侧问题不虚构健侧，分别记录哪一侧更差、两侧是否都受限以及动作是否不适。没有左右可比方向时，普通用户以是否不适和是否能完成功能为主；专业人士具备测量工具时可以补充角度是否在参考范围内，同时仍单独记录不适感。

功能动作结果不要求用户判断“正常/异常”，而是分别记录三个维度：能否完成、是否晃动或借力、是否出现熟悉不适。三个结果允许同时成立，例如“可以完成 + 明显膝内扣 + 出现膝内侧疼痛”。处理与训练同时使用这些结果：不适进入症状处理和复测，晃动或借力进入相关活动度、力量与动作控制检查，无法完成则先降低动作难度。肌肉轻按检查按当前活动方向给出明确肌肉区域；目的是寻找可能影响动作的肌肉区域，不用于自行诊断结构损伤。

### 主动与被动解释

- 主动受限、被动基本正常：优先考虑主动控制和发力能力；
- 主动、被动都受限：肌肉与关节因素都进入候选，同时仍考虑控制不足；
- 普通用户无法判断被动：不强迫填写，进入肌肉比较、低风险活动和主动控制路径。

## 9. 处理实验

### 主诉优先，但不只处理主诉

先处理与主诉最强相关、距离较近且尚未尝试的候选。主诉处理结束后，继续检查和处理仍存在的独立活动、力量和功能问题。

### 组合处理与去重

一组处理可以包含同一假设下的少量内容，例如主要肌肉区域的轻柔松解和相关配合处理。完成整组后合并去重，只复测处理前已经异常、与本轮直接相关且尚未复测的主诉或活动，不在每一个小动作后重复测全部项目。

普通用户一轮通常为“主诉动作 + 1～2 个直接相关异常”，相同动作自动合并；原本正常、无法建立前后比较、肿胀或单纯力量不足不进入即时复测。

同一肌肉区域、同一关节方向和同一控制训练在一次康复中不能重复生成。

一组处理必须标记主次：

- 主要处理目标：本轮最希望验证的肌肉、区域、关节或控制方向；
- 定位依据：按住、屏蔽、发力、拉伸、动作调整或此前重复反应；
- 配合处理：与主要目标相关、但不是本轮主要判断的区域。

有直接定位依据且整组处理后改善时，把主要目标记录为有效方向，配合处理只记录为参与，不分别标记有效。原资料或本次检查完全没有主次依据时，才记录为组合方向有效、主要因素待确认。

后续同一问题再次出现时优先复查主要目标，不把所有配合区域重新做一遍。

### 用户身份

- 普通用户：轻柔自我放松、温和活动和主动控制；
- 教练：经审核的辅助观察和低风险内容；
- 专业人员：被动也受限且条件允许时，进入对应方向的关节松动候选。

肌肉松解有改善但活动仍未达到健侧时，专业路径仍可继续关节处理；普通用户则继续主动控制或建议线下处理。不能因为“有一点改善”直接结束异常方向。

### 刺痛、按压痛和肿胀

- 刺痛不单独等于神经问题；伴随麻、电、放射或感觉变化时进入相应确认；
- 不直接反复刺激明显激惹点，可处理相关且不痛的肌肉区域后复测原动作；
- 按压痛记录具体位置，不要求单次处理立即消失；
- 肿胀管理在一次康复中只安排一次，不在每项处理后复测；当天稍后或下次比较范围和轮廓。

## 10. 复测

### 当场复测

重点复测：

- 原来能稳定复现的主诉动作及 0～10 分；
- 本轮处理涉及且原来异常的活动方向；
- 本轮处理涉及且原来会不适的发力动作。

复测卡只显示动作、处理前记录和新的选择，不展示开发者视角的解释。

没有评分基线时不生成数字复测。系统只比较此前已经确认的活动范围、动作表现或功能结果；后续首次找到稳定可重复的不适时，从当时开始建立评分基线。

### 不当场反复复测

- 肿胀；
- 淤青；
- 单纯按压痛范围；
- 单纯力量不足；
- 需要时间适应的训练能力。

### 结果解释

- 分数下降或活动范围改善：记录为有效方向；
- 有改善但仍未达到健侧：继续其他未重复候选；
- 无变化：降低该方向优先级，换下一候选；
- 变差：停止该方向并回到评估或降低刺激；
- 所有候选结束后仍有症状：保留所有有效方向作为居家和下次重点，不要求必须降到 0 分。

主诉动作和完全相同的活动方向共用一次记录和复测；复合动作仍保留自身功能问题，不能被单一活动度结果错误清除。

有效方向进入居家计划时不能一律写成放松：检查为紧张或松解有效时，可转成居家轻柔放松或拉伸；检查为力量或控制不足时，应转成对应训练；两类问题同时存在时分别处理。

## 11. 训练生成

训练只来自：

- 检查发现的力量或控制差距；
- 处理后确认有效的控制方向；
- 当前仍存在的活动与功能差距；
- 恢复目标和当前阶段。

不按固定数量从训练库补满卡片。

训练顺序：

```text
舒适活动与基础控制
→ 局部力量
→ 骨盆稳定与髋膝踝力传导
→ 双脚站立功能
→ 单腿、台阶和步态
→ 跑跳、落地和减速
→ 变向、疲劳和对抗
```

居家方案一般由 2～4 项真正相关内容组成，可包括有效区域的居家放松、一个局部控制动作、一个功能动作和必要的阶段管理；没有依据时宁可少，不为凑数量添加动作。

组数和个数提供起始建议，例如每组 10～15 个、3 组，并根据第一组反馈调整。动作变形或无法完成则降低数量、范围、阻力或体位；轻松且质量稳定时只进阶一个变量。

## 12. 后续康复

第二次及以后保留历史，不覆盖第一次；但不能另外建立一套“复诊专用决策流程”。界面和首次康复继续使用相同的阶段：症状信息确认、评估检查、针对性处理与复测、训练、本次总结。区别只在于上次已确认的信息自动带入，用户只确认变化。

1. 没有新症状时，沿用上次的位置、性质和主诉动作，不把性质改成“说不清”；
2. 只复查上次仍未解决的具体问题，不再询问“整体活动度怎么样”这类笼统问题；
3. 旧检查只能支持复查旧问题，不能凭旧结果自动新增上次未做过的肌肉处理；新处理必须有本次新增证据；
4. 上次有效处理可以保留，上次无效处理不原样重复；
5. 主诉在本次已经下降后，后续处理不再逐项复测主诉，剩余处理完成后统一复测一次；
6. 出现新症状或新的受伤事件时，为新问题建立支线并重新走相关评估；
7. 仍存在的活动或肌肉问题继续处理，不只做训练；
8. 根据当前能力更新训练阶段并保存本次变化。

## 13. 同一动作的多指标记录

同一次动作可同时回答多个问题，但页面只展示一张动作卡。例如膝关节绷直一次，可依次记录：

- 主动活动范围；
- 动作过程中是否不适；
- 末端轻轻发力或保持时是否偏弱、是否不适；
- 专业人员路径下的被动范围。

后台分别保存活动度、症状和力量/控制事实。活动范围偏小且会疼时必须同时保留两条事实，不能使用 `if / else` 丢掉疼痛。膝、踝、髋及其他关节均遵守此规则。
