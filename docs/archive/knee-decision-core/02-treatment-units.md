# 膝关节处理单元与影响范围

> 处理单元不是“某个异常对应一张卡片”，而是一次明确的处理及其可能影响的问题集合。

## 1. 处理单元必须包含

```text
主要部位
本轮执行内容
主要针对的问题
可能同时影响的问题
处理去重键
需要复测的标准动作
权限与资料来源
```

同一去重键在一次康复中只能执行一次。再次命中时，处理单元切换为 `retest-only`，只更新尚未确认的问题，不再重复展示处理动作：

```text
侧别 + 类型 + 标准部位/关节 + 方向
```

## 2. 首批处理单元

| 处理单元 | 触发依据 | 主要执行 | 同时可能影响 | 复测 |
| --- | --- | --- | --- | --- |
| 肿胀管理 | 明确肿胀且安全条件允许 | 低刺激肿胀管理与当天负荷调整 | 当天活动耐受 | 晚些时候或下次看肿胀轮廓，不做连续即时复测 |
| 大腿内侧与鹅足周围 | 膝内侧主诉，检查发现该区域更紧、更酸或有直接反应 | 轻柔松解明确异常区域 | 下台阶、下蹲、膝伸直症状 | 下台阶；下蹲；若伸直原本异常则一起测伸直 |
| 大腿外侧链 | 下台阶/伸膝问题，检查发现外侧紧张或伸直受限，膝内侧/外侧主诉 | 轻柔松解明确异常区域 | 下台阶、下蹲、膝伸直范围与不适 | 一轮后统一测相关动作 |
| 大腿前侧与股直肌 | 膝下或膝前主诉；屈膝末端、下蹲或下台阶时出现不适，并且检查发现大腿前侧/股直肌紧张或按压异常 | 轻柔松解明确异常区域 | 下台阶、下蹲、屈膝末端 | 只复测处理前已经异常的相关动作 |
| 膝后与小腿上端 | 屈膝或伸直受限，局部检查支持 | 轻柔松解明确紧张区域 | 膝屈曲或伸直 | 只测本轮受影响方向 |
| 膝伸直关节处理 | 专业人员确认被动伸直仍小于健侧，并已完成一组高相关肌肉处理后仍受限 | 按伸直受限方向进行低刺激关节松动 | 被动与主动伸直 | 同一次伸直记录被动、主动和原有不适 |
| 腓骨近端处理 | 专业人员确认屈膝末端问题及相应关节线索，并已完成一组高相关肌肉处理后仍受限 | 低刺激检查并改善腓骨近端活动 | 屈膝末端范围与疼痛 | 原屈膝动作一次 |
| 末端伸膝控制 | 主动伸直受限而被动接近健侧；或普通用户主动范围偏小 | 膝后轻轻下压，找回大腿前侧发力 | 主动伸直与日常支撑 | 训练完成一轮后看主动伸直，不要求一次达到力量正常 |
| 屈膝主动控制 | 主动屈膝范围偏小、被动接近健侧或普通用户无法可靠检查被动；已经完成相关位置确认但没有明确紧张区域 | 脚跟缓慢滑向臀部，再主动控制回到起点 | 主动屈膝范围与动作控制 | 训练完成一轮后再看主动范围；不反复要求用户寻找肌肉位置 |
| 髋—膝控制 | 下蹲/下台阶轨迹异常，且动作调整能改变表现 | 降阶屈髋、髋部支撑和膝方向控制 | 下蹲、台阶、步态 | 训练阶段复查动作质量 |

## 3. 主次归因

线下经常会在一个主要目标周围顺带处理相关区域。产品必须保留主次：

- `primary-supported`：主要目标有直接调整或检查证据，处理后复测改善；
- `primary-hypothesis`：主要目标明确，但只能在整组处理后看到变化；
- `group-only`：原记录无法区分主次，只能记录整组相关；
- 配合区域不单独显示为“有效处理”。

例如“大腿内侧与鹅足周围”是一个主要处理区域，不拆成内收肌、缝匠肌、股薄肌、半腱肌四张卡片。

## 4. 候选顺序

```text
安全与明显肿胀
→ 当前主诉最直接、距离最近且检查支持的区域
→ 同时影响多个未解决问题的主要区域
→ 其他未重复肌肉候选
→ 完成一组高相关肌肉处理后，被动仍受限时的专业关节处理
→ 力量和动作控制训练
```

候选顺序不是固定套餐。没有检查支持时，不因为病例中曾经有效就自动安排。

“局部检查支持”是硬门槛：只有屈膝或伸直受限、但没有确认膝后或小腿上端异常时，系统先让用户在图上补充最明显的位置，不直接生成该区域松解。

用户完成位置确认但选择“没有明确位置/说不清”后，该问题视为已经问过，不再重复询问，也不凭病例经验猜测某块肌肉。普通用户可转入对应方向的低刺激主动控制；专业人员仍按主动/被动结果决定是否需要进一步检查。

专业关节处理的开放顺序为：

```text
完成一组高相关肌肉处理
→ 统一复测这组处理影响的动作
→ 专业人员仍确认对应被动范围受限
→ 开放该方向关节松动
```

## 5. 权限

| 内容 | 普通用户 | 教练 | 康复/医疗相关人员 |
| --- | --- | --- | --- |
| 轻柔自我放松 | 显示 | 显示 | 显示 |
| 主动控制训练 | 显示 | 显示 | 显示 |
| 被动末端判断 | 不作为必填 | 有协助和基础时使用 | 使用 |
| 关节松动 | 不显示操作方法 | 提示转专业处理 | 显示已审核方法 |
| 急性结构/神经路径 | 转专业确认 | 转专业确认 | 按权限和限制处理 |
