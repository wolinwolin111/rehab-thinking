# 膝关节剩余临床审核项

以下项目会影响公开路径，需要审核；其他已确定的结构可以继续开发。

## 已确认

### 1. 大腿前侧与股直肌

当前规则：膝下/膝前主诉不能单凭位置直接生成股直肌处理；还需要屈膝、下蹲或下台阶异常，并且检查发现大腿前侧/股直肌紧张或按压异常。

确认结果：当前触发门槛可用。

### 2. 膝内侧下台阶痛的肌肉顺序

当前规则：根据检查结果在“大腿内侧与鹅足周围”和“大腿外侧链”之间排序，不固定先后。

确认结果：不固定先后，由紧张度、发力和症状调整结果决定。

### 3. 膝伸直受限的关节处理时机

当前规则：普通用户只走肌肉与主动控制；专业人员确认被动仍小于健侧时，先完成一组高相关肌肉处理，仍受限后再进入关节处理。

确认结果：先完成一组高相关肌肉处理，再考虑关节松动。

### 4. 视觉角度门槛

原门槛仅保留给膝关节侧面主动屈伸试验，不再作为全关节规则。

确认结果：不同关节、方向和测试方法使用独立门槛。踝负重背屈优先使用膝碰墙距离及其最小可检测变化；踝内翻/外翻第一版不由单摄像头输出绝对角度结论。具体配置见《视觉AI接入与判断标准》。

## 可以继续开发、暂不阻塞

- 主诉与完全相同动作合并；
- 下台阶与膝伸直保持独立；
- 同一区域只处理一次；
- 无新处理时复用刚才结果；
- 力量不足转训练，不要求手法后即时复测；
- 肿胀和压痛不在每项处理后连续复测；
- 视觉结果只生成测量事实，不直接诊断或开处理。
