# 运动康复思路助手：通用决策流程规范

版本：2026-08-02
适用对象：正在学习运动康复，或希望拓展康复业务的健身、普拉提、瑜伽及体能教练。

## 1. 产品目标

本工具不靠症状名称直接生成一套固定动作，而是还原一次真实康复的工作顺序。最终目标不是单独消除疼痛或练强某块肌肉，而是恢复用户想完成的生活、工作和运动功能。

```text
第一次康复：症状信息收集 → 评估检查 → 问题清单 → 处理与训练 → 保存记录
第二次康复：确认新症状 → 定向复查旧问题 → 调整处理 → 更新记录
```

第一次康复结束后不直接进入统一“复测步骤”。活动度和问题复现动作可以在处理后当场复测；肿胀、按压痛、力量、耐力和平衡按照各自恢复时间，在稍后或下一次康复复查。出现新症状时重新走症状信息收集和相关评估，没有新症状时不重复完整检查。

输出重点始终是四件事：

1. 做什么。
2. 怎么做。
3. 做的时候观察什么。
4. 根据结果如何调整。

## 2. 第一层：症状信息收集

症状信息收集不是固定长问卷。先让用户用自己的话描述，系统提取已经出现的信息，再只追问会改变安全分流、评估选择或恢复目标的缺口。能够确定第一批评估项目后立即结束，不要求把所有可能的问题一次问完。

### 2.1 先自由描述，再结构化确认

首屏只提供一个容易回答的入口：

> 哪里不舒服？什么时候、怎么出现的？现在主要影响什么？希望恢复到什么程度？

系统从自由描述中提取以下字段：

- 部位与侧别。
- 发生时间和发生方式。
- 主要表现与变化趋势。
- 当前受影响的生活、工作或运动功能。
- 已有影像或医学检查。
- 恢复目标层级。

一段描述可能已经覆盖多个字段，系统不能把已经获得的信息重新逐题询问。提取结果先显示在“已收集到的症状信息”中，由用户确认、修改或返回上一项。

AI可以用于理解口语、同义表达和排列追问优先级；安全分流、测试条件和训练进阶仍由结构化规则决定。

### 2.2 主诉表现与受伤背景

- 症状最集中的位置或感觉异常的关节。
- 是否存在明确受伤事件。
- 受伤时关节或身体怎样受力。
- 是否存在明显大力量冲击。
- 距离受伤过去多久。
- 从受伤到现在是好转、无变化还是继续恶化。
- 动作中的异常感觉：疼痛、酸胀、挤压、牵扯、紧绷、卡顿、弹响、麻电、无力、不稳或“说不清的不舒服”。
- 主要疼痛或不适的程度：使用 0～10 分滑条记录，0 表示“没有疼痛或不适”，10 表示“极重，无法继续当前动作”；1～3、4～6、7～9 的辅助说明分别贴近滑条前段、中段和后段显示。
- 哪个动作、动作到哪个阶段、什么负荷下出现，停止动作后多久缓解。

系统不能把主诉局限为“疼痛”。例如“抬手时肩里挤”“下蹲时膝后扯”“转头时颈部卡”“走路时脚踝不稳”，都应被整理为**动作相关异常**，并进入对应关节的活动、力量和动作检查。

系统也不能直接把“不舒服”改写成“关节活动度受限”。更准确的内部表达是：

```text
用户原话
→ 涉及的关节或身体区域
→ 诱发动作与动作阶段
→ 异常感觉类型
→ 待检查的关节活动、肌肉能力、协同模式和局部组织
```

这样既保留用户原始感受，也把它转成可检查的问题，而不是在问询阶段提前下结论。

#### 2.2.1 疼痛/不适评分的记录规则

产品使用数字评分量表（NRS）式的 0～10 分滑条。严格来说，传统 VAS 是一条 100 mm 连续线，而 0～10 的整数选择属于 NRS；前台可直接写“疼痛/不适评分（0～10）”，避免用户理解术语。[疼痛量表比较](https://www.ncbi.nlm.nih.gov/books/NBK49078/table/results.t1/)

评分必须和具体情境绑定，不能只保存一个孤立数字：

```text
症状类型：疼痛 / 酸胀 / 挤 / 扯 / 卡 / 其他不适
评分：0～10
评分情境：静息 / 某个问题复现动作 / 活动后的最明显时刻
动作条件：方向、幅度、速度、负重、扶持等
记录时间：处理前 / 处理后 / 当天稍后 / 次日 / 下次康复
```

- 首次默认记录**当前主要问题在问题复现动作中的分数**。如果动作不安全、当前做不出来或症状只在特定时段出现，就记录静息分数或最近一次出现时的分数，并明确情境。
- 用户未主动选择评分前保持“未确认”，不能预设 6 分或其他常见值。前台端点写成“0 没有疼痛或不适”“10 极重，无法继续当前动作”；1～3、4～6、7～9 的行为提示分别对齐滑条前、中、后段。
- 疼痛使用 0～10 NRS；非疼痛的挤、扯、酸、卡等可以使用相同滑条帮助本人纵向比较，但只称“该不适的程度评分”，不把它解释成已经验证的疼痛量表。
- 处理后必须在相同动作、幅度、速度、负重和扶持条件下再次评分。系统同时显示绝对变化和相对变化，例如“5 分 → 3 分，下降 2 分 / 40%”。
- 速度、幅度、负重和扶持条件只在真正复测时提示，不提前堆在首次症状收集的评分卡中。疼痛动作的结果由前后分数自动生成“保留、换下一项、停止”，不再重复询问“有没有改善”。
- 约下降 2 分或 30%可作为“出现较明确改善”的常用参考，但不是所有损伤、所有时间尺度的统一判定线，也不能单独证明处理方向正确；还要结合用户主观改善、动作质量和活动范围。该参考主要来自慢性疼痛研究。[NRS 变化的临床意义研究](https://pubmed.ncbi.nlm.nih.gov/11690728/)
- 原始分数较低时百分比容易被放大；基线为 0 时不计算改善百分比。
- 评分只用于同一个用户、同一种感觉和相同条件下的前后跟踪，不用于比较不同人的耐痛程度。
- 明显错位、远端循环或感觉异常、进行性无力等安全信号不因分数较低而降级；肿胀、压痛和力量也不为了追求分数变化而在短时间内反复刺激。

### 2.3 大力量冲击不使用专业词提问

不要直接问用户“是不是高能量机制”，应询问具体场景：

- 平地踩空或普通运动扭伤。
- 脚被固定后身体猛烈旋转。
- 从明显高度落地，受伤部位首先承受冲击。
- 车辆、高速碰撞、重物挤压或工业事故。

大力量机制不能单独决定影像需要，必须与骨点压痛、承重或使用能力、变形、感觉和症状趋势组合判断。

### 2.4 局部出血与循环异常分开

急性扭伤或拉伤后，局部紫红、青紫、黄绿色淤血以及淤血向远端移动，可以是皮下出血的演变，不应直接标记为循环异常。

循环与神经筛查应改问：

> 除了受伤区域的局部淤青，手指、脚趾或整个远端肢体是否比健侧明显苍白、灰暗或青紫，并伴随发凉、持续麻木或感觉下降？

处理规则：

- 只有局部淤青，远端温度和感觉正常：记录范围，继续评估。
- 包扎后短暂麻凉，松开后恢复：调整支撑并复测。
- 整个远端肢体持续发凉、麻木或异常变色：优先医学评估。

### 2.5 把“主要问题、恢复目标和复测动作”分开

患者不需要提出一个非常精确的目标动作。系统分别记录：

1. **当前主要问题**：为什么现在来，例如疼痛、肿胀、活动受限、不稳、麻电或动作中出现挤、扯、卡等异常感觉。
2. **恢复目标层级**：希望症状减轻、恢复正常生活、恢复一般运动、恢复某项运动，还是恢复高强度或对抗运动。
3. **当前受影响的功能**：如果用户能说出走路、台阶、抬手等受影响场景就记录；没有具体场景也允许选择“暂时说不清”。
4. **问题复现动作**：由系统或康复师根据主诉选出的检查与当场复测动作，不等同于患者的最终目标。
5. **目标所需能力**：根据恢复层级反推需要的关节活动、力量、稳定、力传导、耐力和动作模式。

问询阶段至少确认用户希望康复到哪一级，而不是默认所有人都要回归高强度运动：

1. 急性损伤不再继续肿胀，能够安全活动。
2. 疼痛、挤、扯、卡等主要不适明显减轻或达到用户可接受程度。
3. 正常完成日常生活、工作和基础家务。
4. 恢复一般训练、跑步、球类或其他运动。
5. 恢复高强度、快速、疲劳状态或有身体对抗的运动表现。

如果用户只说“恢复正常生活”，系统先按相应关节常见的生活任务选择功能检查；如果只说“以后想运动”，再补问运动类型和大致强度，不要求用户马上指出某一个不疼的动作。同样是“恢复篮球”，偶尔投篮、完成普通球局和参加高强度全场对抗需要的能力不同。

评估优先比较健患侧。对于单侧近期问题，对侧是主要个体参照；对侧也有旧伤、双侧症状或整体体能下降时，再结合伤前状态、目标任务要求和必要的常模。不能为了追求统一标准角度或力量，忽略患者原本的双侧状态。

### 2.6 动态追问、题数和结束条件

系统只追问会改变以下内容的问题：

1. 是否可以安全继续评估。
2. 下一步应该检查什么。
3. 最终需要恢复到什么层级。

典型题量控制：

- 描述较完整：补问约 2～4 项。
- 普通慢性问题：约 4～6 项。
- 急性损伤：约 5～8 项，以受伤机制、错位、承重/使用、远端感觉循环和影像为重点。

总题数是动态的。界面显示“预计还需确认约 3 项关键信息”，不显示虚假的固定总题数。每题都提供“不确定”“说不清”“暂时没有注意”和自由补充入口；不要求用户判断结构损伤、神经损伤或专业测试结论。

满足以下条件即可结束症状信息收集：

- 已知道当前主要问题。
- 已完成必要安全筛查。
- 已知道大致发生过程和变化趋势。
- 已知道当前功能影响或确认暂时没有具体功能诉求。
- 已知道恢复目标层级。
- 已能确定第一批评估项目。

结束时提示：“当前信息已经足够，可以开始第一轮评估。评估中发现新的表现时，再补充相关问题。”活动度、力量、触诊和特殊测试属于评估阶段，不塞进症状信息收集。

## 3. 第二层：优先级分流

异常表现分为三级，避免所有问题都显示“停止”。

### 3.1 一级：及时处理

- 明显错位、异常角度或开放性损伤。
- 远端肢体持续发凉、苍白或青紫，并伴感觉或运动能力下降。
- 突然完全丧失肌腱功能，并且相关完整性测试高度异常。
- 快速进展的严重症状或全身异常。

### 3.2 二级：补充影像或专业检查

- 骨性突起上清晰、集中的压痛。
- 大力量机制同时伴随完全无法负重或使用。
- 经过短期保护后仍完全无法完成基本功能。
- 症状持续不变或恶化，尤其超过预期急性反应期。
- 关节明显锁住、机械性卡住。
- 特殊测试明显支持跟腱、胫腓联合或其他重要结构问题。

系统应说明需要确认的方向，而不是笼统地说“超出边界”。例如：

- X线主要确认骨折或脱位。
- 超声可用于部分肌腱和浅表软组织。
- MRI用于需要进一步确认的韧带、肌腱、骨挫伤或关节内问题。

### 3.3 三级：可以继续康复试验

- 局部肿胀或淤青。
- 能走但跛行。
- 某方向活动受限。
- 动作中出现刺痛，但可以顺利回到起点，没有锁住。
- 软组织压痛。
- 部分承重、力量或平衡能力下降。
- 特殊测试不清楚或无人协助。

这一级通过减少组数或个数、降低动作难度或做单变量处理继续评估。

## 4. 时间、机制、功能和趋势必须组合

不能只根据某一个指标决定是否需要影像或停止康复。

推荐组合：

```text
受伤时间
× 受力机制
× 骨点压痛
× 基本功能
× 症状趋势
× 处理后的变化
```

以急性踝损伤为例：

- 能走四步但轻度跛行：优先进行承重、活动度、力量和步态评估。
- 伤后时间较短、普通低能量机制、没有骨点压痛，但因疼痛暂时不能走四步：先保护性承重和少量温和活动，12–24小时复测。
- 不能走四步，并伴骨点压痛或大力量机制：提高X线或专业检查优先级。
- 数日后仍无改善，或功能继续下降：重新检查骨性、韧带、肌腱和关节内问题。
- 较长时间仍完全无法基本承重：不能只靠肌肉松解继续试。

## 5. 第三层：动态检查

检查项目由“当前主要问题＋恢复目标”共同决定，而不是所有人完成同一套清单：主诉负责筛出第一批局部问题和高相关检查；恢复目标负责补充达到该层级必须具备的功能，再比较当前能力与目标能力之间的差距。

### 5.1 基础检查

- 局部观察：肿胀、淤青、轮廓及左右差异。
- 触诊定位：骨点、肌腹、肌腱、韧带区和弥散敏感。
- 关节活动：每个主要方向逐项与健侧比较。
- 基础力量：优先使用健患侧对比，不要求非专业用户填写精确角度或徒手肌力等级。
- 比较顺序：本人伤前状态 → 对侧表现 → 目标任务要求 → 必要的常模或标准角度。单侧近期问题以对侧为主要参照；双侧问题、对侧旧伤或整体体能下降时，不单靠对侧下结论。

### 5.2 功能检查

- 下肢：承重、走路、提踵、下蹲、台阶、平衡和专项移动。
- 上肢：抬手、摸背、拿物、推拉、拧毛巾及目标训练动作。
- 功能动作要拆开观察：需要哪些关节活动、哪些肌肉提供力量、哪些部位负责稳定，以及异常出现在动作的哪个阶段。
- “能够完成”不等于“功能正常”；还要记录挤、扯、卡、不稳、代偿、速度下降和发力顺序异常。

### 5.3 特殊测试

- 只选择与位置、机制和功能高度相关的项目。
- 明确标注单人可做或需要协助。
- 阳性结果用于提高某个方向的优先级，不单独完成疾病诊断。
- 刺痛与锁住必须分开记录。

## 6. 第四层：生成可验证假设

每个受限表现至少考虑以下来源：

1. 肿胀或局部压力。
2. 疼痛保护与肌肉紧张。
3. 肌肉力量或耐力不足。
4. 关节附属活动不足。
5. 动作控制、负荷和代偿策略。
6. 韧带、肌腱、骨性或关节内问题。
7. 神经相关因素。

系统只把它们称为“候选来源”，不能用一次测试直接写成确诊。

### 6.1 从主诉和恢复目标共同生成检查与训练

系统先通过主诉大致筛选可能的问题和对应检查，再根据恢复目标反推该层级需要哪些功能。比较当前功能与目标功能之间的差距后，才决定需要补查哪些部位、处理哪些问题、训练哪些肌肉和协同能力。

训练方案不能只从“哪里弱”生成。系统把目标层级或目标任务拆成三类能力：

1. **关节活动能力**：完成任务需要哪些关节、哪些方向和大致活动范围。
2. **肌肉力量与耐力**：哪些肌肉负责产生力量、减速、支撑或维持姿势。
3. **协同发力与动作模式**：躯干、近端和远端能否按正确顺序共同完成动作。

例如：

| 目标功能 | 需要的关节活动 | 需要的力量与稳定 | 需要的动作模式 |
|---|---|---|---|
| 下楼梯 | 踝背屈、膝屈伸、髋屈伸 | 股四头离心、臀肌、小腿和躯干稳定 | 单腿承重、重心下降、膝髋足协同 |
| 正常走路 | 髋伸展、膝伸直、踝背屈与跖屈 | 臀肌、后侧链、小腿和足弓能力 | 支撑—推进—摆动的重心转换 |
| 抬手拿高处物品 | 胸椎伸展/旋转、肩前屈外旋、肩胛活动 | 肩袖、前锯肌、菱形肌、中下斜方肌和核心 | 躯干稳定下肩胛—肱骨协同上举 |
| 推、拉或撑地 | 肩、肘、腕可用活动 | 肩胛稳定、肩袖、上臂/前臂和躯干 | 躯干—肩胛—上肢的力传导与协同发力 |

系统应找到目标功能中最低的一层能力，从那里开始训练；不能因为检查到多块肌肉较弱，就生成一串互不关联的孤立训练。

### 6.2 五级目标是包含关系，不是五套独立方案

```text
第1级 急性反应控制
→ 第2级 基础症状与关节功能
→ 第3级 日常生活与工作
→ 第4级 回归运动参与
→ 第5级 回归高强度表现或对抗
```

| 目标级别 | 用户常见表达 | 康复至少需要覆盖 | 进入下一级前重点确认 |
|---|---|---|---|
| 1. 急性反应控制 | “先别再肿”“能安全动一动” | 保护、肿胀和负荷管理、允许范围活动、必要的影像/医学确认 | 肿胀和症状趋势稳定，基础活动没有持续恶化，遵守结构愈合限制 |
| 2. 基础症状与关节功能 | “疼痛减轻”“挤和扯消失”“角度恢复” | 主要活动方向、局部刺激、基础肌肉参与和低负荷控制 | 主要异常感觉可控，目标关节具备下一阶段所需活动，训练后可恢复 |
| 3. 日常生活与工作 | “正常走路上下楼”“穿衣拿东西不受影响” | 肩胛或骨盆稳定、基础动作模式、重复日常任务和基本耐力 | 能稳定完成目标生活任务，代偿可接受，当天及次日没有持续反跳 |
| 4. 回归运动参与 | “恢复跑步、健身、球类训练” | 一般力量、单侧控制、速度和方向变化、渐进专项技术与训练量 | 完成修改后的训练，再逐步完成常规训练；专项动作和训练量可耐受 |
| 5. 回归高强度表现或对抗 | “恢复比赛、全场对抗、原来的强度” | 最大/快速力量、减速、反应、疲劳、不可预期任务、身体接触和完整训练量 | 完成接近比赛强度与时长的训练，疲劳和对抗下动作仍稳定，恢复反应可接受 |

选择第 5 级时，系统自动包含第 1—4 级；选择第 3 级时，只要求完成第 1—3 级。用户可以把低一级作为阶段目标，但不能跳过前级能力直接进入更高负荷。

第 4—5 级参考运动回归连续体：回归参与、回归运动、回归表现是逐步、按标准推进的过程，不是康复最后一次测试后的单一“通过/不通过”。具体进阶仍需结合损伤结构、愈合时间、心理准备、运动规则以及医生、治疗师、教练和用户的共同决策。[2016 Bern 回归运动共识](https://bjsm.bmj.com/content/50/14/853)

## 7. 第五层：处理—复测

### 7.1 肿胀

- 核心动作：休息时垫高患侧，在不增加疼痛范围内做 10～20 次缓慢允许方向活动；根据权限和个体情况选择支撑、加压、回流、理疗或遵医嘱外用药。
- 次级提示：可用同角度照片或肿胀边界记录基线，但记录不是处理动作本身。
- 复查：每次康复只登记一次，不在每个手法后重复显示和测试；当天稍后或下一次康复比较轮廓、边界、皮肤纹理、活动和负重趋势。

### 7.2 软组织与肌肉

- 根据疼痛位置和受限方向列出多组候选肌肉。
- 避开骨点、韧带、肌腱、淤血中心和最痛点。
- 一次只选择一组肌腹处理；前台直接写“对相关紧张肌肉做 30～60 秒轻柔松解”，肌肉名称来自当前候选标题。
- 处理后立即复测原活动方向或原功能动作。

### 7.3 刺痛

刺痛不自动终止流程，也不自动等于结构损伤。

```text
记录刺痛动作和出现位置
→ 减小动作幅度或负荷
→ 选择一组周围肌腹轻柔处理
→ 不直接按压刺痛点
→ 用同样动作和负荷复测
```

- 刺痛减轻：保留肌肉处理作为辅助，并衔接主动训练。
- 没有变化：转向关节活动、负荷、触诊和其他组织。
- 出现锁住、骨点集中痛或功能下降：停止诱发，补充评估。

### 7.4 活动受限与关节松动

各方向活动受限可能同时来自肌肉、肿胀、疼痛保护、关节活动或动作控制。

流程：

```text
确认全部受限方向
→ 按肌群去重，先做一组候选肌肉试验
→ 一次比较这组肌肉关联的全部未解决方向
→ 主动、被动都接近健侧：该方向退出后续清单，主动训练巩固
→ 被动接近健侧但主动仍较少：该方向进入对应主动控制训练
→ 有改善但被动仍小于健侧：暂存该方向，不跟下一块肌肉重复测，转对应关节松动
→ 没有变化且被动仍小于健侧：直接进入对应关节松动，不再轮换其他肌肉
```

处理不能按“一个方向一张完整卡”机械复制。系统根据拮抗肌紧张、同功能肌疼痛/紧张、力量和原动作反应，只选择一组最直接的肌肉处理，随后同时复测它可能影响的所有未解决方向。达到健侧的方向退出；被动仍不足的方向，无论有改善还是没有变化，都直接进入关节处理，不再轮换其他肌肉。范围更小、疼痛增加或出现异常阻挡时停止当前方向并重新检查。

关节松动规则：

- 由受过相应训练的人操作。
- **普通用户（general/self）不接收任何关节松动操作卡**；仅 coach/therapist 身份可见。普通用户遇到"被动仍明显受限"时，转介线下由专业人员处理。
- 先排除骨点压痛、明显不稳、持续神经血管异常和机械性锁住。
- 一次只选择一个关节和一个方向。
- 急性阶段从低等级、小幅度开始。
- 不与肌肉松解同时完成。
- 做完立即复测原方向和原功能动作。

### 7.5 训练

训练不是“症状减轻”后的附加内容，也不是“哪里弱就孤立练哪里”，而是把检查中发现的问题重新组织成完整功能。

#### 7.5.1 五层训练结构

```text
第1层：获得可用的关节活动
→ 第2层：建立局部与近端基础能力
→ 第3层：学习基础动作模式
→ 第4层：恢复生活和工作功能
→ 第5层：增加负荷、速度、耐力和运动专项
```

| 层级 | 训练目标 | 下肢举例 | 上肢举例 |
|---|---|---|---|
| 1. 可用活动 | 主动使用处理后获得的范围 | 踝四向活动、膝末端伸直、髋旋转 | 胸椎活动、肩前屈/内外旋、肘腕活动 |
| 2. 肩胛/骨盆稳定能力 | 建立局部力量、躯干与近端动态稳定 | 呼吸与腰腹核心、骨盆控制、臀腿后侧链、小腿和足部力量 | 呼吸与脊柱核心、肩胛贴胸与上回旋、肩袖、前锯肌、菱形肌和中下斜方肌 |
| 3. 基础模式 | 在低风险环境学习正确发力顺序 | 仰卧/俯卧基础练习、四点跪、站立屈髋、双腿承重 | 仰卧/侧卧肩胛控制、四点跪支撑、墙面推拉、躯干稳定下抬手 |
| 4. 生活功能 | 直接练用户想恢复的任务 | 走路、坐站、深蹲、上下楼、提物 | 穿衣、扎头发、拿高处物品、推拉、拧毛巾、撑地 |
| 5. 进阶功能 | 增加真实环境要求 | 单腿、负重、跑跳、落地、变向 | 负重推拉、过顶、快速支撑、投掷、游泳或专项动作 |

前期平躺、侧卧、俯卧和四点跪练习的价值，不只是“练某块肌肉”。这些姿势减少了承重、平衡和疼痛干扰，让用户先学会呼吸、骨盆/肩胛稳定和正确发力顺序。站立屈髋、墙面支撑等则把这种能力连接到真实动作，是基础动作模式训练，不是最终功能训练。

#### 7.5.2 上肢和下肢采用同一思路

- **上肢肩胛稳定能力**：脊柱与核心稳定、胸椎活动、肩胛贴胸与上回旋、肩袖和肩胛周围肌肉协同。记录中的菱形肌、中下斜方肌、肩胛下肌和肩袖训练属于这一层；前锯肌在记录中较少，但在完整上肢功能模型中必须补入。
- **下肢骨盆稳定与髋膝踝协同能力**：腰腹核心、骨盆控制、臀腿后侧链、小腿与足部力量，以及双腿到单腿的承重能力。
- **共同原则**：近端稳定不是把肩胛一直夹紧、下压，也不是把骨盆完全固定，而是在动作中维持合适位置、完成力传导并及时调整；局部活动也不是单独目标，而是要被下一层动作主动使用。

#### 7.5.3 每次只显示少量、有层次的动作

一次方案建议只给 2—4 个动作，并明确各自动机。急性反应或基础症状目标至少 2 个；恢复正常生活及以上至少 3 个，覆盖关节活动、基础力量/控制、承重或生活功能。当前阶段不能完成较高层动作时使用扶持、减小范围、等长、小阻力或短距离基础版，不能因为严格阶段筛选只剩一个动作。

候选维度：

1. 一个“恢复或保持关节活动”的动作。
2. 一个“补肩胛或骨盆稳定能力”的动作。
3. 一个“学习基础动作模式”的动作。
4. 条件允许时，一个“接近目标功能”的动作。

并非每个人四类都要各做一个。系统应选择当前最薄弱、最影响目标功能的层级，避免把所有检查异常都变成训练卡片。

#### 7.5.4 进阶和退阶依据

满足以下多数条件才进入下一层：

- 动作所需关节活动基本可用。
- 能按要求完成组数和个数，动作稳定，明显代偿减少。
- 训练中症状处于可接受范围，停止后能恢复。
- 当天晚些时候和第二天没有持续加重。
- 目标任务的某个组成部分已经改善。

如果动作中原来的挤、扯、卡、不稳或疼痛明显增加，应降低范围、支撑、负荷或速度；若退阶后仍无法完成，则返回活动度、力量和局部问题检查，而不是强行继续进阶。

#### 7.5.5 组数和个数由第一次尝试校准

系统可以给初始目标，但不能把“15 个 × 3 组”写成所有动作的固定处方。用户先完成第一组，再根据实际完成数、动作质量、症状和剩余能力调整。

| 训练类型 | 初始尝试 | 主要观察 |
|---|---|---|
| 活动控制、低负荷激活 | 每组 10～15 个，共 2～3 组 | 范围是否完整，是否出现明显代偿 |
| 一般力量 | 每组 8～12 个，共 2～3 组 | 最后几个是否吃力但仍可控制 |
| 局部耐力 | 每组 12～20 个，共 2～3 组 | 后半组能否维持动作质量 |
| 等长训练 | 每组保持 10～30 秒，共 2～4 组 | 是否抖动、憋气或症状增加 |
| 平衡与控制 | 按保持时间或标准完成次数 | 是否能稳定完成，不靠扶持或明显代偿 |
| 跳跃、快速和爆发训练 | 每组 3～6 个，共 3～5 组 | 速度、落地与减速质量，不追求高次数 |

初始校准规则：

```text
先完成第一组
→ 未达到目标下限就明显代偿、疼痛增加或发不上力：降低阻力、动作难度或每组个数
→ 达到目标区间，动作稳定，结束时大约还能标准完成 2～3 个：保持当前方案
→ 达到上限仍很轻松，大约还能完成 5 个以上：增加少量阻力或动作难度，不无限增加个数
```

进阶前同时看训练后和第二天反应。出现新的刺痛、不稳、麻电、肿胀增加、跛行加重或第二天仍明显高于训练前时，减少一个变量或退阶；连续两次都能完成目标区间、动作质量稳定且次日可恢复时，再增加阻力、难度、个数、组数、速度或持续时间中的一个变量。

前台表达示例：

> 建议先尝试每组 15 个，共 3 组。第一组结束后记录实际完成数、动作是否变形、症状变化，以及感觉还能再做几个，系统会调整剩余训练。

## 8. 结果调整规则

每张处理卡只记录与当前问题匹配的结果，不能为了填满页面而让所有问题都做即时复测：

- 活动度：处理后立即比较同一方向、同一姿势下的活动范围。
- 疼痛或可复现不适：在安全且适合重复的前提下，用同一动作和同一条 0～10 分滑条复测；系统根据前后分数自动生成结果，不再追加“有没有改善”按钮。
- 动作表现：只在动作可安全重复时，比较代偿、流畅度或稳定性。
- 刺痛、压痛：不为追求即时变化反复刺激；必要时在当天晚些时候、第二天或下次康复跟踪。
- 肿胀：本次康复只登记和安排一次管理，不在每个处理后重复显示；稍后或下次比较可见范围、周径或与健侧差异。
- 力量、步态、平衡：属于训练和阶段性复查指标，根据恢复目标在后续康复比较，不要求每个手法后当场改变。

通用调整：

- 改善：保留当前变量，使用主动活动或训练巩固。
- 不变：不继续加力，换一个假设。
- 加重：撤回本次变量，降低难度或补充检查。
- 即时改善后还要记录当天晚些时候和第二天反应。

### 8.1 神经信号 → 直接转介（普通用户）

普通用户描述出现麻、电、放射、针刺等神经信号时：

- 不提供任何自我处理选项（含神经滑动、神经友好活动、温和活动）。
- 直接提示"建议线下专业评估"，保存记录后结束自助流程。
- 理由：①神经自测/自处理风险高，普通人无法区分牵拉感与神经刺激；②能做的"温和活动"多涉及弯腰，对腰椎间盘/肌肉/韧带有负担；③数据中自我神经处理无有效支撑。
- 神经滑动/松动仅 coach/therapist 身份可见。文档区分"专业松动（手法，转介）"与"自我滑动（普通用户不提供）"。

### 8.2 无主诉动作时的处理导向

主诉动作不完整、不清楚、无法当场复现，或没有可参考的主诉时：

1. 不创建虚假的动作复测（`reproduction` 保持空值）。
2. 处理以评估检查发现的问题为主：活动方向受限、力量不足、局部反应、肿胀等按评估结果生成处理目标。
3. 训练围绕评估发现的问题组织，不依赖主诉动作。
4. UI 明确告知："当前没有确认会引发不适的动作，本次将以评估检查发现的问题为主进行处理和训练。"
5. 复诊时比较位置、感觉和活动度变化，不强行复现动作。

### 8.3 训练绝不安排弯腰（腰骨盆模块）

- 评估阶段：弯腰/后仰/侧屈等方向**可以检查**（只做一次，诊断性）。
- 训练阶段：**任何训练动作不得包含弯腰成分**——弯腰反复做对椎间盘、肌肉、韧带有负担，且练不到东西。
- 屈髋 ≠ 弯腰：训练中的"站立屈髋/髋铰链"是髋关节活动；若用户出现腰椎屈曲代替髋屈曲（弯腰），即动作错误，需要纠正提示。

## 10. 自由输入与影像信息的产品化规则

### 10.1 症状输入不直接生成方案

自由描述先被整理为部位、侧别、发生时间、发生方式、主要表现、变化趋势、功能影响、影像情况和恢复目标。用户确认系统理解后，系统只追问会改变安全分流、第一批评估或目标层级的缺口；不重复询问已经提取的信息，也不要求用户一次完成固定长问卷。

没有从原话中提取到的字段保持为空或“待确认”，不得默认部位、侧别、时间、机制、症状、目标、问题动作或评分。检查发现逐项进入右侧病例摘要，转换成“某方向活动受限”“某肌肉力量偏弱”“某动作会引起症状”等结果语言，主工作区不重复展开完整问题清单。

症状输入只负责确定“先查什么”，不能直接生成病名或完整训练。详细活动度、力量、触诊和特殊测试在评估阶段完成；评估发现新问题时再返回补问。AI负责语言理解和追问排序，风险规则、测试条件、健患侧比较和训练进阶由结构化规则控制。

### 10.2 不要求用户判断“有没有结构损伤”

有影像时采用逐项问答：检查类型、骨折或骨裂、骨挫伤或骨髓水肿、韧带、肌腱、积液、软骨，以及医生给出的负重或固定限制。每项允许选择“写有、明确没有、报告没提、看不懂”，避免不同医院报告格式导致的文本解析误差。

### 10.3 需要影像时先保存，再重新评估

保存本次受伤机制、压痛位置、承重、活动和特殊测试结果。取得影像后，从同一案例补充结构化影像信息，并重新走一次症状与功能评估；新方案同时服从影像结论、医生限制和当前功能，不直接沿用旧的组数、个数或训练强度。

### 10.4 骨点压痛使用组合判断

骨点压痛本身不等同于骨折，也不自动锁死全部处理。需要结合具体骨点、受伤力量、能否走四步、足中部症状、时间和变化趋势：低能量、仍能承重且持续改善时，可保护痛点并继续低风险活动；与高风险因素组合时，保存记录并优先补充影像或医学评估。

急性崴脚前台使用“要不要优先拍片确认骨头？”的问答卡，先解释目的，再询问特定骨性位置、受伤当时与现在能否走四步及影像限制；不使用让普通用户难以理解的“骨性风险组合确认”标题。

## 11. 线下记录提炼出的处理规则

资料范围：259份线下评估、治疗和反馈记录，共约1.56万行。记录格式和完整度不同，因此这里只提炼工作方法与候选关系，不把出现频率或一次即时改善当成疗效证明，也不保留个人身份信息。

### 11.1 线下处理的共同顺序

```text
找到可重复的问题表现
→ 明确受限方向、疼痛动作或功能任务
→ 选择一个候选来源
→ 只改变一个变量
→ 立即重复原动作
→ 有效：保留并用主动训练巩固
→ 无效：停止重复，换另一个来源
→ 肿胀、压痛和力量按合适时间延迟复查
```

记录中最有价值的不是某一种手法，而是“用原问题动作验证处理方向”。例如按压或屏蔽某组肌肉、调整关节位置、改变骨盆或足部支撑后，立即重复原疼痛动作；没有变化时会记录为无效并转向其他组织。

产品执行时先围绕主诉完成1～3项高度相关且不重复的处理。主诉本身等同于单一关节方向时，每轮复测同时记录主诉分数和该方向活动范围，两者共用一条问题状态，不再重复做同一个动作；主诉是下楼、深蹲、走路等复合任务时，仍需把主诉与单一活动方向分开。分数下降即记录有效方向；尚未到0分时继续尝试其他未重复候选，降到0分时可提前结束主诉试处理。主诉处理结束后，其他独立活动方向、力量、控制、肿胀和压痛问题仍继续。

首发验证阶段只开放膝关节和踝足。专项检查必须由用户明确描述的部位和症状触发，不能用系统为了分析动作而派生的“蹬地、联动”等词扩大检查范围；普通外踝崴伤默认只检查踝关节四方向、相关力量与一个高相关功能动作。

## 当前落地顺序：膝关节与踝足优先

首发验证只开放膝关节和踝足。普通用户默认走自助路径，一次只安排4～6个高相关检查，只显示可独立完成的动作、轻柔自我松解和训练；关节松动、神经松动及需要专业施力的检查不显示。非膝踝描述不得套用首发方案。

膝踝功能检查优先使用下蹲、单腿站和提踵。记录具体表现并映射后续能力：膝内偏对应髋外展和下肢对线，脚跟提前抬起对应踝背屈，单腿或提踵晃动对应平衡与稳定，小腿提踵高度差对应小腿力量和足弓控制。

麻、电、放射或感觉变化在普通用户路径直接转线下评估。刺痛补问出现范围和轻按反应；可处理周围相关肌肉，但避开刺痛中心，全部相关处理后原动作仍刺痛则转介。肿胀只按时间趋势跟踪，不在单次康复的每项处理后重复复测。

肌肉候选按区域单元保存和去重，例如“股外侧肌、阔筋膜张肌、髂胫束周围”归为“大腿外侧链”。同一区域已经处理过时，其他方向只复测，不重复显示另一串包含相同肌肉的处理卡。

### 11.2 问题到处理方法的映射

| 评估发现 | 首选试验 | 无明显变化时 | 复查时间 |
|---|---|---|---|
| 肌肉紧张、肌腹敏感 | 选择一组相关肌腹轻柔松解、拉伸或MET | 换相邻肌群、关节活动或神经方向 | 立即复测原动作 |
| 一个或多个方向活动受限 | 先轻按比较相关位置；有明确紧张位置才优先松解，没有明显差别先温和活动 | 达到健侧的方向退出；专业人员确认被动仍不足才转关节；被动到位而主动不足转该方向控制训练 | 与主诉相同的方向同时记录主诉和活动范围；其他方向分别复测 |
| 关节附属活动不足或手动对位后改善 | 单一关节、单一方向轻柔松动 | 不加大力度，改查软组织、动作控制和邻近部位 | 当场复测 |
| 神经张力或麻电、牵拉表现 | 小幅、少次数神经滑动，不停留在症状终点 | 重新确认感觉分布、相邻卡压和医学筛查 | 当场与稍后复查 |
| 肿胀、局部炎症 | 支撑、回流、舒适主动活动；有资质和设备时才加入物理因子 | 检查当天负荷和是否存在结构或循环异常 | 数小时及次日，不要求当场消失 |
| 肌力不足或萎缩 | 确认它在目标功能中承担的作用，再放入相应基础动作或功能链训练 | 降级到仰卧、侧卧、俯卧、四点跪或增加支撑，重新建立发力顺序 | 下次康复比较，不要求当场变强 |
| 步态、台阶或动作模式异常 | 先拆解完成任务需要的活动度、力量和协同，再调整重心、支撑、步幅或发力顺序 | 回查最低层能力；缺活动先补活动，缺肩胛/骨盆稳定或髋膝踝协同就降级训练，具备后再回到任务 | 当场复测任务，次日确认反应 |

没有明确诱发动作时，不建立虚假的主诉处理和动作评分变化。评估正常则只安排低刺激基础活动；评估异常则直接以活动方向或疼痛动作为目标。候选库没有匹配时保持空态，不用第一组内容兜底。

单侧活动以“接近健侧/明显小于健侧”记录。双侧问题改为左右分别完成，记录更差侧；处理先差侧后另一侧，复测只问双侧整体变轻、没变化或更重。力量偏弱不要求现场复测或进入手法队列，直接用对应肌群的仰卧或侧卧训练建立控制，再逐步进阶到坐位、站立和单腿功能。

### 11.3 踝足模块中的高频候选关系

- 背屈受限：小腿三头肌、胫骨前后肌、趾伸肌群、肿胀、距小腿关节活动和腓骨活动都作为候选，不能只写成“腓肠肌紧”。
- 外翻或外侧症状：小腿前外侧软组织、腓骨近端与远端活动、距骨和中足活动是常见排查方向。
- 足底接触异常或脚趾踩地感改变：除局部肌肉外，可比较骰骨、足舟骨和足弓支撑调整前后的步态变化。
- 走路、台阶和蹬地受限：局部处理后还要加入提踵、小腿四向力量、臀腿力量、重心转移和步态训练。
- 局部处理无效或症状反复：再检查髋、骨盆、神经张力和整体负荷；近端因素作为第二层候选，不默认所有踝痛都来自骨盆。

踝活动度处理采用“肌群—关联方向”去重：小腿后侧与前侧分别关联背屈/跖屈，小腿外侧与内侧分别关联内翻/外翻。同一肌群处理后，一次复测其全部未解决方向；方向达到健侧后从后续清单移除。主动控制则按方向分别生成：背屈训练胫骨前肌与趾伸肌协同，跖屈从比目鱼肌/腓肠肌负荷到提踵，内翻训练胫骨后肌与胫骨前肌协同，外翻训练腓骨肌群。是否松解同功能或相反功能肌肉由触诊、力量和反应试验决定，不能只按解剖名称自动执行。

### 11.4 按部位整理的评估顺序

以下顺序来自线下记录中反复出现的检查组合。它描述“先查什么”，不是要求每个人完成全部测试；前面的结果正常时可以减少后续项目，发现新症状时则返回相关评估。

#### 膝关节

```text
症状位置、肿胀和功能任务
→ 髌腱、脂肪垫、关节线、鹅足、腘窝等位置轻触诊
→ 膝伸直、弯曲和终点感觉
→ 髌骨与腓骨近端活动（受训者）
→ 踝背屈、髋内外旋
→ 股四头肌、腘绳肌、臀肌和小腿力量
→ 走路、坐站、浅蹲、台阶和单脚控制
→ 按症状选择半月板、韧带或其他特殊测试
```

- 伸直受限：先比较腘肌、腘绳肌和小腿后侧；无变化时再检查膝关节、髌骨或腓骨近端活动。
- 弯曲受限：先比较股直肌、大腿前侧和腘窝周围；无变化时再看关节活动与肿胀。
- 踝或髋处理后，必须回到原膝部动作复测；原动作没变就不保留这个来源。
- 力量不足：先确认它如何影响走路、上下楼或下蹲，再组合股四头肌、腘绳肌、臀肌、小腿与核心，而不是逐块肌肉各生成一个孤立动作。
- 训练进阶：先获得膝和踝髋所需活动，建立骨盆稳定、臀腿后侧链和小腿力量；再从站立屈髋、坐站和浅蹲进入低台阶，随后增加髋膝踝协同、下肢离心控制、单脚任务和目标功能。

#### 踝关节与足部

```text
受伤机制、时间、肿胀、淤青、承重和远端感觉
→ 骨点与软组织触诊
→ 背屈、跖屈、内翻、外翻
→ 距骨、腓骨近端/远端、骰骨、跟骨（受训者）
→ 背屈、跖屈、内翻、外翻力量
→ 神经或稳定性特殊测试（按症状选择）
→ 重心转移、步态、提踵、平衡、台阶和下蹲
```

- 关节活动检查必须作为候选来源：只有轻柔调整后原受限方向或原功能动作改变，才保留该位置。
- 走路和楼梯恢复不能只训练踝部。先恢复踝足活动和小腿/足部能力；进入步态时立即检查并训练骨盆稳定、髋伸展、膝承重缓冲、踝向前滚动、小腿蹬地和重心转换，建立髋膝踝的连续力传导；随后再进入单腿、台阶和跑跳。
- 肿胀与压痛使用延迟观察；活动方向和疼痛动作使用当场复测。

#### 肩关节

```text
疼痛动作、侧睡和上肢麻电表现
→ 肩胛位置、肱骨位置和局部压痛
→ 前屈、后伸、外展、水平内收、内旋、外旋
→ 颈椎、胸椎、第一肋骨和前臂旋转
→ 肩袖内外旋、外展和肩胛控制
→ 举手、摸后脑、手到腰后、拧毛巾和墙面推
→ 按症状选择肩袖、肩锁或神经相关测试
```

- 活动受限时，胸大肌、胸小肌、背阔肌、上斜方肌、肩胛提肌、肩袖和后侧关节囊都是候选，不能一次全部处理。
- 肩胛或胸椎调整只有在原抬手动作改变时才保留。
- 上肢训练先恢复胸椎与肩关节可用活动，再建立躯干、肩胛稳定和肩袖协同；肩胛周围重点包括前锯肌、菱形肌、中下斜方肌和肩胛下肌，之后再从墙面/四点跪等基础模式逐级恢复推、拉、支撑和过顶动作中的力传导。

#### 腰背与髋部

```text
疼痛位置、久坐/弯腰/后伸行为和腿部症状
→ 腰背六方向活动
→ 髋内外旋、屈髋和骨盆动作
→ 腰椎分节活动（受训者）
→ 有腿部症状时检查神经张力
→ 臀肌、髋后伸、腘绳肌和躯干控制
→ 坐站、步行、弯腰取物和髋铰链
```

- 先用一处肌肉、髋部或骨盆调整做反应试验；腰部任务没有改变时不继续扩大处理范围。
- 神经表现与普通牵拉感分开记录，小幅、少次数滑动后同时观察感觉分布和功能。
- 呼吸、臀桥、鸟狗、蚌式开合用于建立躯干与骨盆稳定、臀腿后侧链能力；站立屈髋与髋铰链用于学习基础动作模式；具备这些能力后再进入走路、提物、深蹲、台阶、单腿和跑跳等目标功能。

### 11.5 肩胛—肩袖—上肢功能训练进阶

外部资料与线下记录的方向一致：肩胛不能只做静态“夹紧”，肩袖也不能停在弹力带内外旋。训练应把胸椎、核心、肩胛、肱骨、肘腕和目标动作重新连接。

| 阶段 | 主要能力 | 动作候选 | 进阶观察 |
|---|---|---|---|
| 1. 活动与感觉 | 胸椎活动、肩主动范围、感受肩胛在胸廓上的移动 | 胸椎伸展/翻书、辅助或主动抬手、肩胛时钟、仰卧前锯肌前伸、低负荷肩袖等长 | 原抬手动作没有持续加重；能减少明显耸肩或躯干代偿 |
| 2. 肩胛稳定与肩袖力量 | 前锯肌、菱形肌、中下斜方肌、肩胛下肌和肩袖共同控制 | 侧卧外旋、弹力带内外旋、俯卧伸展/W/T/Y、划船、前伸或动态环抱、墙面滑动 | 可完成规定组数与个数，肩胛不是僵硬夹紧，也不过度外跑或耸肩 |
| 3. 动态稳定 | 开链与闭链下保持肩胛—肱骨协同 | 墙面球稳定、墙面推加、四点跪支撑/交替抗扰、弹力带 PNF、逐级支撑 | 扰动、推拉或抬手时保持控制，症状和次日反应可接受 |
| 4. 日常与一般运动 | 把稳定能力放入推、拉、提、举和过顶 | 提物、负重行走、桌面到地面推撑、过顶推、划船、游泳或投掷的低速分解 | 完成目标日常任务或修改后的运动训练 |
| 5. 高速与对抗 | 快速力量、减速、反应、疲劳和接触耐受 | 90/90 快速内外旋、球类接抛、药球、快速支撑/推撑、专项投掷、受控扰动与逐步对抗 | 接近目标训练量和速度；疲劳或不可预期情况下仍能控制；完成渐进专项过程 |

关键纠偏：

- 肩胛稳定不等于始终“后缩下沉并夹住”。抬手需要上回旋、后倾和贴胸，训练目标是动态控制。
- 不因无症状的翼状或所谓肩胛运动异常就自动训练；先确认肩胛辅助或训练是否能改变问题复现动作。
- 开链或闭链并非固定先后，需根据损伤类型、阶段和耐受选择；终末训练必须服从用户的工作或运动要求。
- 术后或明确结构损伤必须服从医生限制，不能套用普通肩痛进阶时间。

依据包括：2022 Bern 肩部共识建议把肩胛放入整体动力链，并强调末期动作由运动需求决定；2025 年肩袖肌腱病临床指南支持主动康复和回归功能/运动；肩胛定向训练随机试验提示其可改善部分肩痛与功能，但不能把任何一种肩胛练习当成通用处方。[2022 Bern 肩部共识](https://pubmed.ncbi.nlm.nih.gov/34972489/) · [2025 肩袖肌腱病临床指南](https://pubmed.ncbi.nlm.nih.gov/40165544/) · [肩胛稳定训练随机试验](https://pubmed.ncbi.nlm.nih.gov/38376127/)

Mass General 的青少年投掷肩方案提供了一条可参考的能力进阶：早期肩胛和活动控制，随后肩袖/肩胛力量、闭链与抗扰，再到 90/90、快速球类和投掷。本文只借用其进阶结构，不能直接照搬该方案的周数和儿童投掷项目标准。[Mass General 肩部阶段方案](https://www.massgeneral.org/assets/mgh/pdf/orthopaedics/sports-medicine/physical-therapy/pediatric-little-leage-shoulder-protocol.pdf)

### 11.6 腕手—前臂—支撑与握持训练进阶

腕手稳定同样不能停在屈腕、伸腕和握力。它需要关节位置感、屈伸肌共同收缩、前臂旋转控制、肩肘的力传导，以及抓、提、拧、撑和专项动作。

| 阶段 | 主要能力 | 动作候选 | 进阶观察 |
|---|---|---|---|
| 1. 症状与活动 | 控制刺激，恢复腕屈伸、桡尺偏和旋前旋后 | 舒适范围主动活动、手指/拇指活动、轻握放、必要支撑 | 肿胀和异常感觉趋势稳定；活动后没有持续反跳 |
| 2. 肌肉重建与位置感 | 屈肌、伸肌、桡尺偏肌群和旋前旋后肌群低负荷共同收缩 | 中立位等长、轻握力、前臂有支撑的旋前旋后、闭眼/视觉反馈的关节位置复现 | 能在中立位稳定发力，不靠肘肩大幅代偿 |
| 3. 力量与神经肌肉控制 | 向心、慢放、协同稳定和轻扰动 | 抗阻屈伸/桡尺偏、旋前旋后、抓握、轻负荷绕环或飞镖轨迹、弹力棒/球的小幅扰动 | 多方向发力平稳，抓握、旋拧和轻提物可控 |
| 4. 负重与日常功能 | 上肢闭链稳定和真实物品操作 | 墙面—桌面—四点跪渐进支撑，提、搬、拧、推、拉、键鼠或工具操作 | 支撑和目标日常任务可重复完成，次日无持续加重 |
| 5. 高速与专项 | 速度、反应、力量传递和训练量 | 快速球翻转/接抛、药球、动态支撑、球拍/球杆/格斗或器械专项动作 | 完成渐进训练量、速度和专项姿势；需要对抗者再加入扰动和接触 |

分支规则：

- TFCC/远端尺桡关节不稳、舟月不稳、ECU 肌腱问题等需要不同稳定方向；未确认结构时只使用通用低负荷共同收缩和功能进阶，不能自动指定某一条肌腱为主要稳定器。
- 已确认 TFCC/远端尺桡关节问题时，可由专业人员评估 ECU、旋前方肌和关节位置感；已确认舟月不稳时则是另一套肌肉与关节策略。
- 急性摔撑、持续肿胀、明显不稳或负重痛没有改善时，先补充结构检查，不直接进入高负荷撑地。

一项 TFCC 感觉运动康复项目采用“疼痛控制—肌肉重建与关节觉—神经肌肉训练—动作正常化和功能”四阶段，10 名完成者中功能、握力和疼痛改善较明显，但没有对照组，适合做低置信度结构参考而非疗效保证。[TFCC 感觉运动康复研究](https://pubmed.ncbi.nlm.nih.gov/37904835/)

ECU 运动员康复案例及综述支持从无痛主动活动、等长和渐进阻力，进入离心、握力、负重、扰动和专项训练；其个案结果不能直接推广到所有尺侧腕痛。[ECU 运动员康复综述与案例](https://pmc.ncbi.nlm.nih.gov/articles/PMC11067837/) · [Mass General 腕肘基础力量动作](https://www.massgeneral.org/assets/MGH/pdf/orthopaedics/sports-medicine/physical-therapy/mass-general-wrist-and-elbow-strengthening-exercises.pdf)

### 11.7 其余区域的训练进阶

以下内容用于补足线下记录里训练较少的环节。它不是“按病名发一套动作”，而是按检查结果，从当前最低能力逐级回到目标任务；一次只选 2～4 个最相关动作，并以组数、个数或完成任务的次数表达。

#### 颈部与胸椎

```text
舒适主动活动与颈深屈肌控制
→ 颈肩和胸椎耐力
→ 上肢动作中的颈肩协调
→ 久坐、驾驶、转头、抬举等日常任务
→ 需要时进入运动速度、碰撞准备或长时间耐力
```

- 颈部动作不是只做“缩下巴”：还要按实际缺口加入旋转/侧屈控制、肩胛与胸椎协同、逐渐延长的姿势耐力。
- 胸椎活动只在它能改变转头、抬手或转体主诉时进入优先方案；外部研究仅支持它可作为部分机械性颈痛的辅助选择，不能把胸椎僵硬当成所有颈肩问题的原因。
- 工作或训练回归时，从低时长、低速度、低负重开始，逐步增加持续时间、上肢负荷与不可预期干扰。

颈痛指南支持把颈部、肩胛胸廓区的神经肌肉控制、力量、耐力、伸展和有氧活动组合使用；胸椎自我活动的小样本试验只说明它可作为候选辅助，需要用问题复现动作验证。[颈痛临床指南](https://pubmed.ncbi.nlm.nih.gov/28666405/) · [胸椎活动随机试验](https://pubmed.ncbi.nlm.nih.gov/35799408/)

#### 肘关节

```text
屈伸与旋前旋后可用范围
→ 腕伸/屈、前臂旋转和握力的低负荷控制
→ 向心、等长与慢放力量
→ 提、拧、推、拉和支撑
→ 投掷、球拍、工具或高重复工作负荷
```

- 外侧肘痛若检查支持腕伸肌负荷相关，可从等长、向心或慢放抗阻中选择耐受最好的一种，再逐渐增加阻力、杠杆、握力和任务速度。
- 肩胛稳定只在肩胛/肩部也存在能力缺口时补充，不自动给每位肘痛用户。
- 术后、急性韧带损伤、明显神经症状或关节不稳使用独立限制，不能套用肌腱负荷路径。

2022 外侧肘痛指南支持亚急性或慢性病例采用腕伸肌等长、向心和/或离心抗阻，并在高需求工作或运动中分阶段恢复压力、力量、耐力与动作控制；肩胛训练属于发现近端缺口后的附加项。[外侧肘痛临床指南](https://www.orthopt.org/uploads/content_files/files/lucado_et_al_2022_lateral_elbow_pain_and_muscle_function_impairments.pdf)

#### 腰椎与髋部

```text
症状允许的腰髋活动与深层躯干控制
→ 躯干、臀肌与后侧链力量耐力
→ 屈髋、坐站、蹲和步行等基础模式
→ 搬提、台阶、单腿支撑、跑步等目标任务
→ 高负荷、速度、旋转、跳跃或专项耐力
```

- 腰痛不固定只练“核心”。检查可决定采用方向偏好活动、躯干控制、一般力量、步行/有氧或多模式训练；手法只作主动训练的辅助。
- 髋部训练同时考虑活动度、臀肌/内收肌/屈伸旋转力量、骨盆—下肢控制和原疼痛动作；只有某种动作提示能稳定改善主诉，才保留为动作纠正重点。
- 从卧位进入站立不是按时间自动升级，而是看能否控制骨盆和躯干、完成规定次数、并且当日与次日反应可接受。

2021 腰痛指南支持慢性腰痛使用躯干力量/耐力、深层激活、多模式、一般或有氧训练，并根据运动控制缺口选择动作控制训练；2023 非关节炎性髋痛指南支持按查体缺口处理活动、力量和体能，并可对引发日常症状的动作做模式训练。[腰痛临床指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC10508241/) · [髋痛临床指南](https://www.orthopt.org/uploads/content_files/files/Hip_Pain_and_Movement_Dysfunction_revision_2023.pdf)

#### 膝关节

```text
伸屈活动与股四头肌重新参与
→ 骨盆稳定、臀肌、股四头肌、腘绳肌、小腿和足部能力
→ 坐站、浅蹲、步态和双腿承重
→ 台阶、分腿、单腿控制与减速
→ 跑、跳、落地、变向和专项训练量
```

- 膝前/髌股相关表现若同时存在髋和膝力量缺口，优先采用髋与膝联合训练，而不是只练股四头肌或只纠正髌骨。
- 走跑跳回归前应确认所需伸屈活动、稳定步态、单腿任务和落地控制；具体测试阈值随损伤/术式和目标运动变化，不在通用模块写死。
- 跑步、速度敏捷和跳跃可以借用医院方案的阶段结构，但不能照搬术后周数；只增加一个变量，如距离、速度、方向或外部负重。

髌股疼痛指南与国际共识支持髋和膝联合训练；Mass General 的膝力量、跑步、速度敏捷与跳跃方案可作为功能阶段示例。[髌股疼痛临床指南](https://www.orthopt.org/content/s/patellofemoral-pain-2019) · [髌股疼痛共识](https://bjsm.bmj.com/content/52/18/1170) · [Mass General 运动康复方案库](https://www.massgeneral.org/orthopaedics/sports-medicine/physical-therapy/sports-rehab-protocols)

#### 踝关节与足

```text
肿胀趋势与四方向可用活动
→ 小腿、胫骨前后肌、腓骨肌和足部控制
→ 步态、提踵、足弓控制和平衡
→ 单腿台阶、减速与方向转换
→ 跑跳、落地、变向和专项负荷
```

- 急性外侧踝扭伤在保护条件下逐步承重，并按检查加入主动活动、拉伸、神经肌肉、姿势和平衡训练；手法与回流用于帮助肿胀、活动和步态，不替代训练。
- 跟腱中段负荷问题若已由专业评估支持，采用渐进肌腱负荷，而不是只做拉伸；足底/足跟问题则根据足踝髋力量、活动和步态缺口组合训练，不能与跟腱路径混用。
- 跑跳前要先补足小腿推蹬、单腿提踵、动态平衡和落地控制；护具不能单独替代神经肌肉训练。

2021 踝扭伤指南支持结构化活动、拉伸、神经肌肉和姿势/平衡训练；2024 跟腱指南支持可耐受的渐进肌腱负荷作为中段跟腱病的一线训练，但该结论不自动适用于急性撕裂或未明确的后踝痛。[踝扭伤临床指南](https://www.orthopt.org/uploads/content_files/files/jospt.2021.0302.pdf) · [跟腱临床指南](https://www.orthopt.org/uploads/content_files/files/Achilles_Pain_revision_2024.pdf) · [足底痛临床指南](https://www.orthopt.org/content/s/heel-pain-plantar-fasciitis-revision-2023)

### 11.8 后续每次康复的生成规则

后续康复不能只生成训练。每个仍存在的问题分别进入以下分支：

- 活动受限、疼痛动作：生成“记录相同动作的评分与条件 → 本次处理 → 同条件复测评分和动作 → 根据结果调整”。
- 肿胀、按压痛：继续低风险处理，并安排稍后或次日观察。
- 力量、耐力、平衡：先确定它们限制了目标功能的哪一环，再生成“肩胛/骨盆稳定与局部力量 → 基础模式 → 目标任务”的分级训练，不要求当场改善。
- 已改善：减少被动处理，用主动活动和训练巩固。
- 处理后不变：不重复加力，换一个候选来源。
- 变差或连续两次同一方向无效：返回相关评估，检查遗漏因素或补充医学信息。

后续每次康复仍要保持阶段分离：肿胀只显示一次时间性管理提醒，主动控制和力量放在训练阶段，即时处理队列只保留能够用原动作或对应活动范围当场验证的内容。复诊结束分数取本次最后一次已保存复测，不使用进入下一页时清空的评分草稿；训练结束后再完成一次整体主诉复测。

### 11.5 测试报告后的补充规则

- 肌肉松解后在同一轮做8～10次低刺激主动活动，随后统一复测，不把它拆成新的处理或训练步骤。
- 恢复目标是终点，不是当前训练阶段。急性期、评分较高、活动受限或全部试处理无即时变化时，只安排1～2组低刺激基础活动。
- 具体症状位置优先于“走路、下楼”等常见动作匹配候选组。外踝主诉不能因为提到走路就自动带入足底、足趾或整只脚的处理路径。
- 同一肌肉区域用解剖区域单元去重。组合区域拆成前、外、后等实际单元，跨次康复不重复上一节已经无效的同一区域；上一节有效的方向可以复查后继续。
- 第二次及以后康复在“存在可重复、可比较的单侧主诉动作”时保存本次复查分数、处理后分数和训练后整体复测分数；无固定动作或双侧场景只保存症状趋势和动作质量，不伪造数字变化。没有改善时禁用训练进阶，并提示线下重新评估的条件。
- 描述未识别部位、同时提到左右两侧、既往影像或医生限制时必须要求确认或带入分流，不能静默猜测。
- 冰敷不列为急性踝扭伤必做项；用户已经做过时仅记录并提供中性证据说明。

## 12. 首发版流程锁定与复测补充

- 下楼、蹲起、走路、跑跳属于复合功能动作，不与某一个ROM方向自动合并；单一关节动作才可合并。
- 普通用户出现多项7～9分疼痛、多个动作因疼痛无法完成时，停止自助处理并锁定后续导航。
- 主诉分数只由主诉复测更新；活动度复查、肿胀跟踪和“前面已处理过”的复测不能覆盖主诉分数。
- 一轮处理后先复测主诉，再复测本轮涉及且原本异常的活动方向；单侧已接近健侧、双侧已接近较好一侧或原有活动范围的方向退出，仍不足的方向进入下一种不重复处理。
- 多项一起处理后改善，记录为“本轮相关内容”，不把结果强行归因给每一项。
- 训练后加重：先退阶；退阶仍加重：停止并列入下次复查。

## 13. 信息字段必须进入决策

- 主诉动作不明确时，禁止生成“尚未确认”的伪主诉目标；以评估发现的活动、力量和功能问题建立处理与训练队列。
- 力量不足与无力、不稳同类；清楚刺痛与动作刺痛进入低刺激路径；麻或电感进入线下评估路径。
- 影像提示骨折、韧带或肌腱结构异常时，先取得医生允许和限制范围；医生限制不能被系统方案覆盖。
- 起始、末端和全过程症状必须改变训练版本；角度数值只记录，不单独决定升阶或分流。
- 多选字段只有用户明确完成后才算收集完成；历史记录必须一并保存该完成状态，恢复记录时不得重新锁死流程。
