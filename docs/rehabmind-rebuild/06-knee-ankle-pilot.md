# 06 膝踝首批建设内容

当前代码使用情况、输入到后续动作的逐项对应及四条验收用例，统一记录在 [膝关节与踝足首批决策追踪表](./work/01-knee-ankle-decision-trace.md)。本文件继续说明覆盖范围，不再把仅存在于文档中的候选写成已经落地。

## 1. 首批不是两个孤立关节

首批建设单位为“下肢症状区域 + 膝踝功能模块”。症状入口从大腿到足部，不开放骨盆、臀部、腹股沟和髋关节。膝和踝主诉经常出现在大腿、小腿、足底或脚背，也可能通过髋膝踝联动互相影响。

髋膝踝协同、臀腿力量和骨盆稳定可以作为膝踝功能训练出现，但不生成独立的骨盆或髋关节评估、处理与复测路径。

## 2. 首批症状区域

### 大腿

- 前侧；
- 后侧；
- 内侧；
- 外侧。

### 膝周围

- 膝前和髌骨周围；
- 膝内侧和关节线附近；
- 膝外侧；
- 膝后和腘窝；
- 位置说不清。

### 小腿

- 前侧；
- 后侧；
- 内侧；
- 外侧；
- 上、中、下段可选。

### 踝足

- 踝前、踝后；
- 内踝、外踝；
- 足跟、足底、足弓；
- 脚背、足内侧、足外侧；
- 前脚掌和足趾。

## 3. 主诉类型

首批至少支持：

- 疼痛、酸、胀、紧、牵扯；
- 刺痛或局部敏感；
- 卡、挤、夹或活动不顺；
- 肿胀和外伤后淤青；
- 无力、不稳、打软腿；
- 麻、电、放射或感觉变化；
- 动作不舒服但说不清性质；
- 没有固定诱发动作；
- 多位置、多关节、双侧问题。

## 4. 膝功能模块

### 基础检查

- 主动伸直范围与不适；
- 主动屈曲范围与不适；
- 专业模式下的被动范围和末端表现；
- 相关区域紧张比较；
- 股四头肌、腘绳肌、臀肌、内收/鹅足相关肌群、小腿和足弓控制按主诉调用；
- 发力动作出现不适时记录位置、性质和分数。

### 功能检查

- 坐站和下蹲；
- 上下台阶；
- 走路和承重；
- 单腿站；
- 根据目标加入跑步、落地和减速。

### 候选方向

不能按疼痛位置固定肌肉。候选池需要覆盖并去重：

- 大腿前侧；
- 大腿后侧；
- 大腿内侧与鹅足相关区域；
- 大腿外侧链；
- 腘窝和小腿后侧；
- 髋部与骨盆稳定；
- 小腿、踝背屈与足弓；
- 膝关节活动和专业关节处理；
- 股四头肌离心控制以及髋膝踝联动。

例如“下楼膝内侧不适”只能触发多个候选方向，实际检查和处理反应决定保留哪些方向。

## 5. 踝足功能模块

### 急性扭伤确认

- 发生时间和机制；
- 明显错位或异常轮廓；
- 肿胀和淤青具体位置；
- 必要的骨性风险组合；
- 当前承重与步行能力；
- 是否已有影像和医生限制。

不能因为单独骨点压痛或无法走路就永久锁死。结合时间、机制、其他表现和影像状态决定：继续轻柔检查、保存等待影像或进入医学评估。

### 活动检查

- 脚背向上勾（背屈）；
- 脚背向下压（跖屈）；
- 脚掌向内转（内翻）；
- 脚掌向外转（外翻）。

只有足趾、前脚掌或相关功能主诉时才加入脚趾检查，普通崴脚不默认把足趾全部检查一遍。

### 力量与控制

- 背屈、跖屈、内翻、外翻均有对应控制路径；
- 根据受限方向考虑同功能肌和相反方向肌肉的放松、激活与训练；
- 足弓控制；
- 双脚和单腿提踵；
- 单腿稳定、步态和台阶；
- 髋膝踝联动。

### 肌肉区域去重

- 小腿前侧；
- 小腿后侧；
- 小腿内侧；
- 小腿外侧；
- 足底与足弓；
- 与具体主诉相关的局部区域。

同一区域可能影响多个活动方向，只处理一次。完成后合并去重，只复测处理前已经异常且与本轮直接相关的方向；原本正常和需要时间变化的问题不加入即时复测。

## 6. 处理顺序

1. 必要的急性阶段管理只出现一次；
2. 优先处理当前主诉最相关方向；
3. 先处理最直接且尚未处理的相关肌肉区域或主动控制；
4. 第一项高相关处理后，复测主诉和涉及的全部异常方向；
5. 主诉改善后，后续只复测会改变下一步的相关活动范围；
6. 未达到健侧或目标范围时继续未重复候选；
7. 专业模式下被动仍受限，可进入对应关节松动；
8. 本轮处理结束后统一复测一次主诉；
9. 主诉处理结束后继续解决剩余独立异常；
10. 力量和动作质量问题移交训练。

## 7. 训练阶梯

### 急性反应和基础症状阶段

- 舒适范围主动活动；
- 基础等长或低负荷控制；
- 肿胀的时间性管理；
- 保留安全承重能力。

### 正常生活阶段

- 站立屈髋；
- 坐站、浅蹲；
- 双脚提踵；
- 足弓控制；
- 单腿站；
- 步态和台阶；
- 髋膝踝联动。

### 一般运动阶段

- 分腿蹲和台阶进阶；
- 单腿提踵；
- 动态平衡；
- 跑步准备；
- 落地和低强度减速。

### 高强度和对抗阶段

- 单腿跳与连续跳；
- 多方向落地；
- 加速、减速和变向；
- 疲劳条件下控制；
- 专项动作和接触准备。

高阶目标包含低阶能力，不能直接跳到跑跳训练。

## 8. 首批内容审核表

每个位置、检查、处理和训练都要确认：

- 用户是否看得懂；
- 普通用户是否能独立完成；
- 是否真正由主诉或检查触发；
- 不知道时是否有替代路径；
- 是否与其他项目重复；
- 是否有线下病例或其他来源；
- 复测对象是否明确；
- 后续训练是否回到实际功能。
