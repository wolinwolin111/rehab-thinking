# 踝足首批决策关系

> 状态：2026-08-13 临床审核通过。位置先触发检查，检查结果再触发处理。

## 检查与处理顺序

1. 所有非足趾局部的踝关节不适固定优先检查背屈、外翻，不受病程或用户是否记得崴脚影响；主诉明确涉及跖屈或内翻时再补查对应方向。四方向结果统一保存，功能动作和特殊检查只能追加，不能替换基础方向；足趾局部问题不强制套用踝关节筛查。
2. 一般先查小腿前侧发力肌群，再查小腿后侧；明确内踝、足弓内侧或小腿内侧主诉时，提高胫骨后肌相关检查优先级。
3. 同一肌肉区域处理一次，统一复测它关联且尚未解决的方向与主诉，不按方向重复处理同一区域。
4. 普通用户只做主动动作和低负荷控制；胫骨后肌屏蔽、被动检查和关节松动只对专业人员开放。

## 候选关系

| 编号 | 触发 | 决策 |
| --- | --- | --- |
| ANKLE-R01 | 扭伤后肿胀随走路或跑量变化 | 当次只显示一次肿胀管理；记录位置和负荷，晚些时候或次日复查，不逐手法复测 |
| ANKLE-R02 | 踝部主诉或扭伤 | 四方向分别保存；没有足趾症状、受伤或功能线索时不加入足趾检查；未知结果不锁死流程 |
| ANKLE-R03 | 主动范围小、专业检查的被动范围接近健侧 | 转对应方向主动控制；普通用户缺少被动检查时先走低风险肌肉与控制路径 |
| ANKLE-R04 | 内踝、足弓内侧、小腿内侧主诉 | 优先检查内翻活动、内翻发力和足弓控制；检查支持时胫骨后肌升为高优先级候选，仅凭位置不能直接处理 |
| ANKLE-R05 | 多个踝足或小腿区域连续处理后活动痛减轻 | 保存组合有效，并在下次优先单独验证最可能的主要目标；不能把所有组员分别标记有效 |
| ANKLE-R06 | 活动范围改善，但方向控制、提踵或小腿能力仍差 | 进入局部方向控制→小腿力量→髋后侧链→髋膝踝联动→步态/台阶→跑跳的训练链；力量不即时复测 |
| ANKLE-R07 | 找不到发力、明显代偿或无法完成动作 | 降低体位、范围、阻力或复杂度；稳定完成且症状不递增后一次只进阶一个变量 |

## 胫骨后肌权限

- 普通用户：主动内翻、足弓轻收、低负荷内翻控制；不自行深压内踝后方。
- 专业人员：可用触诊或屏蔽试验观察原足底牵扯、内翻或承重症状是否改变。
- 有效后根据紧张与力量结果分别转为居家放松或训练；无变化则降低优先级。

## 功能与训练

- 功能检查按承重→走路→提踵→单腿站逐级出现，不一次全部询问。
- 局部方向控制后，必须补小腿三头肌、臀桥/单腿臀桥、站立屈髋和髋膝踝联动，之后再进入正式步态纠正、台阶、单腿和跑跳。
- 肿胀不是即时复测指标；提高负荷后明显反弹时退回负荷管理。
