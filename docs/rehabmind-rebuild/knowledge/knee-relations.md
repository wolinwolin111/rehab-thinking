# 膝关节首批决策关系

> 状态：2026-08-13 临床审核通过。病例关系用于候选排序，不等于病因诊断。

## 通用顺序

1. 主诉动作优先，膝伸直优先于屈曲；只在当前膝路径内完成必要检查。
2. 普通用户与专业人员都先处理高相关肌肉区域；一组肌肉处理后统一复测主诉和活动度。
3. 主诉改善但活动度仍未接近健侧，或肌肉处理变化不足时，专业人员才进入关节松动。
4. 力量与控制问题进入训练，不要求手法后即时改善。
5. 踝足或骨盆不常规展开；只有既往相关受伤、膝局部路径效果不明显或一次简单调整能改变膝症状时，增加一个关联检查。独立症状另开评估。

## 候选关系

| 编号 | 触发 | 决策 |
| --- | --- | --- |
| KNEE-R01 | 只有弹响或刮擦声，没有明确当前动作 | 先确认可复现动作及疼痛、肿胀、卡住、打软；仍说不清时只观察伸屈和一个常用动作，不生成完整处理链 |
| KNEE-R02 | 屈膝末端痛，已完成必要安全确认 | 先处理检查到的膝后或小腿上端肌肉；变化不足且活动仍受限时，专业人员检查腓骨近端 |
| KNEE-R03 | 下蹲刮擦感且腓骨活动有依据 | 膝主诉按腓骨近端→远端，踝主诉按远端→近端；连续处理后只复测一次原动作 |
| KNEE-R04 | 下蹲或下楼存在膝轨迹异常，轻度外侧支持能改变症状 | 进入髋—膝控制训练；不能仅凭一次调整诊断髋外展肌无力 |
| KNEE-R05 | 无明显急性肿胀的承重胀感，膝局部常规路径效果不明显，或小腿前侧发力也异常 | 胫骨前肌＋趾长伸肌控制作为低优先级组合候选；不推广到一般膝痛，不解释为炎症消退 |
| KNEE-R06 | 伸膝刮擦感且检查指向小腿前外侧 | 趾长伸肌方向可做松解或主动发力；两种手段属于同一目标，复测原伸膝动作 |
| KNEE-R07 | 膝内侧痛或下楼痛 | 默认顺序为鹅足→内收肌→外侧链；若症状调整明确支持某区域，可覆盖默认顺序 |
| KNEE-R08 | 屈髋时膝扭感，髋或骨盆调整能改变原动作 | 作为关联问题进入降阶屈髋和支撑控制；明显形成独立髋/骨盆主诉时另开评估 |
| KNEE-R09 | 膝伸直受限或绷直不适 | 第一组股直肌＋外侧链，第二组腘肌＋小腿三头肌；每组后统一复测；腓骨近端单独验证 |
| KNEE-R10 | 髌骨下缘痛或下楼痛 | 默认加入股直肌/大腿前侧快速检查；异常时优先处理股直肌，变化不足再看股内外侧肌力量平衡 |

## 后侧链检查

- 普通用户先做双腿臀桥；稳定后左右分别做单腿臀桥，比较高度、保持、骨盆偏移、抽筋和腰部代偿。
- 异常只记录为“后侧链力量或控制不足”，不能直接写成腘绳肌无力。
- 只有屈膝发力不适、膝后症状、大腿后侧无力或需要进一步定位时，补做坐姿脚跟向后拖的5秒等长检查。
- 急性拉伤、双腿臀桥不能稳定完成或单腿动作明显诱发症状时，不做单腿版本。

## 归因与复诊

- 多区域连续处理后有效，先保存组合有效，并记录主要目标、配合目标和未区分目标。
- 本次不为拆分归因增加频繁复测；下次优先单独验证最可能的主要目标。
- 单独有效则提升该目标可信度；无效再加入配合目标或恢复组合。多个病例重复出现后才提高全局优先级。
