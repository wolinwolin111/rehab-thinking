# 候选知识关系

本目录保存从匿名病例和外部资料提炼出的可追溯关系。正式可执行内容已经合并到[膝踝首发知识库](../../knee-ankle-pilot-knowledge.md)；这里不再重复描述页面流程。

| 文件 | 用途 |
| --- | --- |
| [关系字段与证据](./relation-schema.md) | 关系数据格式、证据等级和状态 |
| [膝关系](./knee-relations.md) | 已审核膝候选与调用顺序 |
| [踝足关系](./ankle-foot-relations.md) | 已审核踝足候选与调用顺序 |
| [跨区域关系](./cross-region-relations.md) | 尚未开放的多区域与边界候选 |
| [调用规则](./decision-call-rules.md) | 冲突、未知和角色权限 |
| [审核登记](./relation-review-register.md) | 当前审核结论与保留项 |

关系必须说明触发条件、主要目标、配合目标、复测对象、无效处理、角色权限和来源。病例中的整组处理只能先记录“组合有效”；不能把改善分别归因于每个成员，也不能把单次反应写成长期疗效。
