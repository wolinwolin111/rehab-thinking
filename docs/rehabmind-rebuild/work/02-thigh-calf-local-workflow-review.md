# 大腿与小腿独立主诉流程

> 状态：已接入正式产品；一次只评估一个主要问题。桌面端首批范围为大腿局部、膝、小腿局部和踝足。

## 1. 区域边界

| 用户位置 | 决策区域 | 首轮只调用 |
| --- | --- | --- |
| 大腿前/后/内/外侧 | `thigh-local` | 对应肌群拉长、发力和一个高相关功能 |
| 膝周围 | `knee` | 膝伸屈、主诉动作及有证据支持的局部检查 |
| 小腿前/后/内/外侧 | `calf-local` | 对应踝方向、发力和走路/提踵 |
| 踝与足 | `ankle-foot` | 踝足模块 |

肿胀、压痛和麻电位置是当前问题的附属信息，不建立第二主诉。独立的相邻关节症状另开评估。

## 2. 大腿局部

| 位置 | 检查 | 早期训练 | 进阶 |
| --- | --- | --- | --- |
| 前侧 | 前侧拉长、伸膝发力、坐站 | 大腿绷紧、坐姿伸膝 | 台阶、跑步 |
| 后侧 | 后侧拉长、后侧链功能、走路 | 双腿臀桥→单腿臀桥 | 站立屈髋、台阶、加速 |
| 内侧 | 内收肌拉长、夹腿发力、走路 | 夹枕、侧向收腿 | 坐站、侧移、变向 |
| 外侧 | 外侧活动负荷、外展发力、走路 | 侧向抬腿、单腿骨盆稳定 | 侧向迈步、台阶、变向 |

- 普通用户优先做整体后侧链检查；只有屈膝发力或膝后/大腿后侧定位需要时，补脚跟后拉。
- 急性内收肌问题先看局部位置、拉长、轻柔夹腿发力、走路和淤青；复发、局部处理无效或目标为运动回归时，再补臀肌、骨盆稳定和躯干协同。
- 不把“髋后侧链不足导致内收肌代偿”直接写成病因，只保存为待验证贡献因素。

## 3. 小腿局部

| 位置 | 检查 | 早期训练 | 进阶 |
| --- | --- | --- | --- |
| 前侧 | 勾脚活动、勾脚发力、走路 | 主动勾脚 | 脚跟走、台阶、跑跳 |
| 后侧 | 伸膝/微屈膝拉长、提踵、走路 | 坐姿提踵 | 站姿/单腿提踵、跑跳 |
| 内侧 | 内翻活动、内翻发力、足弓、走路 | 小幅内翻、足弓保持 | 提踵、单腿、跑跳 |
| 外侧 | 外翻活动、外翻发力、走路 | 小幅外翻 | 单腿稳定、变向、落地 |

- 小腿局部不自动打开踝四方向。
- 明确内侧主诉提高胫骨后肌检查优先级，但必须由检查结果触发处理。
- 急性拉伤不做慢跑测试；单侧无外伤肿热红痛需增加医学确认。

## 4. 三类常见决策

| 情况 | 当次处理 | 复测 | 后续 |
| --- | --- | --- | --- |
| 急性拉伤 | 保护损伤中心；专业人员可轻柔处理周边紧张区域 | 不追求即时消肿或压痛变化 | 无症状或低症状等长→全范围控制→功能负荷 |
| 非急性紧张/动作不适 | 当前区域只处理一次 | 统一复测相关活动和主诉，不测力量 | 按异常与目标逐级训练 |
| 单纯力量不足 | 不生成手法 | 不即时反复测力量 | 直接进入控制和功能训练 |

急性前几天不按摩、重压或强拉损伤中心；冰敷不是默认处理，也不宣称促进消肿或愈合。用户若只为短时镇痛选择冷敷，应提示短时、保护皮肤且不要因麻木提前增加活动。

## 5. 撞伤、骨应力与肌腱路径

### 肌肉撞伤

直接撞击 → 标记肿胀/淤青 → 排除快速肿大、凹陷、麻木、循环异常和严重功能障碍 → 保护及可耐受活动 → 等长发力 → 力量和功能。急性期不按摩血肿中心，肿胀按时间复查。

### 疑似骨应力

局限骨性疼痛或跑跳负荷增加后疼痛 → 判断走路痛、静息/夜间痛、趋势和高风险位置 → 必要时医学/影像确认 → 调整冲击负荷 → 检查训练量、恢复营养及少量相关功能缺口 → 无痛走路和负荷测试 → 走跑交替，先距离后速度。

踝活动、小腿力量、足弓、单腿稳定、髋/骨盆和髋膝踝联动只记录为“可能增加局部负荷的功能缺口”，不能直接写成病因。疑似骨应力问题不进入普通肌肉松解路径。

### 肌腱负荷

先排突然弹响、凹陷和主动功能突然丧失 → 确认肌腱位置及当前可耐受负荷 → 调整训练量 → 等长 → 双侧慢速动态 → 单侧力量 → 快速力量/储能 → 跑跳回归。按原负荷动作和次日反应调整，不以反复松解为主。

## 6. 复诊与归因

1. 快速复查局部活动、发力和一个高相关功能。
2. 上次有效且仍异常时继续；上次无效或加重时不自动重复。
3. 组合有效先保存组内主目标、配合目标和未区分目标；下次单独验证最可能的主要目标。
4. 力量变化留到后续康复比较；本次做过松解，训练页不重复松解。
5. 新麻电或新受伤回到症状收集，不沿用旧处理链。
