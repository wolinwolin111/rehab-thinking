本目录保存正式规则背后的资料、病例、审核和实施记录，不再单独维护一套“下一版产品规范”。当前产品规则统一从[文档中心](../README.md)进入。

## 当前实施原则

- 线下记录提供候选来源、检查顺序、反应实验和训练进阶经验，不作为固定处方。
- 先用单一主要问题跑通大腿、膝、小腿和踝足；相邻区域只在有明确线索时增加一个检查。
- 多主诉联合处理、语言模型和视觉 AI 保留接口，当前不控制公开流程。
- 当前关系已经完成临床审核的，写回正式知识库并同步代码；未审核关系只留在内部资料中。
- 实施状态以自动测试和[首发场景验收](../pilot-scenario-coverage.md)为准，不在多个文件重复维护进度清单。
