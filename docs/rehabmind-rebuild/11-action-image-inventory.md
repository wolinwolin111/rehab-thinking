## 当前结论

- 旧版半写实素材、普通用户/专业人员双版本和图内标注方案不再作为目标素材。
- 新方案只生成普通用户会自行完成的轻 Q 版成年人物动作图。
- 专业检查与专业操作不生成图片。
- 复合训练拆成单动作图片并在页面组合，避免重复生图和复杂拼图。
- 当前需要生成 44 张唯一素材：10 张自主放松、15 张基础控制、10 张常用功能训练、5 张功能进阶、4 张体位与抗阻变体。

状态只使用四种：`待生成`、`待审核`、`通过`、`需重做`。

## 生成与接入顺序

1. 先生成 R01～R10 和 T01～T15，确认人物、服装、配色、肌肉高亮与动作准确性。
2. 同一人物风格稳定后，再生成 T16～T25。
3. 最后生成容易出现肢体错误的 T26～T30，以及需要核对弹力带固定方向和不同体位的 T31～T34。
4. 每张原图先标记为 `待审核`，按提示词文档的交付检查逐张审查。
5. 审核通过后统一转为 WebP 或受控 PNG，并压缩尺寸、写入素材 manifest。
6. 页面只建立“业务动作 ID → 素材 ID”映射，知识规则和组件不得直接拼接文件名。
7. 图片加载失败时必须保留文字步骤，不能阻断康复流程。

完整可复制提示词见 [RehabMind 膝踝动作图片生成提示词](./10-knee-ankle-action-image-prompts.md)。
