## 3. 证据来源等级

### A：原文明确且有当场或明确后续反应

例如：处理后原动作减轻、活动范围改变、明确写出无效或变差。可用于建立处理实验关系。

若原文还包含按住、屏蔽、发力、拉伸或动作调整后立即变化，可以同时记录主要处理目标；同次其他区域作为配合处理。

### B：原文明确记录检查、处理和跨次症状变化

可以建立纵向关系，但不能把所有同期处理都归因于最终改善。

### C：原文只记录检查或处理，没有复测

只能作为候选来源或检查习惯，不能写成有效规则。

### D：整理者根据处理或训练反推的问题

必须保留 `inferred` 标记，只能进入研究候选池。不能因为“做了某块肌肉”就确认该肌肉一定异常。

### E：外部解剖、教材或指南

用于校验肌肉功能、安全和通用原则，必须记录具体来源；不能覆盖线下病例原文。

## 4. 对既有整理规则的纠正

既有 `康复记录整理\README.md` 包含两条对产品来说过强的假设：

1. “处理的肌肉/关节一定有问题”；
2. “客户持续复诊可以作为处理有效的验证”。

新结构调整为：

- 处理过某区域，只能证明康复师当时选择了这个候选方向；
- 没有处理前检查或处理后反应，不能确认它就是问题；
- 复诊可以说明存在持续服务关系和纵向资料价值，不能单独证明某次处理有效；
- 只有明确的当场复测、明确后续反馈或排除其他解释后，才能提高关系可信度。

同时需要保留康复师的处理主次：有直接定位证据或原文明确主要目标时，不能因为同次还处理了其他相关区域，就把主要方向降成无法归因；配合区域只记录参与，不分别标记有效。
