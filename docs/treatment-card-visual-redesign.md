# 针对性处理卡片设计规范

> 状态：界面参考。现行页面流程以[产品规范](./rehabmind-complete-product-design.md)为准。

## 用户此刻需要知道什么

进入处理步骤后，页面只回答四件事：

1. 目前要改善什么问题。
2. 处理哪个部位。
3. 现在做什么。
4. 具体怎么做。

风险判断、处理权限、选择原因、候选序号和复测规则不放进处理卡。需要复测时，等用户完成处理后再单独显示。

## 桌面端

```text
要改善的问题：踝背屈受限

┌──────────────────┬──────────────────────────┐
│ 处理部位          │ 现在做                   │
│ 小腿后侧          │ 小腿后侧肌群轻柔松解      │
│ 腓肠肌、比目鱼肌   │                          │
├──────────────────┴──────────────────────────┤
│ 怎么做                                       │
│ 找到紧张或牵扯明显的区域，轻柔松解30～60秒。  │
└─────────────────────────────────────────────┘

                         [处理完成，开始复测]
```

## 文案规则

- 使用“现在做”，不用“执行内容”“处理候选”。
- 操作句以动词开头，一句话说完。
- 只保留动作、部位、组数、个数或时间等执行信息。
- 不在处理卡中显示“为什么这样做”“系统如何判断”“处理后如何分流”。
- 不显示小字号的权限、类型和流程提醒。
- 复测页只显示要重新做的动作、要选择的结果和下一步。
- 活动度复测标题统一为“与健侧比较”，不使用“相关方向”。
- 关节处理写“根据受限方向做关节松动”，不使用“根据剩余方向选择低刺激松动”。
- 处理页保留“返回评估检查”，允许修正前面的检查结果。

## 颜色

- 处理部位：青绿色。
- 肌肉松解：蓝色。
- 关节松动：琥珀色。
- 主动控制：绿色。
- 肿胀管理：紫色。
- 神经滑动：玫紫色。

颜色仅用于帮助快速识别处理类型，不增加额外文字说明。

## 响应式

- 桌面端：处理部位和现在做左右排列。
- 手机端：处理部位、现在做、怎么做上下排列。
- 正文不小于16px；核心动作标题不小于24px。
- 页面不能横向滚动。

## 第二次及以后康复

第二次、第三次以及后续康复继续使用同一套精简卡片，不恢复候选列表、权限说明或流程解释。

## 阶段切换提醒

评估、处理、训练之间不直接跳页。每个阶段完成后先显示一张独立提醒页：

- 症状信息收集完毕：接下来开始评估检查。
- 评估检查完成：接下来开始处理并复测。
- 处理复测完成：接下来开始训练。
- 本次康复完成：接下来开始复盘。

提醒页只保留阶段编号、大标题、一句下一步说明、返回和继续按钮。桌面端使用大面积留白与清晰阶段编号，手机端改为纵向排列；不显示处理候选、检查结果、风险解释或右侧流程说明。

页面一次只显示一项处理：

1. 要改善的问题。
2. 处理部位。
3. 现在做什么。
4. 怎么做。
5. “处理完成，开始复测”按钮；进入复测后隐藏刚完成的处理卡。

处理完成后的复测顺序固定为：

1. **先复测主诉**：重新完成原来最不舒服的动作，记录处理前和处理后的0～10分。

> 更新：新的复测评分条不再预填处理前分数。处理前分数单独显示作参考，新横条从“—/10”开始。活动度复测同时询问范围和不适感；复测标题只显示动作名称。处理页顶部使用横向问题清单概览本次主诉和检查异常。
2. **再复测相关活动度**：同一块肌肉影响的所有受限方向一次比较，并分别记录主动、被动与健侧的差距。
3. **最后决定下一步**：综合记录，但活动度路径不能被主诉分数替代。

分流规则：

- 主诉是否改善都要继续完成相关活动度复测。
- 主诉没变、活动度改善：保留活动度变化，继续按剩余差距处理。
- 主诉改善、被动活动仍小于健侧：进入对应方向的关节松动。
- 被动接近健侧、主动仍较少：进入对应方向的主动控制训练。
- 主动和被动都接近健侧：该方向退出处理，进入巩固训练。
- 主诉加重，或活动范围更小、更痛：停止当前处理，返回复查。

同一项肌肉处理只做一次，随后一次复测它关联的全部方向；已经接近健侧的方向不再重复出现。

### 内容数据要求

- 每个肌肉松解、关节松动和主动控制项目必须绑定它会影响的活动方向。
- 已明确配置活动方向时直接使用配置；旧内容暂时可通过相同功能标签匹配对应方向。
- 正式内容库必须逐关节补齐明确映射，不能只靠处理标题猜测复测项目。
- 后续康复继续沿用上一次尚未达到健侧的方向，不重新展示已经解决的方向。
