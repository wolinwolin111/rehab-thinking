| 区域 | 记录能支持的内容 | 当前成熟度 |

## 二、九个区域统一使用的流程

症状信息收集先让用户自由描述，再提取部位、侧别、发生过程、主要表现、功能影响、影像情况和恢复目标。已获得的信息不重复问，只动态补充会改变安全分流、第一批评估或目标层级的缺口；信息足够进入评估后立即结束，不要求患者完成固定长问卷，也不要求患者必须说出一个精确目标动作。

1. **固定当前主要问题和问题复现动作**：主诉可以是疼、挤、扯、卡、酸、麻、无力或不稳；“向右转头疼”“走路时脚踝不稳”等动作可作为复测基线。用户只说“恢复正常生活”或“以后想运动”时，由系统根据部位、主诉和目标层级选择代表性功能检查。
2. **检查本关节每个方向**：先主动与健侧比较；受限时，在安全条件下再由专业人员比较被动活动。
3. **按主动—被动结果分流**：
   - 主动受限、被动接近健侧：优先考虑疼痛抑制、力量或动作控制。
   - 主动和被动都受限：肌肉与关节都进入候选；先处理相关肌肉，改善不足再考虑专业关节松动。
4. **根据位置和异常感觉缩小候选**：酸、紧、牵扯优先看肌肉张力与发力；挤、卡、弹响还要检查关节活动、对位和动作协同；刺、胀、局部热痛优先看近期负荷、肿胀和局部刺激；麻、电、放射感进入神经相关检查；无力、不稳则进入力量、稳定和动作模式检查。
5. **一次只改变一个主要变量**：肌肉支持、肩胛调整、关节位置调整或神经滑动后，立刻重复同一问题复现动作。
6. **主要问题改善后再补齐查体问题**：处理仍存在的活动受限和相关肌肉问题，然后从恢复目标反推训练，而不是只把所有弱肌列出来。
7. **有效肌肉方向不等于一律放松**：
   - 紧张但力量接近健侧：可安排轻柔放松或拉伸。
   - 力量弱：以强化为主。
   - 又紧又弱：现场先获得可用活动范围，居家重点训练主动控制。
   - 未测试力量：不自动生成“放松”或“强化”结论。
8. **量化当前主要问题**：用 0～10 分记录疼痛；挤、扯、酸、卡等不适也可用相同滑条做个人跟踪。每个分数都要绑定静息或同一个问题复现动作，并保存动作幅度、速度、负重和扶持条件。处理后在相同条件下复测，显示前后分数、变化分数和百分比；不能用低分覆盖安全信号，也不能把不同感觉或不同动作的分数直接比较。

### 训练方案统一按功能反推

系统先用主诉确定局部排查方向，再用恢复目标确定需要补充哪些功能检查；比较当前能力和目标能力之间的差距后，再拆成三类能力：

1. 完成任务需要的关节活动。
2. 产生力量、支撑和减速所需的肌肉能力。
3. 脊柱、近端关节与远端关节的协同发力模式。

训练按照下面的顺序组织：

```text
可用关节活动
→ 肩胛稳定或骨盆—髋膝踝协同能力
→ 仰卧/俯卧/四点跪/站立等基础动作模式
→ 走路、台阶、举手、推拉等生活功能
→ 负重、速度、耐力和运动专项
```

- 平躺、侧卧、俯卧练习主要用于减少负荷和代偿，学习正确发力，不只是孤立强化某块肌肉。
- 站立屈髋、墙面支撑、四点跪等用于把基础能力连接到完整动作模式。
- 上肢基础是脊柱核心、胸椎、肩胛稳定和肩袖协同；肩胛周围包括前锯肌、菱形肌、中下斜方肌和肩胛下肌等。
- 下肢基础是腰腹核心、骨盆稳定、臀腿后侧链、小腿与足部力量，以及髋膝踝从双腿到单腿的协同承重和力传导。
- 肩胛稳定不是始终夹紧下压，骨盆稳定也不是完全固定；目标是在动作中维持合适位置、完成力传导并及时调整。
- 一次只给少量有层次的动作：保持活动、补肩胛或骨盆稳定、练模式、接近目标功能；不把每个弱项都做成一张训练卡。

### 先确认用户要恢复到哪一级

五级目标是一条包含式路径：

| 级别 | 用户目标 | 本阶段重点 |
| --- | --- | --- |
| 1. 急性反应控制 | 不再继续肿胀，能够安全活动 | 保护、肿胀和负荷管理、允许范围活动、必要的影像/医学确认 |
| 2. 基础症状与关节功能 | 疼、挤、扯、卡等明显减轻或达到可接受程度 | 主要活动方向、局部刺激、基础肌肉参与和低负荷控制 |
| 3. 日常生活与工作 | 正常走路、上下楼、穿衣、拿物和工作 | 肩胛或骨盆稳定、基础动作模式、重复任务和基本耐力 |
| 4. 回归运动 | 恢复跑步、健身、球类或其他训练 | 一般力量、单侧控制、速度、方向变化和渐进专项训练量 |
| 5. 高强度表现或对抗 | 恢复比赛、全场对抗或原有强度 | 快速力量、减速、反应、疲劳、不可预期任务、接触和完整训练量 |

选择第 5 级时自动包含第 1—4 级，不能从疼痛减轻直接跳到对抗。选择第 3 级时，系统只要求完成第 1—3 级。每一级都按能力标准进阶，不只看康复次数或经过了几周。

健患侧比较优先于一股脑追求标准角度和力量。参考顺序为“本人伤前状态 → 对侧表现 → 目标任务要求 → 必要常模”；对侧存在旧伤、双侧症状或整体能力下降时，不能只看双侧相同。

组数和个数采用“初始目标＋第一组反馈”校准。低负荷动作可先尝试每组 10～15 个、共 2～3 组，一般力量可先尝试每组 8～12 个、共 2～3 组；未达到下限就明显代偿或症状增加时降低难度、阻力或个数，达到区间且还能标准完成约 2～3 个时维持，达到上限仍很轻松时增加少量阻力或难度。训练后及第二天没有持续加重，并连续两次完成，才增加一个变量。

世界卫生组织把康复目标放在恢复功能和有意义的活动；运动回归共识把后半段定义为“回归参与—回归运动—回归表现”的连续过程。这里把两者合并成面向普通用户更容易理解的五级路径。[WHO 康复说明](https://www.who.int/news-room/questions-and-answers/item/rehabilitation) · [2016 Bern 回归运动共识](https://bjsm.bmj.com/content/50/14/853)

### “不舒服”如何进入评估

系统保留用户原话，同时生成一个“动作相关异常”，不能直接把它改写成关节活动度受限：

```text
原话：“抬手时肩里面有点挤”
→ 区域：肩关节/肩胛带
→ 动作：抬手；记录开始出现挤感的阶段
→ 待检查：肩前屈与外旋、肩胛上回旋、肱骨位置、胸椎和相关肌肉
→ 调整后重复同一抬手动作
```

如果关节各方向活动正常，但原动作仍有挤、扯、卡或不稳，就继续检查负荷、关节附属活动、局部组织和协同模式，不能因为“角度正常”就结束。

## 三、颈部模块

### 1. 记录里反复出现的组合

- 转头或侧屈受限，同时出现上斜方肌、肩胛提肌、斜角肌、枕下肌紧张。
- 后仰后侧酸胀或挤压，伴上颈椎活动与胸椎伸展不足。
- 颈肩不适伴头痛、头晕、手麻或电击感。
- 第一肋位置、胸椎旋转、肩胛位置和上肢神经张力与颈部症状同时出现。
- 记录中枕下肌、斜角肌、第一肋、正中神经和尺神经相关处理反复出现；它们只能作为高频候选，不能直接当作病因。

### 2. 按主诉进入检查

| 主诉 | 先做什么 | 重点候选 | 用什么复测 |
| --- | --- | --- | --- |
| 向一侧转头疼或转不动 | 左右旋转、左右侧屈、屈曲、后伸逐项比较；观察耸肩和躯干代偿 | 上斜方肌、肩胛提肌、斜角肌、枕下肌；上颈椎/颈椎活动；同侧第一肋；胸椎旋转 | 相同坐姿、相同转头方向和速度 |
| 后仰酸胀或后侧挤 | 比较主动与专业被动后伸，并检查胸椎伸展 | 枕下肌、颈后肌群、上颈椎与胸椎 | 后仰时角度及原酸胀/挤压感 |
| 低头后侧牵扯 | 屈曲、旋转、肩胛位置和胸椎活动 | 肩胛提肌、上斜方肌、颈胸段后侧肌群 | 低头或原工作姿势 |
| 颈肩连到头痛 | 先问头痛变化、突然性、视物异常、恶心、外伤等，再查颈部活动 | 枕下肌、胸锁乳突肌、上斜方肌和上颈椎只是候选 | 颈部原动作；头痛不适合被短时间反复诱发 |
| 手麻、电感、向手指放射 | 记录范围、感觉和肌力；检查颈部、第一肋、胸肌和正中/尺/桡神经相关动作 | 神经通路受刺激、第一肋/胸肌空间、颈部相关因素 | 麻木范围和轻柔原动作，不拉到症状末端 |

### 3. 处理顺序

1. 先选择与受限方向和触诊结果最相关的一组肌肉，处理后复测转头、低头或后仰。
2. 肌肉处理后被动活动仍明显受限，才由专业人员考虑颈椎、上颈椎、胸椎或第一肋松动。
3. 有上肢麻电感时，使用温和神经滑动，不做强牵拉；同时复查肩关节，避免把肩部问题都归到颈椎。
4. 记录中出现“颈椎快速松动”，但这不适合成为面向教练或学习者的自助指令；产品只保留为“转专业人员处理”。

### 4. 训练与居家

| 阶段 | 做什么 | 观察什么 |
| --- | --- | --- |
| 活动与控制 | 舒适范围各方向主动活动、颈深屈肌、胸椎伸展/旋转 | 转头或低头不持续加重，躯干代偿减少 |
| 颈肩耐力 | 低负荷颈部等长、肩胛胸廓控制、轻推拉 | 能完成规定组数与个数，不靠耸肩或憋气 |
| 动作协同 | 四点跪支撑、鸟狗、上肢动作中保持颈肩控制 | 抬手、推拉时颈肩位置稳定且症状可接受 |
| 日常/工作 | 久坐、驾驶、转头、看屏幕、提物的渐进暴露 | 逐步延长持续时间，次日没有持续反跳 |
| 高需求 | 速度、疲劳、视线转换和专项上肢任务 | 接近目标训练量后仍能控制 |

- 如果主要问题是肌肉紧而力量正常，居家可保留轻柔活动或拉伸；如果颈部或肩胛控制弱，则不应只反复放松。
- 颈痛指南支持颈部与肩胛胸廓区的神经肌肉控制、力量、耐力及有氧活动组合；胸椎训练只有能改变转头、抬手或转体主诉时才进入重点。[颈痛临床指南](https://pubmed.ncbi.nlm.nih.gov/28666405/) · [胸椎活动随机试验](https://pubmed.ncbi.nlm.nih.gov/35799408/)

### 5. 需要单独提醒

进行性无力、持续感觉减退、步态或手部精细动作明显变差、严重或突发头痛头晕，以及外伤后出现神经症状，不进入普通“松解后复测”路径。

## 四、肩关节与肩胛模块

### 1. 记录里反复出现的组合

- 前屈、外展、扎头发、摸背、游泳、投篮、发球或俯卧撑时疼痛、夹挤、弹响或无力。
- 肩内旋受限、后侧关节囊紧、肱骨前移与肩胛位置异常共同出现。
- 肩袖、胸大/小肌、上斜方肌、肩胛提肌、肩胛下肌和肱二头肌长头经常成为候选。
- 调整肩胛、第一肋、肱骨位置或前臂旋转后，原肩部动作发生变化的记录不止一次。
- 训练记录集中在肩胛后缩下沉、菱形肌、中下斜方肌、肩胛下肌、肩袖和支撑控制；系统性的过头负荷进阶仍不足。

### 2. 按主诉位置、动作和异常感觉缩小候选

| 主诉位置/动作 | 优先检查 | 常见候选，不是诊断 | 现场反应实验 |
| --- | --- | --- | --- |
| 肩前方疼或弹响，前举/内收内旋诱发 | 前屈、外展、内外旋；肱骨位置；肩胛与前臂旋转 | 肱二头肌长头、胸大/小肌、肩胛下肌、前侧关节囊、肱骨前移 | 调整肩胛或肱骨位置、处理单一肌肉后重复原动作 |
| 肩上方或外侧抬手痛 | 主动/被动前屈外展；肩胛上回旋和贴胸；空罐等少量相关测试 | 肩袖、三角肌、上斜方肌、后侧关节囊、肩胛控制 | 肩胛辅助、肱骨头调整后复测抬手 |
| 肩后侧牵扯，前屈或转肩时出现 | 内旋、水平内收、前屈；后侧触诊 | 后侧关节囊、肩袖、背阔肌、肩胛提肌与肩胛控制 | 处理后侧组织或稳定肩胛后复测 |
| 摸背或内旋受限 | 主动与被动内旋、肩胛代偿、前臂旋转 | 后侧关节囊、肩袖、胸肌、背阔肌、肩胛位置 | 在不改变躯干代偿的前提下复测摸背高度 |
| 扎头发或放下手时夹/疼 | 抬起和下放分开观察；外旋、肩胛控制和第一肋 | 肩袖、小圆肌等局部候选、上斜方肌、第一肋、肩胛控制 | 屏蔽一个候选或调整第一肋/肩胛后重复下放动作 |
| 俯卧撑、夹胸或推时手臂酸、发不上力 | 肩胛贴胸与后缩稳定、肩袖、肱二头肌/肱桡肌、手腕支撑 | 肩胛稳定不足、上臂/前臂肌肉负荷、腕手支撑 | 先稳定肩胛再做相同推/夹动作 |
| 手麻或向手臂放射 | 颈部、第一肋、胸肌和上肢神经相关动作 | 颈肩—神经路径，不只看肩袖 | 轻柔复测麻木范围和原上肢动作 |

### 3. 评估顺序

1. 先确认本次最想改善的主诉和恢复目标；用户只说“恢复正常生活”或“以后想运动”也可以。
2. 根据主诉选择一个安全、容易重复的问题复现动作，作为现场处理前后的比较动作；它不等于用户必须明确说出的恢复目标。
3. 检查主动前屈、后伸、外展、内旋、外旋，受限方向再比较被动。
4. 观察肩胛静态位置，以及抬臂时上回旋、后倾和贴胸。
5. 触诊肩袖、肱二头肌长头、胸肌、三角肌和肩胛周围肌肉。
6. 只选择与当前主诉高度相关的特殊测试；阳性用于增加结构排查优先级，不直接给出病名。
7. 做一次肩胛、肱骨或相关肌肉调整，马上复测问题复现动作。
8. 必要时补查颈椎、胸椎、第一肋、前臂旋转和上肢神经。

### 4. 处理顺序

- 主动受限而被动接近健侧：先解决疼痛抑制，并训练肩袖、三角肌或肩胛控制。
- 主动、被动都受限：先处理与受限方向相符的肩袖、胸肌、背阔肌或肩胛周围肌肉；改善不足，再由专业人员做肩关节或关节囊松动。
- 主诉明显改善后，再补齐仍存在的内外旋、前屈和肩胛控制问题。
- 任何一个处理方向都要回到举手、扎头发、摸背、推、游泳或投篮等原动作验证。

### 5. 训练与居家选择

肩关节训练不是把肩袖、菱形肌或前锯肌分别练一遍，而是让脊柱—肩胛—肱骨—肘腕重新协同：

| 层级 | 重点 | 动作方向 |
| --- | --- | --- |
| 可用活动 | 胸椎伸展/旋转、肩前屈和内外旋、肘腕活动 | 胸椎活动、疼痛允许范围的肩主动活动 |
| 肩胛与肩袖稳定 | 核心稳定、肩胛贴胸与上回旋、肩袖协同 | 颈深屈肌、前锯肌、菱形肌、中下斜方肌、肩胛下肌与肩袖的低负荷协同 |
| 基础模式 | 躯干稳定下完成上举、推、拉和支撑 | 仰卧/侧卧控制、墙面抬手或推、四点跪支撑、低负荷拉回 |
| 日常功能 | 把基础模式放回真实动作 | 拿高处物品、穿衣、扎头发、摸背、拧毛巾、提物 |
| 进阶功能 | 增加阻力、速度、耐力和过顶要求 | 桌面到地面支撑、负重推拉、卧推、游泳、投掷或专项 |

- 肩袖或外旋弱只是整体能力中的一个缺口，需要和肩胛、胸椎及核心一起放回抬手或推拉动作。
- 抬臂时上斜方肌代偿明显，应降低高度或负荷，先学肩胛—肱骨协同，再逐渐上举。
- 支撑时肩胛外跑，可按墙面支撑—桌面支撑—四点跪—更高负荷支撑进阶。
- 活动度改善但主动达不到，应在新范围内练主动控制，而不是继续堆叠被动松动。
- 肩胛稳定不是把肩胛始终夹紧和下压；上举过程中需要上回旋、后倾和贴胸，目标是动态控制。
- 面向高强度投掷、游泳或对抗运动时，还要增加 90/90 位控制、快速向心与慢放、球类接抛、扰动、疲劳和专项训练量。

记录中前锯肌和完整肩袖负荷进阶较少，因此这里用肩部共识、临床指南和医院阶段方案补足进阶结构。外部方案用于补充“怎样逐级增加能力”，不覆盖本次评估，也不直接照搬术后或青少年方案的周数。

- 2022 Bern 肩部共识：肩胛应放在整体动力链中处理，终末练习由运动需求决定；不建议把无症状肩胛运动异常当成普筛结论。[共识原文](https://pubmed.ncbi.nlm.nih.gov/34972489/)
- 2025 肩袖肌腱病临床指南：主动康复应覆盖疼痛、功能和回归运动。[指南摘要](https://pubmed.ncbi.nlm.nih.gov/40165544/)
- Mass General 阶段方案提供了“肩胛/活动—肩袖与核心—动态稳定—快速球类与投掷”的示例路径，只借用其阶段结构。[阶段方案](https://www.massgeneral.org/assets/mgh/pdf/orthopaedics/sports-medicine/physical-therapy/pediatric-little-leage-shoulder-protocol.pdf)

## 五、胸椎与肋骨模块

### 1. 记录里反复出现的组合

- 胸椎旋转或伸展受限，常与颈部转动、肩抬举、肩胛内侧不适同时出现。
- 第一肋处理、胸大/小肌、菱形肌、背阔肌和竖脊肌处理反复出现。
- 胸椎更多是颈肩或腰髋主诉的相关因素，不一定是患者主诉本身。

### 2. 按主诉进入检查

| 主诉 | 优先检查 | 候选 | 复测 |
| --- | --- | --- | --- |
| 转体时上背或胸前卡 | 坐位/四点跪左右旋转、呼吸和肋骨活动 | 胸椎分节、肋骨、胸肌、背阔肌、竖脊肌 | 相同坐姿与骨盆固定下转体 |
| 驼背或抬手时胸椎伸不开 | 主动伸展、胸椎被动活动、肩前屈 | 胸大/小肌、背阔肌、胸椎和肩胛控制 | 胸椎伸展后再复测抬手 |
| 肩胛骨内侧疼 | 颈部、肩关节、肩胛动作、胸椎和肋骨一起筛 | 菱形肌、肩胛提肌、肩袖、胸椎/肋骨 | 转头、抬手或原训练动作 |
| 第一肋压下后转头/抬手改善 | 比较第一肋调整前后，检查斜角肌、胸肌和神经相关症状 | 第一肋是高相关候选，但不能直接定义为病因 | 同一转头或上肢动作至少重复两次 |

### 3. 处理与训练

- 主动受限、被动接近正常：胸椎主动伸展、翻书、四点跪旋转和呼吸配合。
- 主动、被动都受限：先处理胸肌、背阔肌、菱形肌或竖脊肌；改善不足时由专业人员选择胸椎或肋骨松动。
- 处理后一定回到颈部转动、肩抬举、划水或转体等问题复现动作，而不是只看胸椎角度。
- 进阶可结合肩胛稳定、鸟狗、四点跪支撑和带上肢的转体动作。

训练按“可用活动 → 骨盆固定下控制 → 与肩胛/核心协同 → 原抬手或转体任务”推进。胸椎活动是颈肩和躯干任务的候选辅助，不是必须纠正的姿势指标；现有直接证据有限，必须以问题复现动作是否改变来审核。[颈痛临床指南](https://pubmed.ncbi.nlm.nih.gov/28666405/) · [胸椎活动随机试验](https://pubmed.ncbi.nlm.nih.gov/35799408/)

既往肋骨骨折、胸痛伴呼吸困难或运动时胸闷等情况，不能仅按“胸椎肋骨卡住”处理。

## 六、肘关节模块

### 1. 资料特点

肘部独立病例明显少于肩颈。记录较清楚的路径包括术后伸直受限、前臂旋前受限、肘外侧压痛、小指不适，以及肘—肩胛—第一肋—神经的联动。肱桡肌在记录中出现较多，但不能因此把所有外侧肘痛都归给肱桡肌。

### 2. 按主诉进入检查

| 主诉 | 优先检查 | 常见候选 | 复测 |
| --- | --- | --- | --- |
| 肘伸不直或末端疼 | 主动/被动屈伸、末端感觉、肿胀、瘢痕和压痛 | 肱二头肌、肱桡肌、肱三头肌、关节囊与肘关节 | 相同姿势伸肘，记录角度和末端痛 |
| 旋前或旋后受限 | 主动/被动旋前旋后、近端与远端桡尺关节 | 肱桡肌、前臂旋转肌群、桡尺关节 | 肘固定后重复旋前/旋后 |
| 肘外侧疼、握物或发球痛 | 压痛、握力、抗阻腕伸/旋后、肩胛与肩关节 | 外侧前臂肌群、肱桡肌、桡尺关节、肩胛控制 | 相同重量、握法和发球/提物动作 |
| 肘内侧疼 | 压痛、抗阻屈腕/旋前、外伤机制和尺神经症状 | 屈肌—旋前肌群、尺神经和内侧稳定结构 | 原握物或投掷动作；急性外翻伤不强测 |
| 小指麻或肘内侧电感 | 感觉与肌力、尺神经相关动作，并补查颈肩和第一肋 | 尺神经全路径，不只看肘管 | 麻木范围和轻柔原动作 |

### 3. 处理与训练

- 主动受限、被动接近健侧：在可用范围训练屈伸或旋前旋后控制。
- 主动和被动都受限：先处理与方向相关的肱二头肌、肱三头肌、肱桡肌和前臂肌群；改善不足再由专业人员选择肘或桡尺关节松动。
- 术后还需结合手术时间、医生限制、伤口、肿胀和瘢痕，不用普通肘痛路径硬套。
- 训练从低负荷等长开始，逐步增加主动屈伸、旋前旋后、握力、提物和支撑。
- 外侧肘痛若检查支持腕伸肌负荷相关，可选等长、向心或慢放中耐受最好的一种，再增加阻力、杠杆、握力、重复次数和速度；最后才进入工具、球拍或投掷专项。
- 肩胛训练只在近端能力也存在缺口时补充，不自动给每位肘痛用户。

2022 外侧肘痛指南支持亚急性或慢性病例采用腕伸肌等长、向心和/或离心抗阻，并在高需求工作或运动中分阶段恢复压力、力量、耐力和动作控制。[外侧肘痛临床指南](https://www.orthopt.org/uploads/content_files/files/lucado_et_al_2022_lateral_elbow_pain_and_muscle_function_impairments.pdf)

**边界**：这是外侧肘肌腱相关路径，不自动适用于急性内侧韧带伤、术后、关节明显不稳或神经症状。

## 七、腕与手模块

### 1. 资料特点

腕手记录数量少，但能看出三类相对具体的场景：

1. 鼠标或拇指反复活动后的桡骨茎突/拇指侧疼痛。
2. 点赞、拇指外展后伸或第一掌指关节活动诱发的桡骨远端疼痛。
3. 尺侧腕痛与 TFCC 候选；现有专项内容只有一份，置信度低。

### 2. 按主诉进入检查

| 主诉 | 优先检查 | 候选 | 复测 |
| --- | --- | --- | --- |
| 拇指侧或桡骨茎突痛 | 主动/被动拇指外展、后伸和屈曲；腕背伸；触诊；使用鼠标动作 | 拇长展/伸肌腱、鱼际、第一腕掌关节、腕骨和前臂桡侧肌群 | 同一点赞、鼠标或拇指动作 |
| 手腕尺侧痛 | 腕屈伸、尺偏/桡偏、旋前旋后、抓握和负重 | 尺侧肌腱、远端尺桡关节、腕骨、TFCC 候选 | 相同提物、旋拧或轻支撑动作 |
| 撑地疼、拇指发不上力 | 腕背伸、掌指/腕掌关节、抓握和肩胛支撑 | 腕掌关节、腕骨/桡尺关节、鱼际力量、肩胛稳定 | 墙面或桌面低负荷支撑 |
| 旋拧或握拍疼 | 旋前旋后、握力、腕偏移和肘肩链 | 前臂肌群、桡尺关节、腕骨与握力 | 固定重量和握法复测 |

### 3. TFCC 候选路径

现有专项记录包括尺侧腕痛、尺偏/背伸/旋前旋后受限、关节不稳、琴键征和旋后抗阻提物痛；处理候选包括尺侧屈肌、尺骨/腕骨调整，以及桡偏、小指外展、旋前旋后和抓握力量。

这只能生成“需要进一步检查 TFCC 或远端尺桡关节”的提示。急性摔撑、明显不稳、持续肿胀或负重痛不应直接进入自行松动路径。

### 4. 处理与训练

- 主动受限、被动接近健侧：训练拇指、腕屈伸/偏移、旋前旋后和抓握控制。
- 主动与被动都受限：先处理相关前臂和腕手肌肉；改善不足，再由专业人员选择腕骨、桡尺或拇指关节松动。

腕手训练采用下面的通用进阶：

| 层级 | 主要能力 | 动作方向 |
| --- | --- | --- |
| 症状与活动 | 控制刺激，恢复腕屈伸、桡尺偏、旋前旋后和手指活动 | 舒适范围主动活动、手指/拇指活动、轻握放 |
| 肌肉重建与位置感 | 屈伸肌、桡尺偏肌和前臂旋转肌低负荷共同收缩 | 中立位等长、轻握力、前臂有支撑的旋前旋后、关节位置复现 |
| 力量与动态稳定 | 向心、慢放、协同稳定和小幅扰动 | 抗阻屈伸/偏移、旋前旋后、抓握、轻负荷绕环/飞镖轨迹、弹力棒或球扰动 |
| 负重与日常功能 | 闭链支撑和真实物品操作 | 墙面—桌面—四点跪支撑，提、搬、拧、推、拉、键鼠或工具操作 |
| 高速与专项 | 速度、反应、力量传递和专项训练量 | 球翻转/接抛、药球、动态支撑、球拍/球杆/格斗或器械专项 |

- 腕手不是孤立末端；支撑、推拉和握持还要检查肩胛、肩、肘与核心的力传导。
- TFCC/远端尺桡关节不稳、舟月不稳和 ECU 肌腱问题需要不同稳定方向。未确认结构时，系统只给通用低负荷共同收缩与功能进阶。
- 急性摔撑、持续肿胀、明显不稳或负重痛不改善时，不直接进入高负荷撑地。
- 组数和个数由异常感觉、力量、稳定性及次日反应生成，不因病名固定。

外部资料补足了线下记录缺少的“位置觉—动态稳定—负重—专项”阶段。一项 TFCC 感觉运动项目使用疼痛控制、肌肉重建/关节觉、神经肌肉训练、动作正常化/功能四阶段；样本仅 10 人且无对照，因此只能作为低置信度结构参考。[TFCC 感觉运动研究](https://pubmed.ncbi.nlm.nih.gov/37904835/)

ECU 运动员综述与案例支持无痛主动活动后，逐步进入等长、渐进阻力、慢放、握力、负重、扰动和专项训练；不能把这一条路径推广成所有尺侧腕痛的固定方案。[ECU 运动员康复综述与案例](https://pmc.ncbi.nlm.nih.gov/articles/PMC11067837/) · [Mass General 腕肘基础动作](https://www.massgeneral.org/assets/MGH/pdf/orthopaedics/sports-medicine/physical-therapy/mass-general-wrist-and-elbow-strengthening-exercises.pdf)

## 八、腰椎与骨盆模块

### 1. 记录里反复出现的组合

- 久坐、弯腰、后仰、侧屈、翻身或睡觉诱发腰骶部不适。
- 腰部主诉同时伴髋活动受限、腰大肌/腰方肌/竖脊肌紧张、臀肌或腘绳肌力量不足。
- 臀腿牵扯、麻木或电感与直腿抬高、腓肠/胫神经相关动作同时出现。
- 记录大量使用“骨盆卡旋前/旋后”，它可作为位置观察和手法试验方向，不能当成已经确认的结构错位。
- 臀桥、死虫、鸟狗、屈髋、单腿训练出现频率较高，但应由实际力量和动作检查决定，不应成为每个腰痛用户的固定套餐。

### 2. 按主诉、问题复现动作和位置缩小候选

| 主诉 | 优先检查 | 常见候选，不是诊断 | 现场复测 |
| --- | --- | --- | --- |
| 久坐后腰中间或偏一侧酸痛 | 坐姿、弯腰、后仰、左右侧屈；髋屈曲和坐姿习惯 | 腰大肌、腰方肌、竖脊肌、髋活动与躯干耐力 | 保持相同坐起/弯腰动作；久坐耐受留作随访 |
| 弯腰时后侧牵扯 | 弯腰动作、直腿抬高、腘绳肌与神经相关动作、髋屈曲 | 后侧肌群、神经张力、髋活动、腰椎分节 | 相同站距与膝位置下弯腰 |
| 后仰时腰部挤或卡 | 后伸、髋后伸、股直肌/腰大肌、腰椎专业分节检查 | 前侧髋肌肉、腰椎/髋关节活动和躯干控制 | 控制骨盆代偿后重复后仰或髋后伸 |
| 翻身、起床或睡觉腰骶痛 | 翻身、桥式准备动作、髋活动和骶髂周围触诊 | 腰方肌、臀肌、髋关节囊、骶髂相关候选 | 相同方向翻身或起身 |
| 臀部或坐骨附近疼 | 髋屈伸旋转、坐姿、腘绳肌起点、梨状肌、腰椎与神经 | 臀肌、梨状肌、腘绳肌起点、髋后侧关节囊、腰椎/神经 | 原坐姿、走路、翻身或单腿动作 |
| 腿麻、电感或放射 | 症状范围、感觉与肌力、直腿抬高及相关神经动作 | 神经受刺激、腰椎/髋周组织和姿势负荷 | 麻木范围和轻柔原动作，不追求拉到更麻 |

### 3. 评估与处理顺序

1. 固定一个本次目标，例如“坐 20 分钟后右腰酸”或“弯腰时左腿后侧扯”。
2. 检查弯腰、后仰、左右侧屈和必要的旋转；同时观察是腰椎在动、髋在动还是躯干整体代偿。
3. 触诊腰大肌、腰方肌、竖脊肌、臀肌、梨状肌和骶髂周围；专业人员再做腰椎分节检查。
4. 检查髋屈曲、后伸、内外旋，直腿抬高、PKB及相关神经动作。
5. 测臀肌、腘绳肌和躯干控制，再看屈髋、下蹲、单腿站和步态。
6. 肌肉或髋/骨盆位置调整后，必须回到原弯腰、翻身、走路或坐起动作复测。
7. 主动功能受限但专业被动/分节活动接近正常时，以控制和训练为主；两者都受限时，先处理相关肌肉，改善不足再由专业人员选择腰椎、髋或骶髂相关松动。

### 4. 训练与居家选择

| 层级 | 训练目的 | 动作方向 |
| --- | --- | --- |
| 可用活动 | 能主动使用腰髋所需方向 | 温和弯腰/后伸/转体、髋活动 |
| 骨盆稳定与后侧链控制 | 建立呼吸、腰腹核心、骨盆和后侧链控制 | 呼吸、臀桥、死虫、鸟狗、蚌式或髋外展 |
| 基础模式 | 把躯干和臀腿能力连接到承重动作 | 四点跪、站立屈髋、坐站、双腿髋铰链 |
| 日常功能 | 恢复用户实际受限任务 | 走路、弯腰取物、翻身起床、深蹲、提物和台阶 |
| 进阶功能 | 增加单腿、负重和耐力 | 分腿蹲、单腿屈髋、负重髋铰链、跑跳或专项 |

臀肌、腘绳肌或核心弱决定骨盆稳定与后侧链练习的侧重点，但不能让方案停在臀桥、蚌式和鸟狗。具备基础控制后，必须回到弯腰取物、走路、蹲起或恢复目标对应的功能任务。

力量不足和耐力问题不要求当场消失；本次只复测疼痛与活动受限，训练效果在后续复查。

外部指南补充了线下记录较少的负荷层级：慢性腰痛可根据缺口选择躯干力量/耐力、深层激活、动作控制、一般力量、有氧或多模式训练；手法只能作为主动训练的辅助。系统因此不能固定生成“核心三件套”，而应从目标任务反推最低缺口。[腰痛临床指南](https://pmc.ncbi.nlm.nih.gov/articles/PMC10508241/)

## 九、髋关节与大腿模块

### 1. 记录里反复出现的组合

- 髋屈曲、后伸、内旋、外旋或内收受限，主诉可在腹股沟、髋外侧、臀部或大腿。
- 腰大肌、股直肌、阔筋膜张肌/髂胫束、内收肌、梨状肌、腘绳肌和髋关节囊频繁作为候选。
- 臀大肌、臀中肌和腘绳肌力量不足，与走路、单腿站、单腿蹲和下肢力线问题同时出现。
- 髋问题经常与腰、膝和踝共同出现，但只有能够改变问题复现动作的相关区域才升为本次重点。

### 2. 按主诉位置、动作和异常感觉缩小候选

| 主诉位置/动作 | 优先检查 | 常见候选，不是诊断 | 现场复测 |
| --- | --- | --- | --- |
| 腹股沟或髋前方夹、刺、卡 | 髋屈曲、内旋、内收、后伸；触诊；屈曲内收相关测试 | 腰大肌、股直肌、内收肌、前侧关节囊；盂唇/关节内结构仅作进一步排查候选 | 相同屈髋、弓箭步或走路抬腿动作 |
| 髋外侧酸、单腿站紧或疼 | 单腿站、外展力量、骨盆控制、髋内外旋 | 臀中/小肌、TFL/髂胫束、髋关节囊与单腿负荷 | 相同单腿站时长或台阶动作 |
| 臀部或髋后侧卡、酸 | 髋屈曲/旋转、梨状肌、腘绳肌起点、神经和腰椎 | 臀肌、梨状肌、腘绳肌、后侧关节囊、腰椎/神经 | 坐姿、屈髋、翻身或走路 |
| 髋内旋受限 | 主动与被动内旋、骨盆代偿、后侧关节囊和髋周肌肉 | 关节囊、臀深层肌群、腰大肌/TFL等按触诊与复测排序 | 稳定骨盆后复测内旋，再复测问题复现动作 |
| 后伸受限或弓箭步前侧拉 | 主动/被动后伸、PKB、股直肌与腰大肌、臀肌力量 | 股直肌、腰大肌、前侧关节囊、臀肌控制 | 保持骨盆位置重复后伸或弓箭步 |
| 下蹲/跑步/单腿动作不稳 | 臀大/中肌、腘绳肌、内收肌、髋旋转、膝踝和躯干 | 髋周力量、动作控制、踝活动与足部支撑 | 同一深度、速度与扶持条件的原动作 |

### 3. 处理顺序

- 主动受限、被动接近健侧：训练对应方向的主动控制和相关力量。
- 主动与被动都受限：按受限方向先处理髋周肌肉和前/后侧关节囊；改善不足时由专业人员做髋关节松动。
- 腹股沟刺痛、弹响或屈曲内收测试明显阳性时，不用一次软组织改善就排除关节内结构；持续或负荷反复加重时结合影像与医学评估。
- 骨盆位置调整只有在能稳定改善髋活动或问题复现动作时才保留，不能单靠腿长变化下结论。
- 主诉改善后，再处理仍存在的髋活动和肌肉问题，随后进入力量训练。

### 4. 训练与进阶

- 先恢复髋屈伸、内外旋等目标任务需要的活动。
- 用呼吸、臀桥、髋外展、低负荷屈膝等建立骨盆稳定、臀大/中肌与后侧链控制。
- 用站立屈髋、坐站、双腿承重练骨盆—髋—膝协同，而不是停留在床上练习。
- 再进入深蹲、分腿蹲、台阶和单髋支撑，训练重心转换与单腿控制。
- 最后增加单腿髋铰链、负重、跑跳、落地和变向。
- 某块肌肉弱只决定哪个环节需要更多训练，不单独决定整套方案；训练终点始终是目标功能。

2023 非关节炎性髋痛指南补充了两个可进入系统的规则：一是按查体缺口处理活动、柔韧、力量、功率和体能；二是可以针对会诱发日常症状的动作做模式训练。后者目前证据较弱，因此只能显示为“可尝试并复测原动作”的外部候选。[髋痛临床指南](https://www.orthopt.org/uploads/content_files/files/Hip_Pain_and_Movement_Dysfunction_revision_2023.pdf)

## 十、膝关节模块

### 1. 记录里反复出现的组合

- 膝伸直末端受限，伴股外侧链、腘肌、小腿三头肌等紧张和股四头肌末端控制不足。
- 膝前、膝下、内侧、外侧或后侧疼痛与上下楼、下蹲、走跑和跳跃动作相关。
- 髌骨活动、近端腓骨、胫骨位置、踝背屈/外翻、髋与臀肌控制经常成为相关候选。
- 肿胀、术后瘢痕、肌肉萎缩和屈曲受限有独立处理路径。
- 训练内容从伸膝激活、臀桥、小腿力量到深蹲、分腿蹲、登阶、单腿控制和跑跳，覆盖相对完整。

### 2. 推荐检查顺序

1. 问清疼痛具体位置、性质、发生时间、受伤/手术、肿胀、影像和恢复目标；不要求用户必须说出精确动作。
2. 观察肿胀、皮温、肌肉围度、负重和步态。
3. 触诊髌骨周围、髌腱、脂肪垫、关节线、鹅足附近、腘窝、腘肌和小腿。
4. 检查髌骨上下内外活动。
5. 按标准方法对比主动伸直、屈曲；受限方向再安全比较被动。
6. 测股四头肌/股内斜肌、腘绳肌、臀肌和小腿力量。
7. 按受伤机制与疼痛位置选择韧带、半月板或髌股相关测试，不做整套无差别测试。
8. 补查踝背屈/外翻、近端腓骨、髋各方向、骨盆和相关神经动作。
9. 用下蹲、单腿站、单腿蹲、上下台阶、走跑或跳跃落地复现主诉。
10. 做一个肌肉屏蔽、发力提示、髌骨/胫骨/腓骨调整后，立刻重复问题复现动作。

### 3. 按主诉位置、动作和异常感觉缩小候选

| 主诉位置/动作 | 优先检查 | 第一批候选，不是诊断 | 现场复测 |
| --- | --- | --- | --- |
| 膝前或膝下，蹲起/上下楼痛 | 髌骨、髌腱/脂肪垫、伸直、股四头力量、髋膝踝动作 | 股直肌/股外侧肌、髌骨轨迹、髌腱或脂肪垫、股四头控制、踝背屈 | 同一台阶高度、下蹲深度和速度 |
| 下楼时膝内侧疼 | 具体触诊点、伸直、髌骨/胫骨、鹅足肌群、髋与足踝控制 | 外侧链过紧；缝匠肌/股薄肌/半腱肌及鹅足区域；内收肌、内侧腘绳肌；胫骨后肌/足弓；臀肌与股四头离心控制 | 同一只脚先下、相同扶持和速度下楼 |
| 膝外侧疼 | 股外侧肌、TFL/髂胫束、外侧腘绳肌、腘肌、腓骨与踝足 | 外侧链、近端腓骨、腓骨肌/足踝支撑、髋控制 | 原走路、下蹲、台阶或跑步动作 |
| 膝后侧紧或伸不直 | 主动/被动伸直、腘肌/腘绳肌、小腿三头肌、关节肿胀 | 后侧肌群、关节活动、神经张力和股四头抑制 | 被动伸直 → 主动伸直 → 原负重动作 |
| 扭转、卡住或关节线疼 | 受伤机制、肿胀、关节线触诊及少量半月板/韧带测试 | 结构相关候选、局部刺激、动作控制 | 不反复做高刺激扭转；必要时进入影像问答 |
| 走路或跑跳不稳 | 股四头、臀肌、腘绳肌、小腿、踝足、单腿控制 | 力量与动作控制、步态、踝足支撑 | 同一距离/动作留作功能复查，不要求当场力量改变 |

### 4. 活动受限的处理路径

#### 膝伸直受限

- 主动受限、被动接近健侧：优先处理疼痛抑制，并训练股四头肌末端伸膝控制。
- 主动和被动都受限：先检查并处理股外侧肌、TFL/髂胫束、腘肌、腘绳肌、小腿三头肌和相关后侧链；改善不足时由专业人员考虑髌骨上推、膝关节或近端腓骨松动。
- 被动改善后立即训练主动伸直到新范围，再复测上下楼、走路或下蹲主诉。
- 这不是“找到一块紧的肌肉就结束”；外侧链、后侧链、髌骨、膝/腓骨关节和股四头控制都要根据实际结果排序。

#### 膝屈曲受限

- 主动受限、被动接近健侧：看屈膝控制和疼痛抑制。
- 主动和被动都受限：检查股四头肌/股直肌、髌骨向下活动、关节囊、肿胀和术后瘢痕；肌肉处理改善不足时再考虑专业关节松动。
- 处理后复测被动屈曲、主动屈曲，再复测下蹲或上下楼。

### 5. 肿胀、按压痛和力量怎么处理

- 肿胀：记录范围是否缩小、轮廓是否恢复和负重是否逐渐改善；不要求一次治疗后消失。
- 按压痛、刺痛或局部胀痛：用于跟踪局部刺激，不适合短时间反复按压验证。
- 力量不足：安排相应训练，不以“当场变强”为复测目标。
- 当场复测只集中在主诉疼痛动作和明确的活动受限。

### 6. 训练按检查结果生成

以“恢复上下楼”为例，不能因为测到股四头弱就只安排伸膝训练。完整路径是：

| 层级 | 需要解决的能力 | 动作方向 |
| --- | --- | --- |
| 可用活动 | 膝伸屈、踝背屈和髋活动满足台阶动作 | 主动活动和处理后新范围控制 |
| 骨盆稳定与局部力量 | 核心、臀肌、股四头、腘绳肌、小腿和足部能力 | 呼吸/核心、臀桥、末端伸膝、屈膝和提踵 |
| 基础模式 | 髋膝踝共同承重，学会屈髋与重心下降 | 坐站、站立屈髋、浅蹲、分腿承重 |
| 目标功能 | 建立台阶中的单腿支撑和离心控制 | 低台阶上/下、逐渐增加台阶高度和连续次数 |
| 进阶功能 | 增加速度、负重、耐力和运动要求 | 负重台阶、单腿蹲、跳上/跳下、跑步和变向 |

其他膝功能同样按任务拆解：

- 走路需要膝伸直、小腿推进、臀腿支撑和步态重心转换。
- 深蹲需要踝背屈、膝髋活动、核心稳定和臀腿协同。
- 跑跳需要力量之外的减速、落地、弹性和左右转换能力。
- 实际弱项决定肩胛或骨盆稳定、局部力量练习的侧重点，但训练必须逐步回到目标功能。

主诉解决后，要顺势补齐伸屈活动、相关肌肉紧张和力量不足，再进入完整训练，而不是主诉一减轻就结束。

外部资料补充三条训练边界：

- 膝前/髌股相关表现同时存在髋与膝力量缺口时，优先考虑髋与膝联合训练，而不是只练股四头肌或只调整髌骨。[髌股疼痛临床指南](https://www.orthopt.org/content/s/patellofemoral-pain-2019) · [髌股疼痛国际共识](https://bjsm.bmj.com/content/52/18/1170)
- 进入跑、跳、变向前，要确认所需伸屈活动、稳定步态、单腿任务和减速/落地控制；具体阈值随损伤、术式与目标运动变化。
- Mass General 的膝力量、回归跑步、速度敏捷和跳跃方案只用来补足阶段结构；系统不照搬术后周数，并且一次只增加距离、速度、方向或外部负重中的一个变量。[Mass General 运动康复方案库](https://www.massgeneral.org/orthopaedics/sports-medicine/physical-therapy/sports-rehab-protocols)

## 十一、踝关节与足模块

### 1. 记录里反复出现的组合

- 急性崴脚或外伤后出现肿胀、淤血、负重痛和四方向活动受限。
- 慢性踝不稳、背屈/外翻受限、距骨或腓骨活动不足、小腿与足部肌肉能力下降。
- 疼痛位置覆盖外踝/前外侧、内踝/足弓、踝前、足背、足底、跟腱和足跟。
- 处理记录包括小腿三头肌、腓骨肌、胫骨前/后肌、趾伸肌、足底组织，以及距骨、近远端腓骨、骰骨、足舟骨和跖趾关节候选。
- 后期必须包含小腿力量、提踵、步态、平衡、单腿控制和跑跳；不能只做臀桥与髋训练。

### 2. 急性损伤先分流

1. 询问受伤方向、时间、高能量机制、当时和现在能否负重、肿胀/淤血变化及既往崴脚。
2. 明显错位或轮廓异常不等于普通肿胀；若怀疑骨性问题，进一步问是否拍片，而不是直接永久中断流程。
3. 没有影像但路径提示需要确认时，保存本次记录，等待影像后重新评估。
4. 影像采用问答录入：是否骨折、韧带损伤、肌腱损伤、积液、骨髓水肿或其他；骨折/明确结构异常按医嘱分期，无骨折或仅积液/骨髓水肿仍结合时间、负重和活动重新制定方案。
5. 急性淤血残留不直接等于循环危险；需要结合温度、感觉、足趾颜色、血运和变化趋势。

### 3. 四方向活动必须逐项检查

- 背屈、跖屈、内翻、外翻分别主动与健侧比较。
- 存在受限时，在安全范围比较被动；能负重后增加膝碰墙等功能性背屈测试。
- 主动受限、被动接近健侧：优先训练对应方向控制。
- 主动和被动都受限：先处理方向相关肌肉；改善不足时，再由专业人员选择踝关节分离、距骨、腓骨、骰骨、足舟骨或跖趾关节松动。
- 处理后复测被动方向、主动方向和原走路/台阶/提踵动作。

### 4. 按主诉位置、动作和异常感觉缩小候选

| 疼痛位置/动作 | 优先检查 | 第一批候选，不是诊断 | 复测 |
| --- | --- | --- | --- |
| 外踝或前外侧，崴脚后/走路痛 | 外侧肿胀压痛、内翻/外翻、背屈、相关韧带测试、腓骨活动 | 腓骨肌、胫骨前肌、趾长伸肌、近远端腓骨、距骨与外侧韧带 | 同一段走路、轻负重或外翻动作 |
| 内踝或足弓内侧疼 | 内侧触诊、内翻力量、提踵、足弓和第一跖趾 | 胫骨后肌、屈趾相关肌群、足底组织、足舟骨和足弓支撑 | 相同提踵、走路或足弓负重 |
| 踝前方卡、背屈痛 | 背屈主动/被动、膝碰墙、距骨与小腿肌肉 | 小腿三头肌、胫骨前/趾伸肌、距骨和踝前局部刺激 | 相同膝碰墙距离或下蹲 |
| 足背外侧或足趾根疼 | 趾伸、背屈、外翻、腓骨与骰骨 | 趾长伸肌、腓骨肌、骰骨/腓骨、鞋和步态负荷 | 相同走路或抬脚动作 |
| 后侧或跟腱疼 | 背屈、双/单脚提踵、小腿三头肌和跟腱负荷 | 小腿三头肌、跟腱负荷、踝背屈和步态推进 | 固定次数的提踵或相同走路速度 |
| 足底或足跟疼 | 足底触诊、足趾伸展、足弓、提踵、小腿和步态 | 足底组织、足部小肌群、胫骨后肌、小腿三头肌与足部关节 | 相同晨起/走路场景留作随访，现场用轻负重动作 |

### 5. 肿胀、刺痛和步态怎么处理

- 肿胀：跟踪是否消退和范围是否缩小；过度肿胀时先处理肿胀与温和活动，不强测末端。
- 活动时刺痛：可把周围肌肉与关节轨迹作为候选，但先看损伤时间和局部刺激程度；不因“松解后好一点”就排除结构损伤。
- 急性期步态异常：可能主要来自疼痛和不敢负重，先随时间和负重恢复观察。
- 较长时间仍跛行或推进不足：检查背屈、小腿力量、足弓、平衡、膝髋控制；处理与训练后仍无改善，再提高影像或医学评估优先级。

### 6. 训练不能停在早期

| 阶段 | 目标 | 动作方向 |
| --- | --- | --- |
| 1 | 肿胀与可接受活动 | 四方向温和主动活动、足趾活动、逐步负重 |
| 2 | 恢复局部活动与力量 | 背屈/外翻等受限方向训练、双脚提踵、胫骨前/后肌、腓骨肌和足部控制 |
| 3 | 恢复步态与髋膝踝联动 | 骨盆稳定、髋伸展、膝关节负荷吸收、踝滚动、小腿推进和连续重心转移 |
| 4 | 恢复单腿支撑与日常功能 | 足弓控制、单腿站、单脚提踵、台阶，并保持骨盆—髋—膝—踝连续力传导 |
| 5 | 下肢协同力量与减速 | 深蹲、分腿蹲、登阶、单腿屈髋、减速和不稳定面，但不替代踝足专项 |
| 6 | 回归运动 | 快节律提踵、跑步、双脚到单脚落地、侧向跳、变向和专项耐力 |

每次后续康复如果肿胀、疼痛或活动受限仍存在，仍然继续做相应局部处理；训练是逐步增加的另一条线，不是用训练替代尚未解决的肿胀和关节/肌肉问题。

外部资料补充三条踝足分支：

- 急性外侧踝扭伤在保护条件下逐步承重，并按检查加入主动活动、拉伸、神经肌肉、姿势和平衡训练；手法和回流只能帮助肿胀、活动与步态，不能替代训练。[踝扭伤临床指南](https://www.orthopt.org/uploads/content_files/files/jospt.2021.0302.pdf)
- 跟腱中段负荷问题若经专业评估支持，采用渐进肌腱负荷，而不是只拉伸；此路径不适用于急性撕裂或尚未明确的后踝痛。[跟腱临床指南](https://www.orthopt.org/uploads/content_files/files/Achilles_Pain_revision_2024.pdf)
- 足底/足跟问题根据足踝髋力量、活动和步态缺口组合训练，不能与跟腱路径混用。[足底痛临床指南](https://www.orthopt.org/content/s/heel-pain-plantar-fasciitis-revision-2023)

## 十二、如何转成产品规则

系统不应直接输出“你是某某肌损伤”，而应生成下面四层内容：

### 1. 已确定事实

- 用户原始主诉、恢复目标、问题复现动作和异常感觉位置。
- 当前主要疼痛/不适的 0～10 分、评分情境，以及处理前后的同条件变化。
- 用户选择的最终目标级别、当前所在级别，以及目标任务的频率、时长、负重、速度和对抗程度。
- 哪个主动方向出现疼、挤、扯、卡、不稳或其他异常。
- 被动是否也受限。
- 哪块肌肉紧、哪块肌肉力量弱。
- 哪个手动调整确实改变了问题复现动作。

### 2. 优先候选

只显示 2—4 个与主诉最相关的肌肉、关节或动作控制方向，并写成“先检查/先尝试”，不写成诊断。

### 3. 本次处理

- 先处理主诉最相关的一个候选。
- 当场只复测疼痛/不适动作、同条件 0～10 分和活动受限。
- 肿胀、按压痛、麻木、力量等不要求当场消失，放到后续跟踪。
- 主诉改善后，继续处理仍存在的活动与肌肉问题。

### 4. 居家训练

- 从目标功能反推需要的活动、力量和协同模式，再选择当前最低层能力。
- 由力量结果决定局部肌肉是放松、拉伸、强化还是“先获得范围再强化”，但局部肌肉只决定训练侧重点。
- 方案按“可用活动 → 肩胛/骨盆稳定与局部力量 → 基础模式 → 目标功能”组织，不能停在孤立肌肉练习。
- 使用组数与个数等普通用户能理解的表达。
- 只给 2—4 个与本次发现最相关的动作。
- 下一次康复先复查问题复现动作、活动受限、肿胀/异常感觉变化、上次肩胛/骨盆稳定、局部力量和动作模式，再决定是否进阶。

## 十三、现阶段不能假装已经解决的内容

- 颈部抗阻、耐力和回归专项已补入外部进阶框架，但具体组数、个数及不同运动标准仍缺少本地案例审核。
- 肩袖、前锯肌、过头负荷与投掷/游泳已补入外部进阶框架，但不同主诉和不同运动的组数、负荷及真实案例随访仍不足。
- 外侧肘痛已补入指南支持的腕伸肌等长/向心/慢放及高需求分期；内侧肘痛、急性韧带伤和投掷回归仍缺少本地验证，不能照搬外侧路径。
- 腕手已补入通用感觉运动和负荷进阶，但线下病例、长期随访和不同结构分支仍明显不足，不能自动套用 TFCC 或 ECU 路径。
- 腰髋记录虽然多，但“骨盆旋前/旋后”等表述缺少统一客观标准，产品中只能作为位置候选和反应实验。
- 膝与踝足已补入走跑跳阶段结构，但受伤/手术阶段、影像结果、单腿能力和负荷反应仍必须写入个体进阶条件，不能只按疼痛分数自动升级。
- 很多记录写了处理内容，但缺少严格的处理前后数值与长期结果，因此“出现频率高”不等于“疗效已经被证明”。

这些缺口应在产品中显示为低置信度候选或待补充模块，而不是用更多文字掩盖。
