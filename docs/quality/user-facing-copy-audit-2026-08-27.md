# RehabMind 正式用户界面文案审计

日期：2026-08-27
范围：普通问诊、专业工作台、安全确认、评估、处理复测、训练、总结、历史记录、保存恢复、冲突和移动导航
排除：`/test` 测试工作台、`/admin` 管理后台、决策实验室及展开后的诊断详情

## 1. 审计规则

- 用户只需要知道当前结果、风险和下一步，不需要理解系统如何保存或推导。
- 正式页面不展示“快照、投影、基线、可比较、持久化、线程、候选、门控、静默覆盖、修订”等实现术语。
- 专业模式保留主动活动、被动活动、末端感觉等必要临床术语，但不展示软件实现术语。
- 一段说明原则上不超过两句话；多个条件拆成清单。
- 同一内容不同时用标题、正文和小字重复三遍。
- 安全、停止、就医和医生限制条件不因精简而删除。

## 4. 共享文案入口

正式页面重复文案集中在 `components/shared/user-facing-copy.ts`：

- 未完成动作的复测标题与说明。
- 处理前评分上下文。
- 本机保存失败提示。
- 本机与云端记录冲突标题和说明。

新增页面应优先复用这些入口，避免同一状态再次出现不同说法。

## 5. 后续验证

本审计只标记开发实现状态，不代替浏览器回归。测试会话应基于最终提交验证：

- 普通模式和专业模式不出现登记的实现术语。
- 桌面与移动端长文案不溢出、不堆叠。
- 安全、停止、就医和医生限制出口没有因文案精简而丢失。
- 展开“查看记录详情”以前，冲突主操作区不显示技术版本差异。
