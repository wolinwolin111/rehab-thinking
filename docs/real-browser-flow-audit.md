# 真实页面闭环验收

## 目的

源码断言只能证明“代码里有这段文字”，不能证明用户真的能点击完成流程。每次评估/处理规则调整后，必须在桌面浏览器从新评估开始，按页面实际按钮走到总结或明确停止出口。

## 每次点击的验收纪律

1. 只点击当前 `domSnapshot()` 中可见的按钮，不按旧快照连续盲点。
2. 每次点击后立即重新读取 `domSnapshot()`，记录阶段、标题、当前按钮和已收集信息。
3. 检查“下一步”是否在信息足够后才启用；不能出现无按钮、禁用按钮却没有补充提示、自动跳过未填页面。
4. 每个阶段都读取浏览器 error 日志；出现报错、卡死或意外跳转，立即停在现场记录，不用源码推测“应该可以”。
5. 从返回上一步重新进入时，重新确认已选值、评分、复测结果和处理队列是否仍是最新数据。

## 首批必须走完的真实路径

| 路径 | 关键组合 | 必须看到的结果 |
| --- | --- | --- |
| 普通用户·膝前痛 | 下楼梯痛5分、伸直受限、大腿前侧紧张；主诉复测5→3 | 处理复测不直接结束；总结显示5→3；训练可进入 |
| 专业用户·膝前痛 | 被动活动+关节处理，无末端感觉能力也可声明 | 肌肉处理后复测被动仍受限时进入关节松动；不会因终末感字段锁死 |
| 髌骨组合 | 四方向被动活动全部记录 | 只显示一个评估步骤，但实际有向上、向下、向内、向外四张方向卡；不显示主动/抗阻问题 |
| 普通用户·无固定动作 | 位置明确但动作和分数跳过 | 不生成虚假评分；到达明确的低刺激训练或保存出口 |
| 全阳性膝流程 | 活动、功能、局部检查、肌肉均异常 | 一组处理后统一复测相关动作；活动仍未达健侧时继续下一处理，不直接训练或结束 |
| 加重 | 处理或训练后分数升高/出现新感觉 | 停止当前处理，进入“确认加重后的变化”或保存并结束；不能跳回空白评估 |
| 返回修改 | 评估完成后返回修改一个选项 | 下游旧答案作废并重新开放依赖项；不跳到最新未填写题，也不沿用旧处理队列 |
| 第二次康复 | 上次结束分数低于首次，旧问题仍在 | 使用上次结束数据；先快速复查旧问题、轻柔松解，再安排训练，不直接沿用首次数据 |

## 固化的断言

`scripts/real-browser-flow-audit.mjs` 提供统一辅助器：

- `auditCheckpoint`：检查当前阶段标题、必需/禁止内容、按钮或明确终止出口，并检查 error 日志；
- `auditPatellaGroup`：检查髌骨方向卡实际数量必须为4；
- `auditSummaryScore`：检查总结采用本轮最新主诉分数，而非首次分数；
- `auditNoRuntimeErrors`：检查浏览器 error 日志为0。

这些断言不能替代人工判断动作是否看得懂，但能把“没按钮、跳步、重复复测、数据回退、运行时报错”从人工印象变成每次走读都要记录的证据。

## 本轮新增闭环核对

1. 专业用户在“主动伸直受限 → 被动仍受限 → 膝关节伸直方向松动”后，页面不能把通用膝关节候选误显示成髌骨专项复测。
2. 真正进入髌骨方向候选时，标题必须是“髌骨向上/下/内/外滑动辅助”，处理卡只复测本轮实际受限的方向；不能把四个方向重新全部复测。
3. 髌骨复测必须使用“被动活动幅度”和“被动活动时有没有出现新的不适”，不能回退为主动活动或抗阻力量问题。
4. 普通用户的肿胀管理完成后仍必须出现已确认的肌肉/活动处理或明确的低刺激训练出口；急性肿胀、刺痛、麻电感场景不自动显示训练后自主按压。
5. 组合与极限场景至少覆盖：全阳性、全部“无法完成/暂不判断”、主诉分数下降但活动仍受限、活动接近健侧但力量偏弱、处理后加重、训练后加重、返回上一步修改、双侧主诉、第二次康复沿用上次结束分数。

## 本轮实际走读记录（2026-08-16）

- 膝关节普通用户路径已从症状收集走到训练和总结：下楼梯主诉、活动受限、功能动作因疼痛无法完成、肌肉紧张、处理后复测、训练反馈和总结均可完成；疼痛导致的功能动作不再被误判为“需要补充检查”。
- 大腿专业用户路径已完成：安全确认 → 影像结论 → 被动活动/终末感/不适记录 → 功能检查 → 评估结果 → 肌肉处理 → 复测 → 关节松动 → 被动复测 → 低刺激训练 → 训练后整体复测 → 总结。
- 走读发现并修复：局部大腿/小腿路径提前返回导致专业 PROM 受限没有关节处理；批量复测未把“被动仍受限”交接给下一类关节候选；关节处理标题把完整 finding 文本拼进标题。现在会按受限方向生成专业关节处理卡，并用稳定 target id 处理动态队列重排。
- 专业复测闭环实测结果：关节处理后选择“均接近目标”会完成当前方向并进入训练选择，不再直接落到无说明的终止页；总结采用本轮结束分数（本例 5→2），并显示有效处理、训练和下次复查窗口。
