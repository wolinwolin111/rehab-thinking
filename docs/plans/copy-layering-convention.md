# 文案分层约定

> 自助模式和专业模式有不同的用户群体，文案必须明确分层，避免混用。

## 规则

1. **自助模式**（普通用户、教练）：用大白话，避免临床术语。目标：普通用户能看懂、能操作。
2. **专业模式**（康复师、`isThinkingMode && !workflowProfile.isStudy`）：用标准临床术语。目标：专业用户觉得精确、不啰嗦。

## 已分层的文案

| 位置 | 自助 | 专业 |
|---|---|---|
| 恢复目标 GOALS | `GOALS_SELF`（先消肿止痛、疼痛明显减轻…） | `GOALS_PRO`（急性反应减轻、基础症状改善…） |
| 症状性质 | 折叠大类（疼痛/麻电感/无力不稳/说不清） | 平铺 4 大类（全部展开） |
| 活动度检查 | 口语化（把脚背向上勾、转到最大范围） | 专业术语（踝关节背屈 AROM、主动活动到最大范围） |
| 保持/力量检查 | 停住不动，看稳不稳 | 同一个动作：检查抗阻力量 |
| 观察提示 | 哪边活动范围更小、活动到最大范围时会不会牵拉或卡住 | 哪侧活动范围更小、主动活动到最大范围时是否诱发症状 |

## 新增文案时的检查清单

- [ ] 自助模式：用大白话，有画面感，不超过 15 字。
- [ ] 专业模式：用标准术语，不啰嗦。
- [ ] 如果只有一个版本，评估是否应该拆成两套。
- [ ] 拆成两套时，参考 `GOALS_SELF` / `GOALS_PRO` 的模式（常量 + 渲染处选择）。
