# 膝关节问题与动作归并表

> 用途：把主诉、活动度、力量和功能检查统一成“问题”，避免页面把同一件事重复生成多次。

## 1. 问题类型

| 类型 | 例子 | 当场处理 | 当场复测 |
| --- | --- | --- | --- |
| 主诉症状 | 下楼时膝内侧酸痛 6/10 | 优先 | 有固定动作时复测 |
| 活动范围 | 主动伸直比健侧小 | 视主动/被动结果 | 复测范围；原本有痛则同时记分数 |
| 动作不适 | 绷直膝盖时内侧刺痛 | 与同动作范围合并 | 同一次动作同时更新范围和分数 |
| 力量不足 | 股四头肌末端发力偏弱 | 转训练 | 不要求手法后立即变强 |
| 功能控制 | 下台阶时膝内扣 | 转动作控制训练 | 完成一轮训练后再看动作质量 |
| 肿胀 | 髌骨周围肿胀 | 单独管理 | 当天晚些时候或下次比较 |
| 按压痛 | 鹅足周围压痛 | 作为定位线索 | 不要求每项处理后消失 |
| 麻、电或感觉变化 | 小腿外侧麻到足背 | 先分流 | 不进入普通自助处理链 |

## 2. 完全相同的动作

以下表达归入同一个标准动作，只做一次：

| 标准动作 | 用户可能的表达 |
| --- | --- |
| 下台阶 | 下楼、下楼梯、下台阶、从台阶往下、台阶下降 |
| 上台阶 | 上楼、上楼梯、上台阶、登阶 |
| 膝伸直 | 膝盖绷直、伸直膝盖、膝后下压、伸膝 |
| 膝屈曲 | 弯膝、屈膝、脚跟滑向臀部 |
| 下蹲 | 下蹲、蹲起、深蹲 |
| 坐站 | 从椅子站起、坐下再站起、坐站 |
| 单腿站 | 单脚站、单腿站、单腿平衡 |
| 站立屈髋 | 屈髋、髋折叠、站立位屈髋 |

同一标准动作可以同时承载多个指标。例如一次“膝伸直”可以同时记录：

- 主动范围；
- 被动范围（专业人员路径）；
- 内侧疼痛分数；
- 刮擦或牵扯感。

## 3. 相关但不能合并的动作

| 动作 A | 动作 B | 关系 |
| --- | --- | --- |
| 下台阶 | 膝伸直 | 相关，但一个是复合功能任务，一个是单关节活动，分别保留 |
| 下蹲 | 下台阶 | 都有负重屈膝，但负荷和控制要求不同，分别保留 |
| 单腿站 | 单腿下蹲 | 能力逐级关系，不合并 |
| 走路 | 跑步 | 负荷阶段不同，不合并 |
| 膝屈曲 | 下蹲 | 可相互提供线索，但不能用一个结果代替另一个 |

## 4. 问题状态

每条问题只能通过状态更新推进，不能用页面位置猜测：

```text
待检查 → 已确认 → 待处理 → 本轮已覆盖
                         ├→ 改善
                         ├→ 仍存在
                         └→ 已解决

力量/控制问题 → 转训练
肿胀/压痛 → 后续复查
安全或神经信号 → 专业评估
```

主诉改善只更新主诉状态，不会自动删除独立存在的活动度、力量或控制问题。

## 5. 首批膝关节问题入口

| 位置/表现 | 首个确认重点 | 不自动追加 |
| --- | --- | --- |
| 膝内侧下楼痛 | 下台阶、膝伸直、内侧与外侧相关检查 | 完整踝足检查、全部特殊测试 |
| 膝前下蹲痛或刮擦 | 下蹲、伸屈范围、髌股与轨迹线索 | 所有韧带测试 |
| 膝后或屈膝末端痛 | 膝屈曲、伸直、膝后和小腿上端 | 跑跳测试 |
| 急性扭伤伴肿胀 | 安全确认、肿胀位置、当前可承受活动 | 未尝试过的楼梯、跑步复测 |
| 只有弹响且说不清动作 | 建立一个可复现任务；否则简短看伸屈 | 疼痛评分和完整处理链 |
| 力量不足或打软 | 股四头肌、臀部支撑、当前功能任务 | 手法后反复测力量 |
