# 膝关节与踝足首发知识库

> 状态：现行
>
> 版本：2026-08-13
>
> 用途：首发 Demo 的评估、处理和训练内容来源

本文件只整理当前开放的膝关节和踝足模块。内容来自线下康复记录、关节活动受限判断资料、肌肉解剖作用和已核对的康复资料。所有内容都是候选来源和反应试验，不直接等同诊断。

---

## 1. 通用生成方式

主诉和恢复目标共同决定内容：

主诉位置与动作 → 相关活动方向 → 局部紧张和力量 → 功能动作 → 与目标能力的差距 → 处理和训练。

### 1.1 问题分类

| 检查结果 | 系统处理 |
| --- | --- |
| 活动范围偏小 | 紧张位置取样，必要时主动控制或专业关节处理 |
| 活动会不适 | 记录位置、性质、分数并进入可复测处理 |
| 肌肉紧张 | 优先轻柔松解该区域 |
| 力量偏弱 | 移交对应训练 |
| 发力会不适 | 处理相关区域并复测发力 |
| 功能动作异常 | 记录代偿和阶段，进入动作训练 |
| 肿胀或淤青 | 时间性管理，稍后或次日观察 |
| 麻或电感 | 普通用户停止自助神经处理，建议专业确认 |

### 1.2 处理顺序

1. 先解决主诉；
2. 从离症状位置最近且动作相关性最高的区域开始；
3. 同一区域只处理一次；
4. 一项处理关联的所有异常方向一起复测；
5. 主诉处理结束后继续处理其他独立活动问题；
6. 最后根据力量和功能问题安排训练。

肌肉候选由两部分组成：线下记录提供更常见、更有效的优先方向，功能解剖补齐该活动的动作肌、拮抗肌和必要稳定肌。系统保留完整候选，但一次只执行本次检查最支持的一个标准区域。

一个肌肉处理单元包含“轻柔松解 + 相关方向低次数主动控制 + 一次统一复测”。主动控制只做5～8次，用来观察当前方向是否更容易完成；真正的力量、耐力和功能进阶仍在训练部分。

### 1.3 三层评估与问题数量

首发版使用三层而不是“把相关项目全部问一遍”：

| 层级 | 要确认什么 | 进入条件 |
| --- | --- | --- |
| 局部问题层 | 主诉附近的活动、发力、轻按和高相关专项检查 | 所有人 |
| 基础功能层 | 承重/走路、关键活动、局部与后侧链力量、平衡和髋膝踝协同 | 安全且当前能力允许 |
| 目标进阶层 | 台阶、单腿、跑跳和变向等目标差距 | 前一层能够稳定完成且目标需要 |

基础功能异常包括：不能正常承重或走路、关键活动偏小或会不适、局部或后侧链力量偏弱、平衡或动作控制异常、当前能力达不到恢复目标。普通用户首屏只出现当前最需要的一项功能动作；完成正常后才增加下一项，最多逐级增加，不同时展开整条测试链。

## 2. 膝关节

### 2.1 常见主诉入口

| 主诉 | 优先关注 |
| --- | --- |
| 膝前或髌骨周围不适 | 膝屈伸、髌骨周围、股四头、踝背屈、下蹲 |
| 膝内侧不适 | 膝伸直、内侧与鹅足区域、外侧链、髋控制、下楼 |
| 膝外侧不适 | 大腿外侧链、膝后外侧、髋稳定、下蹲或跑步 |
| 膝后不适 | 膝伸直与屈曲、大腿后侧、腘肌、小腿后侧 |
| 扭转后肿胀 | 安全与影像确认、肿胀、伸直、承重和专项检查 |
| 下楼或蹲起疼 | 膝屈伸、踝背屈、股四头和臀部力量、髋膝踝联动 |
| 伸不直 | 主动伸直、紧张位置、专业模式被动伸直、股四头控制 |
| 无力或打软腿 | 股四头、臀部和小腿力量，单腿与台阶控制 |

这些对应关系只决定检查顺序，不能直接认定病因。

### 2.2 首发评估队列

基础方向：

1. 膝盖伸直；
2. 膝盖弯曲。

这两项作为完整基础检查组：默认先伸直、再弯曲，两项都要保存，不能被股四头力量、台阶、下蹲或专项检查挤掉。明确的主诉功能动作可先复现，但随后仍完成伸直和弯曲。

根据主诉追加：

- 髌骨周围轻按或相关专项检查；
- 股四头发力；
- 下蹲；
- 双脚或单脚提踵；
- 台阶或下楼；
- 单腿站或单腿控制；
- 急性扭转后的结构性排查。

普通用户一般保留最相关的4～6项。

#### 2.2.1 膝关节专项检查库

| 项目 | 分类 | 当前适用前提 | 结果用途 |
| --- | --- | --- | --- |
| 髌骨周围轻按定位 | 定位筛查 | 膝前、髌骨周围或髌骨下方不适 | 记录最熟悉的具体位置，不判断结构 |
| 膝内外侧关节线轻按 | 定位筛查 | 膝内/外侧明确痛点，扭转后卡顿 | 记录集中压痛，不能单独判断半月板 |
| 麦氏测试相关筛查 | 专业特殊测试 | 扭转后关节线症状、卡顿或伸屈受限 | 提高半月板方向专业评估优先级 |
| Lachman前向稳定检查 | 专业特殊测试 | 非接触扭转、快速肿胀、打软或前向不稳线索 | ACL方向优先检查；前抽屉仅作补充，不默认重复两项 |
| 后沉观察＋后抽屉 | 专业特殊测试 | 膝前方受撞、跪倒或后向不稳线索 | 先观察后沉，再按需要检查后向松弛 |
| 外翻/内翻应力检查 | 专业特殊测试 | 膝内/外侧受力机制、局部症状或侧向不稳 | 先按相应侧别出现，不把两侧四项全部展开 |
| 髌骨辅助反应 | 反应实验 | 下蹲、台阶或跑步时膝前症状 | 轻柔辅助髌骨后复测同一动作，只用于症状修饰 |

膝前向稳定以Lachman为优先，前抽屉只在体位、病程或结果需要补充时出现；不在学习者首轮加入高技术要求的轴移检查。后向稳定采用后沉观察后再决定是否后抽屉。内外侧应力按受伤机制和症状侧别出现。麦氏测试保留为专业可选项，不作为膝扭伤默认必查，因为单项诊断准确性不足。

原“髌骨/胫骨位置反应”不再作为一个专项测试。首发只保留膝前痛的髌骨辅助症状修饰；胫骨旋转或位置调整拆到专业处理反应实验，只有相应活动、症状和专业能力支持时出现，页面禁止使用“错位、复位”表述。

### 2.3 活动度判断

#### 膝伸直

普通用户：

1. 仰卧，腿自然伸直；
2. 大腿前侧用力，把膝后侧向床面压；
3. 比较两侧膝后能否压向床面、空隙和是否不适；
4. 看不清时，把同一条薄毛巾先后放到两侧膝后，绷紧大腿后轻轻抽动，比较哪一侧更容易抽出；
5. 再把绷直的整条腿抬离床面约10厘米并保持3秒，比较膝盖能否保持笔直，是否明显抖动或很快落下。

膝后明显更悬空只记录“主动伸直偏小”；抬腿时膝盖弯曲、抖动或很快落下记录“伸直保持能力不足”。普通用户无法据此判断被动范围或关节受限。疼痛、害怕或看不清时允许跳过保持检查。

专业人员可补充：

- 手放腘窝下比较压力；
- 固定大腿末端，轻抬小腿感受末端角度和弹性；
- 区分主动与被动范围。

#### 膝屈曲

仰卧或俯卧，缓慢弯曲膝盖，比较脚跟靠近臀部的程度、膝前或膝后的不适和左右差异。

### 2.4 紧张位置取样

| 方向 | 用户可选位置 |
| --- | --- |
| 膝伸直 | 大腿前侧、大腿内侧、大腿后侧、小腿后侧 |
| 膝屈曲 | 大腿前上方、大腿外侧、膝后侧 |

用户选择的位置直接进入优先处理。没有明显差别时先做温和主动活动。

普通用户的处理以肿胀管理、明确异常肌肉区域的轻柔松解和主动控制为主。膝伸直取样包含大腿前侧、外侧、内侧及膝后/小腿后侧；选中的区域只处理一次，随后统一复测原主诉和膝伸直。普通用户不进入关节松动，也不把主动受限直接解释成关节问题。

### 2.5 肌肉区域候选

| 区域单元 | 主要包含 | 常关联方向或场景 |
| --- | --- | --- |
| 大腿外侧链 | 股外侧肌、阔筋膜张肌、髂胫束周围 | 膝伸直、屈曲、膝内外侧不适、下蹲 |
| 大腿前侧 | 股四头、股直肌和膝前软组织 | 膝屈伸、下蹲、台阶 |
| 大腿内侧与鹅足 | 内收肌、缝匠肌、股薄肌、半腱肌、股内侧肌 | 膝内侧不适、下楼、膝屈伸 |
| 大腿与膝后侧 | 腘绳肌、腘肌 | 伸直不足、膝后牵扯 |
| 小腿后侧 | 腓肠肌、比目鱼肌 | 膝伸直、踝背屈、步态 |
| 臀部与髋后外侧 | 臀中肌、臀大肌及髋稳定肌群 | 下蹲、台阶、单腿和跑步 |

列表用于候选排序。只有位置、动作或检查反应支持时才进入处理。

膝内侧下楼或下蹲问题的默认处理顺序是鹅足相关肌肉 → 内收肌 → 外侧链；某一处只有检查支持时才出现。膝伸直受限时把股直肌/大腿前侧与外侧链作为第一组，把腘肌与小腿后侧作为第二组；每组完成后统一复测，不拆成多张重复卡。髌骨下痛默认快速查看股直肌和大腿前侧，异常才处理。

### 2.6 关节处理

专业模式下，肌肉处理后仍未达到比较目标且被动也受限时，可考虑：

- 髌骨相关方向；
- 胫股关节对应方向；
- 近端胫腓关节相关方向。

出现硬性阻挡、明显锐痛、急性高敏感或医生限制时不进入。

近端胫腓关节不要求用户判断前后微动或末端感觉。只有膝外侧/腓骨头附近症状、相关动作可复现，且高相关肌肉处理后变化不足时，才开放“腓骨近端辅助反应实验”。专业人员轻柔固定或辅助一个方向，保持相同条件复测膝伸直、下蹲或台阶；结果只记录明显改善、少量变化、无变化或加重，不记录错位、复位或关节受限。膝主诉优先近端；踝主诉优先远端，近端只作条件式补充。

### 2.7 力量与功能训练

#### 第1～2阶段

- 脚跟滑动；
- 膝后下压；
- 仰卧直腿或终末伸膝控制；
- 臀桥；
- 仰卧内收控制；
- 仰卧足弓和踝部控制。

力量明显偏弱时优先仰卧或侧卧。

后侧链按“臀桥 → 单腿臀桥 → 站立屈髋”进阶。臀桥和单腿臀桥建立臀大肌、腘绳肌与骨盆稳定能力；能够稳定完成后，再用站立屈髋把力量带回站立动作。

#### 第3阶段：正常生活

- 站立屈髋；
- 坐站；
- 浅蹲；
- 分腿蹲基础版；
- 台阶；
- 双脚提踵；
- 髋膝踝联动和步态。

#### 第4阶段：一般运动

- 单腿蹲或单腿坐站；
- 进阶台阶；
- 单腿提踵；
- 动态平衡；
- 跑步准备；
- 低强度落地与减速。

#### 第5阶段：高强度与对抗

- 跳跃和落地；
- 变向和减速；
- 疲劳条件下控制；
- 速度与专项动作；
- 接触或对抗准备。

## 3. 踝关节与足

### 3.1 常见主诉入口

| 主诉 | 优先关注 |
| --- | --- |
| 急性崴脚、外踝肿痛 | 安全和骨性风险、肿胀；四方向必须检查，其中背屈和外翻优先，跖屈和内翻次之；承重随后按主诉加入 |
| 外踝或小腿外侧不适 | 腓骨肌区域、外翻控制、背屈、步态 |
| 小腿前外侧活动不适 | 先查胫骨前肌与腓骨肌；局部处理变化不明显时，可把阔筋膜张肌/髂胫束周围作为一次反应试验 |
| 内踝或足弓内侧不适 | 胫骨后肌区域、内翻控制、足弓和提踵 |
| 踝前卡或勾脚受限 | 背屈、小腿后侧、踝前区域、专业关节检查 |
| 足底或足跟不适 | 足弓、足底、小腿后侧、提踵和步态 |
| 走路或上下楼困难 | 四方向活动、小腿力量、足弓、平衡和髋膝踝联动 |
| 跑跳目标 | 提踵、单腿稳定、落地、减速和变向 |

没有脚趾受伤、疼痛或功能主诉时，不自动加入脚趾检查。

### 3.2 急性损伤

急性崴脚先确认：

- 明显错位或开放伤口；
- 远端颜色、温度和感觉的持续异常；
- 骨性标志处高度集中压痛；
- 当时和目前能否承重走四步；
- 是否已有影像和医生限制。

普通肿胀、淤青和软组织压痛不能单独判定骨折。

### 3.3 首发评估队列

急性崴脚的基础四方向必须全部完成，不能被承重、提踵、力量或特殊检查挤掉。默认顺序是背屈、外翻、跖屈、内翻；如果用户明确说某个方向疼，先检查该方向，再按上述优先级补齐其余三个方向。

基础四方向：

1. 脚背向上勾；
2. 脚掌向外转；
3. 脚背向下压；
4. 脚掌向内转。

根据主诉追加：

- 勾脚、下压、内翻或外翻力量；
- 下蹲；
- 提踵；
- 单腿站；
- 步态、台阶或跑跳；
- 急性崴脚相关专项检查。

#### 3.3.1 踝足专项检查库

| 项目 | 分类 | 当前适用前提 | 结果用途 |
| --- | --- | --- | --- |
| 急性崴脚骨性风险组合 | 安全分流 | 急性外伤后骨点压痛或承重困难 | 决定影像优先级，不诊断骨折 |
| 踝前抽屉相关稳定检查 | 专业特殊测试 | 内翻崴伤后反复打软、不稳或外踝前方症状 | 提高外侧韧带稳定性专业评估优先级 |
| 距骨倾斜检查 | 专业特殊测试 | 外踝下方症状、内翻机制或前抽屉后仍需补充外侧稳定信息 | 作为CFL方向的条件式补充，不与前抽屉默认捆绑 |
| 下胫腓联合测试组 | 专业特殊测试 | 外旋机制、高位踝痛、胫腓联合压痛或背屈负重明显异常 | 外旋与挤压作为组合证据，单项不能确认高位踝损伤 |
| 小腿挤压/跟腱连续性筛查 | 专业安全筛查 | 突然蹬地、响声、踝后剧痛或无法正常提踵 | 可疑时停止普通训练并转专业评估 |
| Windlass足底张力反应 | 反应实验 | 足底/足跟痛与晨起、走路或提踵相关 | 提高足底—大脚趾链检查优先级 |

踝外侧稳定先结合ATFL区域触诊和前抽屉；距骨倾斜只在CFL方向线索存在时追加。下胫腓联合不能依赖单项检查，使用受伤机制、压痛位置、外旋和挤压反应的组合；需要明确结构时优先结合MRI等影像。四方向基础活动仍先于这些专业检查。

大腿和小腿局部首发不机械增加传统特殊测试。急性拉伤、撞伤、疑似骨应力、跟腱风险及小腿明显肿胀/颜色温度变化，优先使用“收缩—拉长—功能表现”和安全分流；只有某项新增测试能明确改变安全出口、评估方向或处理权限时才进入库。

### 3.4 紧张位置取样

| 方向 | 用户可选位置 |
| --- | --- |
| 背屈 | 小腿后面、脚底、踝前侧 |
| 跖屈 | 小腿后侧、小腿前面、足背；同时区分发力侧不适和前侧牵拉限制 |
| 内翻 | 小腿外侧、外踝周围、脚底外侧 |
| 外翻 | 小腿内侧、内踝周围、足弓内侧 |

选中的部位优先进入轻柔松解；没有明显差别时先做该方向温和主动活动。

### 3.5 肌肉区域候选

| 区域单元 | 主要包含 | 常关联方向或场景 |
| --- | --- | --- |
| 小腿后侧 | 腓肠肌、比目鱼肌 | 背屈、跖屈、提踵和步态 |
| 小腿前侧 | 胫骨前肌、趾伸肌群 | 背屈控制、抬脚 |
| 小腿外侧 | 腓骨长短肌 | 外翻、外踝稳定和走路 |
| 小腿后内侧 | 胫骨后肌、趾屈肌群 | 内翻、足弓和内踝稳定 |
| 足底与足弓 | 足底软组织和足内在肌 | 足弓、蹬地、平衡 |

同一小腿区域影响多个方向时只处理一次；先完成当前仍受限方向的低次数主动控制，再统一复测这些方向。已经恢复的方向立即退出，不继续显示控制或复测。

用户或旧记录写“小腿前外侧”时，先结合定位和动作拆分：背屈、胫骨前肌或趾伸肌线索归小腿前侧；外翻或腓骨肌线索归小腿外侧；无法拆分则补充定位。局部处理变化不明显时，大腿外侧链仅作为下一项反应试验。只有原动作稳定改善才保留该方向，不能据此直接认定病因。

| 活动方向 | 动作肌候选 | 拮抗肌候选 | 低次数主动控制 |
| --- | --- | --- | --- |
| 膝伸直 | 大腿前侧肌群 | 大腿后侧、膝后两侧、小腿后侧 | 膝后轻压床面，5～8次 |
| 膝屈曲 | 大腿后侧与膝后两侧 | 大腿前侧肌群 | 脚跟沿床面滑向臀部，5～8次 |
| 踝背屈 | 小腿前侧肌群 | 小腿后侧肌群 | 脚背向上勾，5～8次 |
| 踝跖屈 | 小腿后侧、后内侧肌群 | 小腿前侧肌群 | 坐稳后缓慢把脚背向下压，5～8次 |
| 踝内翻 | 小腿后内侧、前侧肌群 | 小腿外侧肌群 | 脚掌缓慢转向内侧，5～8次 |
| 踝外翻 | 小腿外侧肌群 | 小腿后内侧、前侧肌群 | 脚掌缓慢转向外侧，5～8次 |

这张表用于候选生成，不是要求每行肌肉全部松解。具体执行仍以用户定位、紧张取样、主诉相关性和当前检查结果为准。

### 3.6 肿胀管理

首发普通用户可执行：

- 休息时垫高患侧小腿；
- 在不增加疼痛的范围内缓慢勾脚和下压；
- 当天晚些时候或第二天比较肿胀范围和轮廓。

肿胀不在每项肌肉处理后反复检查。淤青按时间记录，不当作循环异常。

### 3.7 关节处理

专业模式下，肌肉处理后活动仍未达到目标且被动也受限时，可根据方向考虑：

- 距小腿关节；
- 距下关节；
- 远端胫腓关节；
- 其他与检查方向一致的低刺激关节处理。

普通用户只进入肌肉和主动控制路径。

### 3.8 力量与功能训练

#### 第1～2阶段

- 仰卧或半躺踝四方向主动活动；
- 背屈、跖屈、内翻和外翻基础控制；
- 足弓控制；
- 舒适范围双脚提踵；
- 基础臀桥和骨盆稳定。

臀桥只在走路、台阶、单腿、反复负荷或较高恢复目标需要时加入。足趾撞伤、鞋压、大拇趾局部痛等明确局部问题先处理局部，不常规检查或训练臀大肌和腘绳肌。

#### 第3阶段：正常生活

- 单腿臀桥；
- 站立屈髋；
- 双脚提踵；
- 坐站和浅蹲；
- 单腿站；
- 足弓与膝盖方向控制；
- 步态和台阶；
- 髋膝踝联动。

#### 第4阶段：一般运动

- 单腿提踵；
- 动态平衡；
- 分腿蹲和台阶进阶；
- 跑步准备；
- 双脚到单脚落地；
- 低强度减速。

#### 第5阶段：高强度与对抗

- 单脚跳和连续跳；
- 多方向落地；
- 加速、减速和变向；
- 疲劳条件下足踝稳定；
- 专项跑跳和接触准备。

### 3.9 大腿和小腿局部组织路径

大腿和小腿局部入口采用短流程：主诉位置对应的活动与发力为必查项，再加入一个高价值的相反/协同方向；明确功能场景决定功能检查优先级，但不把四个方向全部铺开。补查正常只用于排除，不生成处理；补查异常才加入对应松解、控制或基础训练。大腿前侧补查后侧链，大腿后侧补查前侧或单腿稳定，大腿内外侧互查；小腿前后侧互查，小腿内外侧互查。

小腿前侧/外侧主方向以背屈、外翻及其控制为主，小腿后侧以背屈拉长和跖屈发力为主，小腿内侧出现明确主诉时提高胫骨后肌相关路径优先级。每个方向的动作肌与拮抗肌都可进入一次共享触诊候选，但只显示与本次主方向直接相关的2～3个标准区域。范围正常但主方向复现熟悉的疼、酸、紧或牵扯时仍检查一次；急性局部损伤不要求触诊。

轻按发现明确更紧或更酸的区域后，生成独立“肌肉紧张”问题；两侧接近不生成异常。该区域同次只处理一次，并把其直接关联、且已经确认异常的方向合并复测。

疼痛或不适导致某个活动“无法完成”时，同时记录为症状动作和活动范围待确认。该方向必须保留在未解决清单，并在一组相关处理后复测能否完成、范围和不适分数。害怕、没看懂或主动选择急性期跳过不按活动异常处理。

活动或力量选择“做不出来”后必须即时追问原因并给退阶动作。活动检查按疼痛、害怕、不会操作或其他原因分流；力量检查按疼痛、完全使不上力、找不到发力、不会操作、无人协助或害怕加重分流。疼痛进入症状记录，完全无力或找不到控制进入基础训练，操作/协助问题保持“本次无法判断”。任何“无法完成”都不能走默认分支变成正常。

活动未完成时，不再继续询问依赖该动作已经完成的“不适有无”、主动保持、抗阻力量或被动范围。因疼痛停下直接进入不适位置、性质和评分；因不会做、害怕或其他原因停下直接进入下一项。大小腿的目标区域采用“目标肌肉拉长动作＋目标肌肉主动缩短/保持”配对，第二个相反方向只观察拉长反馈，不再附带另一组肌肉的力量检查。

评估结束只允许出现三种证据状态：明确异常、检查明确且未见异常、证据不足。只要关键检查中仍有“不会做、无法判断或未测试”，就不能显示“没有发现问题”，也不能据此生成针对性处理或直接进阶训练。证据不足时提供三个出口：重新看说明并检查、补充症状信息、保存后由专业人员协助。

处理或训练后加重属于停止状态，不是普通的“无效”。页面先确认停止后的变化，再进入一次训练退阶、最多3项聚焦复查或专业评估；不返回整套评估。退阶仍加重不能循环，后续康复完成聚焦复查后返回原来的复诊阶段。被标记为加重的处理不沿用为有效候选。

处理效果不能只按下降分数排序。主诉5→2记录为“部分贡献”，说明该区域参与当前问题但仍有剩余来源；随后另一来源2→0记录为“关键完成”，本次同时保存为“A＋B组合解决”。如果第一项处理单独使主诉降至0，记录为“单项完成”。“关键完成”表示完成本次剩余症状，不等同于病因或病根。

下一次康复若自然仍有症状，优先复验上次的单项完成或关键完成项：单独重复完成时提高独立相关性；仍需前一部分贡献项与关键完成项组合才解决时，保留组合关系；本次无效时降低优先级并重新排序。不得为了验证故意诱发症状。

大腿和小腿的疼痛位置只作为症状锚点，不直接决定处理位置。主方向活动/发力、一个最相关功能动作和条件式相反/协同方向共同排序候选。局部处理部分改善时继续处理剩余异常；局部处理变化不足且走路、跑步、单腿、台阶、下蹲或变向等功能线索成立时，才开放一个跨区域反应实验。每切换一个新的主要来源可复测一次主诉；同一来源内部、配合处理或没有新处理时复用结果。

恢复目标只确定训练最高阶段，不决定起始阶段。首次从局部低负荷控制和基础协同动作开始；后续根据本次完成质量、症状、次日反应及康复次数逐级开放走路、台阶、单腿和跑跳，不因选择“恢复运动”在首次直接展示整条训练链。

| 路径 | 处理重点 | 恢复顺序 |
| --- | --- | --- |
| 急性拉伤 | 不重压或强拉损伤中心；专业人员可轻柔处理周边明确紧张区域；可耐受时做低强度等长 | 等长 → 全范围控制 → 力量 → 功能负荷 |
| 肌肉撞伤 | 防止再次撞击；不按摩、重压或强拉淤青/血肿中心；冰敷不作为默认恢复方法 | 舒适活动 → 等长 → 力量 → 走路、台阶或运动 |
| 疑似骨应力 | 降低冲击负荷；走路痛、静息/夜间痛或趋势变差时补充医学/影像确认；不进入普通松解 | 无痛走路 → 功能负荷 → 走跑交替 → 先距离后速度 |

四区域的功能锚点：大腿前侧用坐站，大腿后侧用臀桥/单腿臀桥，大腿内外侧用单腿骨盆稳定；小腿前侧用走路抬脚，小腿后侧用提踵，小腿内外侧用单腿足弓与足踝稳定。小腿前后侧使用背屈—跖屈配对，小腿内外侧使用内翻—外翻配对；动作ID、标题和实际操作必须保持同一方向。训练仍从局部等长或主动控制开始，再进入臀桥、坐站、步态、台阶、单腿和跑跳，不直接从疼痛位置跳到高阶功能。
| 肌腱负荷 | 先排突然弹响、凹陷或主动功能突然丧失；以负荷训练和次日反应为主 | 等长 → 双侧慢速 → 单侧力量 → 快速力量/储能 → 跑跳 |

## 4. 主诉性质怎样改变排序

| 描述 | 优先考虑 |
| --- | --- |
| 酸、紧、牵扯 | 紧张位置、肌肉控制和力量 |
| 刺、胀、局部热 | 降低刺激，关注炎症反应、局部摩擦和外伤 |
| 麻、电、烧灼伴感觉变化 | 神经或感觉分布，普通用户不做自助神经手法 |
| 不稳、没劲、打软腿 | 力量、稳定、动作模式和承重能力 |
| 卡、挤、夹 | 关节活动、轨迹、相邻区域和功能动作 |

这些描述只调整评估和候选顺序，不能单独诊断组织。

## 5. 内容数据格式

每个检查项至少包含：

- id；
- 面向用户的名称；
- 怎么做；
- 观察什么；
- 适用身份；
- 触发条件；
- 正常、异常和无法判断选项；
- 可能生成的 findings。

每个处理候选至少包含：

- 处理区域；
- 操作类型；
- 怎么做；
- 停止条件；
- 可影响的活动方向；
- 复测动作；
- 用户权限；
- 来源和版本。

每个训练动作至少包含：

- 起始体位；
- 训练目标；
- 组数和个数；
- 怎么做；
- 退阶和进阶；
- 适用阶段；
- 关联力量、控制和功能标签。
