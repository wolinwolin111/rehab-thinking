# 疼痛评分锚点文案需求

## 背景

康复应用里有一个 0-10 分的疼痛评分滑块，由用户自己选。现状是：

```
0 · 没有疼痛或不适
1～3 轻微，基本不影响动作
4～6 明显，会影响动作
7～9 很重，难以继续
10 · 极重，无法继续
```

## 需求

改写这 4 段锚点文案，让**没有任何医学背景的普通用户**能一眼理解每个分数段大概对应什么感受。

## 约束

1. **通用**：不能绑定特定场景（不能写"走路"、"跑步"、"上下楼"等），因为用户可能是肩、颈、腰、膝等不同部位。
2. **简洁**：每段一句话，不超过 15 个字。
3. **不雷同**：不能用临床 NRS 的常用锚点（如"影响睡眠"、"疼到哭"），需要用自己的描述。
4. **有画面感**：用生活里人自然能感受到的东西来描述，比如表情变化、身体反应、注意力被占据的程度，不要用"轻微/明显/很重"这种抽象的程度词。

## 参考方向（仅供参考，不是要求）

- 疼的时候会皱眉吗？会倒吸一口气吗？会喊出来吗？
- 疼的时候还能继续做手里的事吗？还是会被打断？
- 疼的时候会不自觉地揉它吗？走路会跛吗？
- 疼的时候是不动就疼，还是只有做某个动作时才疼？

## 输出格式

4 段锚点文案，每段对应 1～3 分、4～6 分、7～9 分、10 分（0 分保持不变）。
