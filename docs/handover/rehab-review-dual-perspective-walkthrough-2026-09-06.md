## 3. 康复师视角发现（临床合理性）

### 🔴 真缺陷

**R-1 松解时长双轨不一致（R4 实测 + 源码核对）**
- 走查：R4 膝伸不直 → 针对性处理「右侧大腿外侧链：轻柔松解＋主动控制」→ 文案「用手或泡沫轴轻柔处理 30～60 秒……保持 30～60 秒，必要时一次延长至 90 秒」。
- 核对：批次 5（f9721b6）裁定松解类候选 30～60 → 60～90 秒，catalog `treatment.ts` 已改；但 **knee-workflow-adapter.ts 旧层 do 文案 + candidate-action-core.ts:58 兜底剂量**仍是「30～60 秒，必要时一次延长至 90 秒」。
- 影响：同一次康复中，不同松解候选时长口径不一致（部分 60～90，部分 30～60）；且「必要时延长至 90 秒」与「60～90 秒」并存会让康复师困惑到底是哪个区间。
- 归属：批次 7 缩减时 adapter 原函数保留（记录在案），但时长裁定未同步到保留层——**请 dev 确认**是统一 adapter 层文案，还是明确兜底剂量覆盖规则。
- 建议：候选 `do` 文案统一走目录（松解时长 60～90）；adapter 保留层与 candidate-action-core 兜底同步，或加校验防双轨漂移。

### 🟡 建议优化

**R-2 自助「全正常」评估 → 引导补查而非直接处理（P1）**
- 走查：P1 自助下蹲受限，评估全选正常（能蹲下去/稳定/不会不舒服）→ 落「还有问题需要补充检查」→ 引导「先看膝关节伸直（AROM）」。
- 判断：临床保守合理（下蹲受限与伸直受限相关，补查伸直有依据），且符合"证据不足→assessment"分派（02 §6）。但患者视角（见 P-5）会困惑。
- 建议：补查引导时给一句"为什么补查这项"的通俗解释，降低"我说下蹲疼你却查伸直"的突兀感。

**R-3 专项触发依赖明确来源词（R3 走查正确，但边界未覆盖）**
- 走查：R3 膝扭转+专项能力 → 评估队列含 ACL/骨折风险专项卡，符合知识库 §4（Lachman 优先）。
- 建议（非阻塞）：专项检查"触发词必须命中用户明确来源"（02 §4）在口语化描述下可能漏触发；建议对典型高危词（听到响/不敢用力）做一次走查补测。

### 🟢 有意取舍 / 正确行为（非缺陷）

- **R-4 双侧逐侧复测台账（R5）**：左右两行、confirm 两侧齐全前不放行——符合 bilateral 规则（02 §11）。✅
- **R-5 关节处理未直接进入（R4）**：膝伸不直 → 先松解+主动控制，未直接关节处理——符合"关节处理四条件：肌肉处理后被动仍受限"（02 §7）。✅（注：本次走查未深入驱动到关节处理候选出现，该分支建议另用定向场景验证。）
- **R-6 组织路径（P4/P5）**：大腿后侧拉伤 / 小腿外侧紧酸的症状语境正确落到局部/骨应力筛查线索。✅
- **R-7 踝评估队列（P2/R2）**：承重→下台阶→下蹲等逐卡，功能卡按动作定制（能走完/走不了或不敢走）——符合批次 3 选项定制。✅

## 4. 患者视角发现（可理解 · 可执行）

### 🔴 真缺陷

**P-1 不支持区 / 麻电的位置引导困惑（P6/P7）**
- P6（肩抬手疼）：提示「暂不支持肩关节与肩胛」，但页面仍显示大腿细分图位置选择器，引导用户"这次最想解决哪里"选**下肢**位置；提示文案"骨盆、臀部、腹股沟和髋关节暂未开放"未提"肩"，与用户输入不匹配。
- P7（腰臀麻电）：提示「暂不支持髋关节与大腿」，但麻电范围选择器仍要求"先选择左腿右腿 + 大腿细分图"标记麻电范围。
- 判断：产品范围限制合理（首发只支持大腿至足部），但**拒绝后无清晰"退出/换主诉"路径，仍把用户按在下肢选择器上**；文案列举的不支持区与用户实际输入（肩/腰臀）错位。
- 建议：① 不支持区提示后提供明确出口（如"回到描述修改部位"），不再展示下肢选择器或改为置灰提示；② 提示文案按实际识别的不支持部位动态生成（"肩关节"而非固定列骨盆/髋）；③ 麻电等需要定位的症状，若落在不支持区应直接给"建议线下评估"出口而非强制下肢定位。

### 🟡 建议优化

**P-2 恢复目标双显示易混（R1/P1）**
- 走查：训练页顶部「恢复目标：基础症状改善」（当前训练阶段），侧栏「恢复目标：恢复正常生活」（用户总体目标）。
- 判断：设计上"训练当前阶段"与"总体恢复目标"分层合理，但两处都叫"恢复目标"会让患者以为冲突。
- 建议：训练页顶部改名为"当前训练阶段"或"本次训练目标"，避免与侧栏总体目标重名。

**P-3 位置标注含未感知的部位（P2）**
- 走查：用户填"外踝"，评估卡位置显示"右侧 · 外踝 / 前外侧"——"前外侧"是解析补出的，用户未主动选。
- 建议：自动补出的位置应有来源标记或允许用户核实，避免用户误以为系统记错。

**P-4 补查引导缺"为什么"（P1）**
- 见 R-2。建议补一句通俗理由。

**P-5 训练反馈标签"做完更不舒服"的后果不透明（R1）**
- 走查：训练卡反馈四档（做不了/难度正合适/做完还很轻松/做完更不舒服），选了"更不舒服"会触发加重警告与聚焦复查（T-10）。但按钮上无后果提示。
- 建议：对"做完更不舒服"可在按钮旁加小字（如"选了会先停止并确认变化"），降低误触。

**P-6 自主放松默认折叠（R1）**
- 走查：「训练结束后 针对性自主放松（3 项）」折叠在 details 内，默认收起。
- 建议：训练完成进入下一阶段前，放松作为必做项建议半展开或加提示，否则患者可能忽略。

### 🟢 有意取舍 / 正确行为

- **P-7 训练卡可照做性高（R1）**：怎么做/退阶/进阶/组次清晰，动作配体位与图片——可执行性好。✅
- **P-8 双侧低负荷门文案清晰（P8）**：「当前只开放低负荷基础活动」+ 进阶禁用说明明确。✅
