## 4. 不变式

- 零逻辑变更：超时是纯 UI 生命周期；网格是纯样式；文案不改语义。
- 桌面 toast 样式与位置不变（右下方块）；桌面 `is-two` 440px 封顶保留。
- 错误信息不依赖 toast 持久存在：同步状态条（`pilotSyncState` error/offline）是持久事实源，toast 只是瞬时通知。

## 5. 非阻塞范围

## 6. 已知坑

- **toast 断言不能再等"点击关闭"**：现在所有 toast 都会自动消失（确认 ≤2.8s、错误 5s）。要断言"已消失"用 `wait_for_timeout` 后 count==0；要断言持久状态改断顶部同步状态条。
- 通栏规则 `button:last-child:nth-child(odd)` 作用于**所有**奇数选项非 is-two 网格（含 5 选项裸网格），不只 is-three。
- 移动端 toast 宽度随内容（实测 123px），断言位置用"水平居中 + bottom 固定"，不要断言全宽。
