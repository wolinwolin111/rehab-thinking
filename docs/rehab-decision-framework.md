# 运动康复思路助手：通用决策流程规范

版本：2026-08-01  
适用对象：正在学习运动康复，或希望拓展康复业务的健身、普拉提、瑜伽及体能教练。

## 1. 产品目标

本工具不靠症状名称直接生成一套固定动作，而是还原一次真实康复的工作顺序。

```text
第一次康复：症状询问 → 评估检查 → 问题清单 → 处理与训练 → 保存记录
第二次康复：确认新症状 → 定向复查旧问题 → 调整处理 → 更新记录
```

第一次康复结束后不直接进入统一“复测步骤”。活动度和疼痛动作可以在处理后当场复测；肿胀、按压痛、力量、耐力和平衡按照各自恢复时间，在稍后或下一次康复复查。出现新症状时重新走症状询问和相关评估，没有新症状时不重复完整检查。

输出重点始终是四件事：

1. 做什么。
2. 怎么做。
3. 做的时候观察什么。
4. 根据结果如何调整。

## 2. 第一层：症状问询

所有损伤至少收集以下信息，具体选项根据部位配置。

### 2.1 症状与受伤背景

- 症状最集中的位置。
- 是否存在明确受伤事件。
- 受伤时关节或身体怎样受力。
- 是否存在明显大力量冲击。
- 距离受伤过去多久。
- 从受伤到现在是好转、无变化还是继续恶化。
- 疼痛性质：酸胀、钝痛、刺痛、烧灼或麻电感。

### 2.2 大力量冲击不使用专业词提问

不要直接问用户“是不是高能量机制”，应询问具体场景：

- 平地踩空或普通运动扭伤。
- 脚被固定后身体猛烈旋转。
- 从明显高度落地，受伤部位首先承受冲击。
- 车辆、高速碰撞、重物挤压或工业事故。

大力量机制不能单独决定影像需要，必须与骨点压痛、承重或使用能力、变形、感觉和症状趋势组合判断。

### 2.3 局部出血与循环异常分开

急性扭伤或拉伤后，局部紫红、青紫、黄绿色淤血以及淤血向远端移动，可以是皮下出血的演变，不应直接标记为循环异常。

循环与神经筛查应改问：

> 除了受伤区域的局部淤青，手指、脚趾或整个远端肢体是否比健侧明显苍白、灰暗或青紫，并伴随发凉、持续麻木或感觉下降？

处理规则：

- 只有局部淤青，远端温度和感觉正常：记录范围，继续评估。
- 包扎后短暂麻凉，松开后恢复：调整支撑并复测。
- 整个远端肢体持续发凉、麻木或异常变色：优先医学评估。

### 2.4 功能问题必须在问询阶段确定

用户多选真正受限的任务，例如：

- 走路或承重。
- 上下楼。
- 踮脚、蹬地或推举。
- 下蹲、弯腰或抬手。
- 单脚站、转身或方向变化。
- 日常使用动作，例如举手、穿衣、拧毛巾、拿物。
- 跑跳、力量训练或专项运动。

没有报告的问题，不自动生成对应检查和训练。

## 3. 第二层：优先级分流

异常表现分为三级，避免所有问题都显示“停止”。

### 3.1 一级：及时处理

- 明显错位、异常角度或开放性损伤。
- 远端肢体持续发凉、苍白或青紫，并伴感觉或运动能力下降。
- 突然完全丧失肌腱功能，并且相关完整性测试高度异常。
- 快速进展的严重症状或全身异常。

### 3.2 二级：补充影像或专业检查

- 骨性突起上清晰、集中的压痛。
- 大力量机制同时伴随完全无法负重或使用。
- 经过短期保护后仍完全无法完成基本功能。
- 症状持续不变或恶化，尤其超过预期急性反应期。
- 关节明显锁住、机械性卡住。
- 特殊测试明显支持跟腱、胫腓联合或其他重要结构问题。

系统应说明需要确认的方向，而不是笼统地说“超出边界”。例如：

- X线主要确认骨折或脱位。
- 超声可用于部分肌腱和浅表软组织。
- MRI用于需要进一步确认的韧带、肌腱、骨挫伤或关节内问题。

### 3.3 三级：可以继续康复试验

- 局部肿胀或淤青。
- 能走但跛行。
- 某方向活动受限。
- 动作中出现刺痛，但可以顺利回到起点，没有锁住。
- 软组织压痛。
- 部分承重、力量或平衡能力下降。
- 特殊测试不清楚或无人协助。

这一级通过降低剂量、改变动作或单变量处理继续评估。

## 4. 时间、机制、功能和趋势必须组合

不能只根据某一个指标决定是否需要影像或停止康复。

推荐组合：

```text
受伤时间
× 受力机制
× 骨点压痛
× 基本功能
× 症状趋势
× 处理后的变化
```

以急性踝损伤为例：

- 能走四步但轻度跛行：优先进行承重、活动度、力量和步态评估。
- 伤后时间较短、普通低能量机制、没有骨点压痛，但因疼痛暂时不能走四步：先保护性承重和低剂量活动，12–24小时复测。
- 不能走四步，并伴骨点压痛或大力量机制：提高X线或专业检查优先级。
- 数日后仍无改善，或功能继续下降：重新检查骨性、韧带、肌腱和关节内问题。
- 较长时间仍完全无法基本承重：不能只靠肌肉松解继续试。

## 5. 第三层：动态检查

检查项目由前面的答案决定，而不是所有人完成同一套清单。

### 5.1 基础检查

- 局部观察：肿胀、淤青、轮廓及左右差异。
- 触诊定位：骨点、肌腹、肌腱、韧带区和弥散敏感。
- 关节活动：每个主要方向逐项与健侧比较。
- 基础力量：优先使用健患侧对比，不要求非专业用户填写精确角度或徒手肌力等级。

### 5.2 功能检查

- 下肢：承重、走路、提踵、下蹲、台阶、平衡和专项移动。
- 上肢：抬手、摸背、拿物、推拉、拧毛巾及目标训练动作。

### 5.3 特殊测试

- 只选择与位置、机制和功能高度相关的项目。
- 明确标注单人可做或需要协助。
- 阳性结果用于提高某个方向的优先级，不单独完成疾病诊断。
- 刺痛与锁住必须分开记录。

## 6. 第四层：生成可验证假设

每个受限表现至少考虑以下来源：

1. 肿胀或局部压力。
2. 疼痛保护与肌肉紧张。
3. 肌肉力量或耐力不足。
4. 关节附属活动不足。
5. 动作控制、负荷和代偿策略。
6. 韧带、肌腱、骨性或关节内问题。
7. 神经相关因素。

系统只把它们称为“候选来源”，不能用一次测试直接写成确诊。

## 7. 第五层：处理—复测

### 7.1 肿胀

- 做什么：支撑、适当加压、抬高、舒适范围主动活动。
- 看什么：同角度照片中的轮廓、肿胀边界和皮肤纹理。
- 复测：肿胀减轻、不变或增加。

### 7.2 软组织与肌肉

- 根据疼痛位置和受限方向列出多组候选肌肉。
- 避开骨点、韧带、肌腱、淤血中心和最痛点。
- 一次只选择一组肌腹处理。
- 处理后立即复测原活动方向或原功能动作。

### 7.3 刺痛

刺痛不自动终止流程，也不自动等于结构损伤。

```text
记录刺痛动作和出现位置
→ 减小动作幅度或负荷
→ 选择一组周围肌腹轻柔处理
→ 不直接按压刺痛点
→ 用同样动作和负荷复测
```

- 刺痛减轻：保留肌肉处理作为辅助，并衔接主动训练。
- 没有变化：转向关节活动、负荷、触诊和其他组织。
- 出现锁住、骨点集中痛或功能下降：停止诱发，补充评估。

### 7.4 活动受限与关节松动

各方向活动受限可能同时来自肌肉、肿胀、疼痛保护、关节活动或动作控制。

流程：

```text
确认受限方向
→ 主动活动或一组候选肌肉试验
→ 复测
→ 改善：主动训练巩固
→ 无改善：进入独立的关节松动试验
```

关节松动规则：

- 由受过相应训练的人操作。
- 先排除骨点压痛、明显不稳、持续神经血管异常和机械性锁住。
- 一次只选择一个关节和一个方向。
- 急性阶段从低等级、小幅度开始。
- 不与肌肉松解同时完成。
- 做完立即复测原方向和原功能动作。

### 7.5 训练

训练不是“症状减轻”后的附加内容，而是恢复功能的主体：

- 局部活动与四向力量。
- 小腿或前臂等局部肌群力量。
- 臀腿、肩胛或躯干等近端能力。
- 步态、平衡、台阶或日常使用动作。
- 跑跳、变向、推拉及专项训练。

## 8. 结果调整规则

每张处理卡只提供与当前问题一致的结果按钮：

- 肿胀：减轻 / 不变 / 增加。
- 活动度：范围增加 / 不变 / 范围更小。
- 刺痛：减轻 / 不变 / 加重。
- 步态：跛行减少 / 不变 / 加重。
- 力量：完成更稳 / 不变 / 反应加重。
- 平衡：更稳 / 不变 / 更不稳。

通用调整：

- 改善：保留当前变量，使用主动活动或训练巩固。
- 不变：不继续加力，换一个假设。
- 加重：撤回本次变量，降低难度或补充检查。
- 即时改善后还要记录当天晚些时候和第二天反应。

## 10. 自由输入与影像信息的产品化规则

### 10.1 症状输入不直接生成方案

自由描述先被整理为部位、侧别、发生时间、发生方式、主要表现和功能影响。用户确认系统理解后，再进入分流问询；缺少的信息由后续问题补齐。AI未来可以负责语言理解和追问排序，但风险规则、测试条件和训练进阶仍由结构化规则控制。

### 10.2 不要求用户判断“有没有结构损伤”

有影像时采用逐项问答：检查类型、骨折或骨裂、骨挫伤或骨髓水肿、韧带、肌腱、积液、软骨，以及医生给出的负重或固定限制。每项允许选择“写有、明确没有、报告没提、看不懂”，避免不同医院报告格式导致的文本解析误差。

### 10.3 需要影像时先保存，再重新评估

保存本次受伤机制、压痛位置、承重、活动和特殊测试结果。取得影像后，从同一案例补充结构化影像信息，并重新走一次症状与功能评估；新方案同时服从影像结论、医生限制和当前功能，不直接沿用旧剂量。

### 10.4 骨点压痛使用组合判断

骨点压痛本身不等同于骨折，也不自动锁死全部处理。需要结合具体骨点、受伤力量、能否走四步、足中部症状、时间和变化趋势：低能量、仍能承重且持续改善时，可保护痛点并继续低风险活动；与高风险因素组合时，保存记录并优先补充影像或医学评估。

## 11. 线下记录提炼出的处理规则

资料范围：259份线下评估、治疗和反馈记录，共约1.56万行。记录格式和完整度不同，因此这里只提炼工作方法与候选关系，不把出现频率或一次即时改善当成疗效证明，也不保留个人身份信息。

### 11.1 线下处理的共同顺序

```text
找到可重复的问题表现
→ 明确受限方向、疼痛动作或功能任务
→ 选择一个候选来源
→ 只改变一个变量
→ 立即重复原动作
→ 有效：保留并用主动训练巩固
→ 无效：停止重复，换另一个来源
→ 肿胀、压痛和力量按合适时间延迟复查
```

记录中最有价值的不是某一种手法，而是“用原问题动作验证处理方向”。例如按压或屏蔽某组肌肉、调整关节位置、改变骨盆或足部支撑后，立即重复原疼痛动作；没有变化时会记录为无效并转向其他组织。

### 11.2 问题到处理方法的映射

| 评估发现 | 首选试验 | 无明显变化时 | 复查时间 |
|---|---|---|---|
| 肌肉紧张、肌腹敏感 | 选择一组相关肌腹轻柔松解、拉伸或MET | 换相邻肌群、关节活动或神经方向 | 立即复测原动作 |
| 某方向活动受限 | 先处理限制该方向的候选肌肉 | 由受训者做对应关节松动；仍无效则查肿胀、关节内或相邻关节 | 当场复测活动方向和功能动作 |
| 关节附属活动不足或手动对位后改善 | 单一关节、单一方向低剂量松动 | 不加大力度，改查软组织、动作控制和邻近部位 | 当场复测 |
| 神经张力或麻电、牵拉表现 | 低剂量神经滑动，不停留在症状终点 | 重新确认感觉分布、相邻卡压和医学筛查 | 当场与稍后复查 |
| 肿胀、局部炎症 | 支撑、回流、舒适主动活动；有资质和设备时才加入物理因子 | 检查当天负荷和是否存在结构或循环异常 | 数小时及次日，不要求当场消失 |
| 肌力不足或萎缩 | 直接安排对应肌肉激活和分级力量 | 降级动作、增加支撑或改变姿势 | 下次康复比较，不要求当场变强 |
| 步态、台阶或动作模式异常 | 调整重心、支撑、步幅或近端发力后重复任务 | 回查局部活动度、力量、疼痛保护和近端控制 | 当场复测任务，次日确认反应 |

### 11.3 踝足模块中的高频候选关系

- 背屈受限：小腿三头肌、胫骨前后肌、趾伸肌群、肿胀、距小腿关节活动和腓骨活动都作为候选，不能只写成“腓肠肌紧”。
- 外翻或外侧症状：小腿前外侧软组织、腓骨近端与远端活动、距骨和中足活动是常见排查方向。
- 足底接触异常或脚趾踩地感改变：除局部肌肉外，可比较骰骨、足舟骨和足弓支撑调整前后的步态变化。
- 走路、台阶和蹬地受限：局部处理后还要加入提踵、小腿四向力量、臀腿力量、重心转移和步态训练。
- 局部处理无效或症状反复：再检查髋、骨盆、神经张力和整体负荷；近端因素作为第二层候选，不默认所有踝痛都来自骨盆。

### 11.4 按部位整理的评估顺序

以下顺序来自线下记录中反复出现的检查组合。它描述“先查什么”，不是要求每个人完成全部测试；前面的结果正常时可以减少后续项目，发现新症状时则返回相关评估。

#### 膝关节

```text
症状位置、肿胀和功能任务
→ 髌腱、脂肪垫、关节线、鹅足、腘窝等位置轻触诊
→ 膝伸直、弯曲和终点感觉
→ 髌骨与腓骨近端活动（受训者）
→ 踝背屈、髋内外旋
→ 股四头肌、腘绳肌、臀肌和小腿力量
→ 走路、坐站、浅蹲、台阶和单脚控制
→ 按症状选择半月板、韧带或其他特殊测试
```

- 伸直受限：先比较腘肌、腘绳肌和小腿后侧；无变化时再检查膝关节、髌骨或腓骨近端活动。
- 弯曲受限：先比较股直肌、大腿前侧和腘窝周围；无变化时再看关节活动与肿胀。
- 踝或髋处理后，必须回到原膝部动作复测；原动作没变就不保留这个来源。
- 力量不足：按股四头肌、腘绳肌、臀肌和小腿的实际弱项安排训练，不追求当场变强。
- 功能训练：从坐站、浅蹲、低台阶进入，随后增加下肢离心控制与单脚任务。

#### 踝关节与足部

```text
受伤机制、时间、肿胀、淤青、承重和远端感觉
→ 骨点与软组织触诊
→ 背屈、跖屈、内翻、外翻
→ 距骨、腓骨近端/远端、骰骨、跟骨（受训者）
→ 背屈、跖屈、内翻、外翻力量
→ 神经或稳定性特殊测试（按症状选择）
→ 重心转移、步态、提踵、平衡、台阶和下蹲
```

- 关节活动检查必须作为候选来源：只有轻柔调整后原受限方向或原功能动作改变，才保留该位置。
- 走路和楼梯恢复不能只训练踝部，还要加入小腿、臀腿、平衡和步态控制。
- 肿胀与压痛使用延迟观察；活动方向和疼痛动作使用当场复测。

#### 肩关节

```text
疼痛动作、侧睡和上肢麻电表现
→ 肩胛位置、肱骨位置和局部压痛
→ 前屈、后伸、外展、水平内收、内旋、外旋
→ 颈椎、胸椎、第一肋骨和前臂旋转
→ 肩袖内外旋、外展和肩胛控制
→ 举手、摸后脑、手到腰后、拧毛巾和墙面推
→ 按症状选择肩袖、肩锁或神经相关测试
```

- 活动受限时，胸大肌、胸小肌、背阔肌、上斜方肌、肩胛提肌、肩袖和后侧关节囊都是候选，不能一次全部处理。
- 肩胛或胸椎调整只有在原抬手动作改变时才保留。
- 训练以肩袖、前锯肌和肩胛控制为主，再逐级恢复推、拉、支撑和过顶动作。

#### 腰背与髋部

```text
疼痛位置、久坐/弯腰/后伸行为和腿部症状
→ 腰背六方向活动
→ 髋内外旋、屈髋和骨盆动作
→ 腰椎分节活动（受训者）
→ 有腿部症状时检查神经张力
→ 臀肌、髋后伸、腘绳肌和躯干控制
→ 坐站、步行、弯腰取物和髋铰链
```

- 先用一处肌肉、髋部或骨盆调整做反应试验；腰部任务没有改变时不继续扩大处理范围。
- 神经表现与普通牵拉感分开记录，低剂量滑动后同时观察感觉分布和功能。
- 训练按呼吸、臀桥、鸟狗、蚌式开合、站立屈髋和髋铰链逐级推进。

### 11.5 后续每次康复的生成规则

后续康复不能只生成训练。每个仍存在的问题分别进入以下分支：

- 活动受限、疼痛动作：生成“本次处理 → 当场复测 → 根据结果调整”。
- 肿胀、按压痛：继续低风险处理，并安排稍后或次日观察。
- 力量、耐力、平衡：直接生成训练，不要求当场改善。
- 已改善：减少被动处理，用主动活动和训练巩固。
- 处理后不变：不重复加力，换一个候选来源。
- 变差或连续两次同一方向无效：返回相关评估，检查遗漏因素或补充医学信息。
